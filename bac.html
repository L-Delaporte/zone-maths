Rigueur et rédaction mathématique

Au bac, le résultat seul ne rapporte presque rien : tout réside dans la clarté du raisonnement (hypothèses du TVI vérifiées, initialisation et hérédité soignées pour la récurrence).

Un exercice de type bac commenté

Cet exercice a été écrit pour le site : il ne provient pas d'un sujet officiel et son barème est indicatif.

Énoncé (5 points)

On considère la fonction f définie sur [0 ; +∞[ par f(x) = √(2x + 3) et la suite (un) définie par u0 = 0 et, pour tout entier naturel n, un+1 = f(un).

  1. (2 points) Démontrer par récurrence que, pour tout entier naturel n, 0 ≤ un ≤ un+1 ≤ 3.
  2. (0,5 point) En déduire que la suite (un) converge.
  3. (1,5 point) Déterminer la limite de la suite (un).
  4. (1 point) Écrire en Python une fonction seuil() qui renvoie le plus petit entier n tel que 3 − un < 0,001.

Corrigé et conseils de rédaction

  1. On note P(n) la propriété « 0 ≤ un ≤ un+1 ≤ 3 ». Initialisation : u0 = 0 et u1 = √3, donc 0 ≤ u0 ≤ u1 ≤ 3 : P(0) est vraie. Hérédité : supposons P(n) vraie pour un entier naturel n. La fonction f est croissante sur [0 ; +∞[, donc f(0) ≤ f(un) ≤ f(un+1) ≤ f(3), c'est-à-dire √3 ≤ un+1 ≤ un+2 ≤ 3. Comme √3 ≥ 0, P(n + 1) est vraie. Conclusion : P(n) est vraie pour tout entier naturel n.
    Conseil. Énoncez la propriété, signalez où sert l'hypothèse de récurrence et justifiez la croissance de f : c'est elle qui permet de conserver les inégalités.
  2. D'après la question 1, la suite est croissante et majorée par 3. Or toute suite croissante et majorée converge : (un) converge.
    Conseil. Citez les deux hypothèses : une suite majorée, sans être croissante, peut ne pas converger.
  3. Notons ℓ la limite de la suite. Pour tout n, un ≥ 0, donc ℓ ≥ 0. La fonction f étant continue sur [0 ; +∞[, le passage à la limite dans un+1 = f(un) donne ℓ = f(ℓ). Ainsi ℓ² = 2ℓ + 3, soit (ℓ − 3)(ℓ + 1) = 0. Comme ℓ ≥ 0, on a ℓ = 3.
    Conseil. Mentionnez la continuité de f et expliquez pourquoi la valeur −1 est écartée. 
  4. from math import sqrt

def seuil():
    n = 0
    u = 0
    while 3 - u >= 0.001:
        u = sqrt(2 * u + 3)
        n = n + 1
    return n
    La fonction renvoie 8 : 3 − u7 ≈ 0,002 et 3 − u8 ≈ 0,0007.
    Conseil. La boucle se poursuit tant que la condition voulue n'est pas atteinte : la condition du while est la négation de 3 − un < 0,001.
