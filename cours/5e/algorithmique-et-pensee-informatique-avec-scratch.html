Cours et exercices corrigés de 5e : Algorithmique et pensée informatique avec Scratch

Instructions séquentielles de déplacement et dessin, boucles inconditionnelles de répétition, initialisation et lecture de variables simples.

Objectifs du chapitre

  • Décomposer un problème en une suite ordonnée d'instructions (algorithme) et l'exécuter à la main.
  • Écrire et tester un script Scratch déclenché par un événement (drapeau vert, touche pressée).
  • Utiliser une boucle bornée (« répéter nnn fois ») et une instruction conditionnelle (« si … alors … sinon »).
  • Utiliser une variable, notamment pour programmer un programme de calcul.
  • Tracer un polygone régulier : angle de rotation 360∘n\frac{360^\circ}{n}n360∘​.

Le cours

1. Les bases de Scratch

  • Le lutin exécute le script sur la scène. Sa position est repérée par ses coordonnées : xxx entre −240-240−240 et 240240240, yyy entre −180-180−180 et 180180180.
  • Un script commence par un bloc événement : « quand le drapeau vert est cliqué », « quand la touche espace est pressée ».
  • Blocs de mouvement : « avancer de 505050 pas », « tourner de 909090 degrés », « aller à x : 000 y : 000 ».
  • Extension stylo : « stylo en position d'écriture » pour laisser une trace, « effacer tout » pour repartir d'une scène vide.

2. Boucles et polygones réguliers

Une boucle répète une séquence d'instructions : « répéter nnn fois », « répéter jusqu'à ce que … », « répéter indéfiniment ».
Pour tracer un polygone régulier à nnn côtés, le lutin fait un tour complet (360∘360^\circ360∘) en nnn rotations égales :

répéter n fois
    avancer de (côté)
    tourner de (360 / n)

Polygone réguliernnnAngle de rotation
triangle équilatéral3120∘120^\circ120∘
carré490∘90^\circ90∘
pentagone572∘72^\circ72∘
hexagone660∘60^\circ60∘
octogone845∘45^\circ45∘

3. Variables

Une variable est une « boîte » qui porte un nom et contient une valeur qui peut changer pendant le programme : « mettre score à 000 », « ajouter 111 à score ».
Programme de calcul en Scratch (le nombre saisi est stocké dans « réponse ») :

quand drapeau vert cliqué
demander [Nombre ?] et attendre
mettre [r] à ((réponse) * 3)
ajouter 5 à [r]
dire (r)

La variable rrr vaut d'abord le triple du nombre saisi, puis on lui ajoute 555 : si l'utilisateur tape 444, le lutin dit 171717 (4×3+54 \times 3 + 54×3+5). Dans Scratch, le signe ×\times× s'écrit « * ».

4. Instructions conditionnelles

Le bloc « si alors … sinon … » exécute une partie du script seulement si la condition est vraie, l'autre partie sinon.

si (réponse) = 12 alors
    dire [Bravo !]
sinon
    dire [Essaie encore]

Une condition peut utiliser ===, <<<, >>> ou un capteur (« couleur touchée ? », « touche pressée ? »).

À retenir

  • Un script = un événement + une séquence d'instructions exécutées dans l'ordre.
  • « répéter nnn fois » exécute nnn fois tout le bloc qu'elle contient.
  • Polygone régulier à nnn côtés : tourner de 360∘n\frac{360^\circ}{n}n360∘​.
  • Une variable mémorise une valeur ; « si … alors … sinon » choisit entre deux actions.

Méthodes et exemples rédigés

Méthode : Déterminer l'angle de rotation d'un polygone régulier

Exemple

Quel angle de rotation faut-il programmer pour tracer un pentagone régulier ?

  1. Propriété : Un pentagone régulier possède 5 côtés égaux.

  2. Règle : Pour faire un tour complet et fermer la figure, la somme des rotations extérieures vaut 360∘360^\circ360∘.

  3. Calcul : Angle=360∘5=72∘\text{Angle} = \frac{360^\circ}{5} = 72^\circAngle=5360∘​=72∘.

  4. Script : Répéter 5 fois : avancer de LLL, tourner de 72∘72^\circ72∘.

Méthode : Exécuter un script à la main avec une variable

Exemple

Quelle est la valeur finale de xxx ?

mettre [x] à 4
répéter 3 fois
    mettre [x] à ((x) * 2)
    ajouter 1 à [x]

  1. Étape 1 : On fait un tableau de suivi. Au départ, x=4x = 4x=4.

  2. Tour 1 : x=4×2=8x = 4 \times 2 = 8x=4×2=8, puis x=8+1=9x = 8 + 1 = 9x=8+1=9.

  3. Tour 2 : x=9×2=18x = 9 \times 2 = 18x=9×2=18, puis x=19x = 19x=19.

  4. Tour 3 : x=19×2=38x = 19 \times 2 = 38x=19×2=38, puis x=39x = 39x=39. La valeur finale est 393939.

Méthode : Utiliser une condition

Exemple

Écrire un script qui demande un nombre entier et dit « pair » ou « impair ».

  1. Étape 1 : Un entier est pair si le reste de sa division par 222 est 000 ; dans Scratch, ce reste s'obtient avec le bloc « (réponse) modulo (2) ».

  2. Étape 2 : On utilise « si ((réponse) modulo (2)) = 0 alors dire [pair] sinon dire [impair] ».

  3. Étape 3 : On teste avec plusieurs valeurs : 141414 donne « pair », 777 donne « impair ».

Pièges fréquents

  • Pour tracer un triangle équilatéral, l'angle de rotation dans Scratch est l'angle extérieur (180∘−60∘=120∘180^\circ - 60^\circ = 120^\circ180∘−60∘=120∘) et non l'angle intérieur de 60∘60^\circ60∘ !
  • Bien penser à réinitialiser la position (« aller à x:0, y:0 » et « effacer tout ») au début de chaque script.
  • Une instruction placée après une boucle (et non à l'intérieur) n'est exécutée qu'une seule fois.
  • Dans « si … alors … sinon », une seule des deux parties est exécutée.

Questions de révision

Essaie de répondre de tête avant d'afficher la réponse.

De quel angle doit-on tourner pour tracer un carré dans Scratch ?

90∘90^\circ90∘ (car 360∘4=90∘\frac{360^\circ}{4} = 90^\circ4360∘​=90∘).

De quel angle doit-on tourner pour tracer un triangle équilatéral ?

120∘120^\circ120∘ (car 360∘3=120∘\frac{360^\circ}{3} = 120^\circ3360∘​=120∘).

De quel angle le lutin doit-il tourner pour tracer un hexagone régulier ?

360∘÷6=60∘360^\circ \div 6 = 60^\circ360∘÷6=60∘.

Combien de fois est exécutée l'instruction située dans un bloc « répéter 5 fois » ?

Exactement 5 fois de suite.

Que fait le bloc « avancer de 50 » dans Scratch ?

Il déplace le lutin de 50 pas dans la direction vers laquelle il est orienté.

Qu'est-ce qu'une variable en programmation ?

Une « boîte » nommée qui mémorise une valeur pouvant changer pendant l'exécution du programme.

Exercices corrigés

Exercice 1 Tracé d'un carré dans Scratch

Palier 1 · découverte

Dans Scratch, pour tracer un carré avec une boucle « répéter 4 fois : avancer de 50, tourner de ... degrés », de quel angle doit-on tourner ?

Un indice

La somme des 4 rotations fait 360∘360^\circ360∘.

Voir la correction

Réponse attendue : 90

Angle=360∘4=90∘\text{Angle} = \frac{360^\circ}{4} = 90^\circAngle=4360∘​=90∘

Exercice 2 Distance totale parcourue

Palier 2 · application

Un lutin exécute le script : « répéter 6 fois : avancer de 15 pas ». Quelle distance totale en pas a-t-il parcourue ?

Un indice

Multiplie le nombre de répétitions par le nombre de pas.

Voir la correction

Réponse attendue : 90

6×15=90 pas6 \times 15 = 90\text{ pas}6×15=90 pas

Exercice 3 Triangle équilatéral dans Scratch

Palier 3 · approfondissement

Pour faire tracer un triangle équilatéral à un lutin avec le bloc « répéter 3 fois », quel doit être l'angle de rotation extérieur en degrés ?

Un indice

Attention : l'angle extérieur vaut 360∘3\frac{360^\circ}{3}3360∘​.

Voir la correction

Réponse attendue : 120

Angle=360∘3=120∘\text{Angle} = \frac{360^\circ}{3} = 120^\circAngle=3360∘​=120∘

Exercice 4 Défi : Programme de calcul Scratch multi-étapes

Palier 4 · défi

Un lutin exécute le programme de calcul Scratch suivant :

quand drapeau cliqué
demander [Choisir un nombre] et attendre
mettre [N] à réponse
mettre [N] à (N + 4)
mettre [N] à (N * 5)
mettre [N] à (N - 15)
mettre [N] à (N / 2)
dire (N)

Si l'on choisit le nombre 777 au départ, quel nombre affiche le lutin à la fin ?

Un indice

Applique chaque bloc l'un après l'autre dans l'ordre : ajoute 4 à 7, puis multiplie le résultat par 5...

Voir la correction

Réponse attendue : 20

((7+4)×5−15)÷2=(11×5−15)÷2=(55−15)÷2=402=20((7 + 4) \times 5 - 15) \div 2 = (11 \times 5 - 15) \div 2 = (55 - 15) \div 2 = \frac{40}{2} = 20((7+4)×5−15)÷2=(11×5−15)÷2=(55−15)÷2=240​=20
