Cours et exercices corrigés de 5e : Repérage sur une droite et dans le plan

Abscisse d'un point sur une droite graduée, repère orthogonal du plan (abscisse et ordonnée positives et négatives).

Objectifs du chapitre

  • Lire et placer des abscisses sur une droite graduée.
  • Lire les coordonnées d'un point dans le plan muni d'un repère orthogonal.
  • Placer un point de coordonnées relatives données.
  • Calculer les coordonnées du milieu d'un segment.

Le cours

1. Droite graduée

Chaque point d'une droite graduée est repéré par un nombre relatif appelé son abscisse. L'origine OOO a pour abscisse 0.

  • Les nombres positifs se trouvent à droite de l'origine.
  • Les nombres négatifs se trouvent à gauche de l'origine.

2. Repère orthogonal du plan

Dans un repère orthogonal, la position d'un point MMM est donnée par un couple de nombres noté M(x;y)M(x ; y)M(x;y) :

  • xxx est l'abscisse (axe horizontal, orienté de gauche à droite).
  • yyy est l'ordonnée (axe vertical, orienté de bas en haut).

Astuce mnémotechnique : Ordre alphabétique (xxx puis yyy).

3. Milieu d'un segment dans un repère

  • Sur une droite graduée, l'abscisse du milieu MMM de [AB][AB][AB] est la demi-somme des abscisses :

xM=xA+xB2x_M = \frac{x_A + x_B}{2}xM​=2xA​+xB​​

  • Dans le repère du plan, les coordonnées du milieu MMM de [AB][AB][AB] sont :

M(xA+xB2;yA+yB2)M\left(\frac{x_A + x_B}{2} ; \frac{y_A + y_B}{2}\right)M(2xA​+xB​​;2yA​+yB​​)

Méthodes et exemples rédigés

Méthode : Placer un point dans un repère

Exemple

Placer le point A(−4;3)A(-4 ; 3)A(−4;3) dans un repère orthogonal.

  1. Étape 1 : Partir de l'origine O(0;0)O(0;0)O(0;0).

  2. Étape 2 : Se déplacer de 4 unités vers la gauche sur l'axe des abscisses (x=−4x = -4x=−4).

  3. Étape 3 : Monter de 3 unités sur l'axe des ordonnées (y=+3y = +3y=+3) et placer AAA.

Pièges fréquents

  • Ne pas intervertir l'abscisse et l'ordonnée : le premier nombre est toujours horizontal, le deuxième vertical !

Questions de révision

Essaie de répondre de tête avant d'afficher la réponse.

Quelles sont les coordonnées de l'origine d'un repère ?

O(0;0)O(0 ; 0)O(0;0) : abscisse 0 et ordonnée 0.

Dans les coordonnées d'un point M(3;−4)M(3 ; -4)M(3;−4), quel nombre est l'abscisse ?

333 est l'abscisse (lu sur l'axe horizontal) et −4-4−4 est l'ordonnée (lu sur l'axe vertical).

Sur une droite graduée, où se situent les nombres négatifs par rapport à zéro ?

À gauche de l'origine 0 (ou vers le bas si la graduation est verticale).

Que peut-on dire de l'abscisse du milieu MMM d'un segment [AB][AB][AB] ?

L'abscisse de MMM est la moyenne des abscisses de AAA et BBB : xM=xA+xB2x_M = \frac{x_A + x_B}{2}xM​=2xA​+xB​​

Exercices corrigés

Exercice 1 Abscisse sur une droite graduée

Palier 1 · découverte

Sur une droite graduée d'origine OOO, le point AAA a pour abscisse −4-4−4. Quelle est la distance OAOAOA ?

Un indice

La distance à zéro d'un nombre est toujours positive.

Voir la correction

Réponse attendue : 4

La distance entre l'origine et le point d'abscisse −4-4−4 est égale à 444 unités.

Exercice 2 Lecture de coordonnées dans le plan

Palier 2 · application

Dans un repère orthogonal, le point MMM a pour coordonnées (3;−5)(3 ; -5)(3;−5). Quelle est l'ordonnée de ce point ?

Un indice

Les coordonnées s'écrivent sous la forme (abscisse;ordonneˊe)(\text{abscisse} ; \text{ordonnée})(abscisse;ordonneˊe).

Voir la correction

Réponse attendue : -5

L'abscisse est 3 (axe horizontal) et l'ordonnée est −5-5−5 (axe vertical).

Exercice 3 Symétrie par rapport aux axes

Palier 3 · approfondissement

Dans un repère orthogonal, le point AAA a pour coordonnées (2;5)(2 ; 5)(2;5). Quelles sont les coordonnées de son symétrique A′A'A′ par rapport à l'axe des abscisses ?

  1. (2 ; -5)
  2. (-2 ; 5)
  3. (-2 ; -5)
  4. (5 ; 2)
Un indice

Le point reste au même niveau horizontal mais passe de l'autre côté de l'axe des abscisses.

Voir la correction

Bonne réponse : A. (2 ; -5)

Exact : la symétrie par rapport à l'axe des abscisses conserve l'abscisse et change le signe de l'ordonnée.

L'abscisse reste x=2x = 2x=2 et l'ordonnée devient l'opposée : y=−5y = -5y=−5, donc A′(2;−5)A'(2 ; -5)A′(2;−5).

Exercice 4 Défi 4ème : Milieu d'un segment

Palier 4 · défi

Dans un repère, on donne A(2;4)A(2 ; 4)A(2;4) et B(8;10)B(8 ; 10)B(8;10). Quelle est l'abscisse du milieu III du segment [AB][AB][AB] ?

Un indice

L'abscisse du milieu est la moyenne des abscisses : xA+xB2\frac{x_A + x_B}{2}2xA​+xB​​.

Voir la correction

Réponse attendue : 5

xI=2+82=102=5x_I = \frac{2 + 8}{2} = \frac{10}{2} = 5xI​=22+8​=210​=5
