Cours et exercices corrigés de L3 : Complétude, Espaces de Banach et Théorème du Point Fixe de Picard

Suites de Cauchy, espaces métriques complets, espaces de Banach (EVN complets), prolongement des applications uniformément continues, théorème du point fixe de Picard-Banach, théorème de Cauchy-Lipschitz pour les EDO, théorème de Baire.

Objectifs du chapitre

  • Définir les espaces de Banach et utiliser le critère des séries absolument convergentes.
  • Démontrer que Lc(E,F)\mathcal{L}_c(E, F)Lc​(E,F) est un espace de Banach dès que FFF l'est.
  • Définir les espaces de Hilbert et énoncer le théorème de projection sur un convexe fermé.
  • Énoncer et appliquer le théorème de représentation de Riesz dans un espace de Hilbert.
  • Connaître le théorème de Baire, ses conséquences (Banach-Steinhaus, application ouverte) et le théorème du point fixe de Picard.

6. Baire, Banach-Steinhaus et point fixe de Picard

  • Théorème de Baire : dans un espace métrique complet, toute intersection dénombrable d'ouverts denses est dense ; de façon équivalente, une réunion dénombrable de fermés d'intérieur vide est d'intérieur vide.
  • Banach-Steinhaus : si EEE est un Banach, FFF un espace normé et (Ti)i∈I(T_i)_{i \in I}(Ti​)i∈I​ une famille de Lc(E,F)\mathcal{L}_c(E, F)Lc​(E,F) telle que sup⁡i∥Tix∥<+∞\sup_i \|T_i x\| < +\inftysupi​∥Ti​x∥<+∞ pour tout xxx, alors sup⁡i∥Ti∥<+∞\sup_i \|T_i\| < +\inftysupi​∥Ti​∥<+∞.
  • Application ouverte : une application linéaire continue surjective entre deux Banach est ouverte ; si elle est bijective, son inverse est continu (isomorphisme de Banach).
  • Point fixe de Picard : soit (X,d)(X, d)(X,d) complet non vide et f:X→Xf : X \to Xf:X→X kkk-contractante avec k∈[0;1[k \in [0 ; 1[k∈[0;1[. Alors fff a un unique point fixe x∗x^{\ast}x∗ et, pour tout x0x_0x0​, la suite xn+1=f(xn)x_{n+1} = f(x_n)xn+1​=f(xn​) converge vers x∗x^{\ast}x∗ avec

  • Banach-Steinhaus suppose l'espace de départ complet ; sans complétude, une famille simplement bornée peut ne pas être uniformément bornée.

Considère la suite xn+1=f(xn)x_{n+1} = f(x_n)xn+1​=f(xn​) : montre que d(xn+1,xn)≤knd(x1,x0)d(x_{n+1}, x_n) \le k^n d(x_1, x_0)d(xn+1​,xn​)≤knd(x1​,x0​), puis que la suite est de Cauchy.

Voir la correction

Bonne réponse : A. fff admet un unique point fixe

Le théorème du point fixe de Banach affirme que toute application strictement contractante d'un espace métrique complet dans lui-même possède un unique point fixe.

Exercice 2 Espace de Banach

Palier 2 · application

Un espace vectoriel normé (E,∥⋅∥)(E, \|\cdot\|)(E,∥⋅∥) est appelé un espace de Banach lorsqu'il est :

  1. Complet pour la distance induite par la norme
  2. De dimension finie
  3. Muni d'un produit scalaire
  4. Séparable
Un indice

Compare des exemples : R\mathbb{R}R est un espace de Banach, Q\mathbb{Q}Q ne l'est pas, et ℓ∞\ell^\inftyℓ∞ en est un bien qu'il soit de dimension infinie. Quelle propriété des suites de Cauchy distingue R\mathbb{R}R de Q\mathbb{Q}Q ?

Voir la correction

Bonne réponse : A. Complet pour la distance induite par la norme

Par définition, un espace de Banach est un espace vectoriel normé complet pour la métrique issue de sa norme.

Exercice 3 Un espace vectoriel normé non complet

Palier 3 · approfondissement

On munit E=C([0,1],R)E = \mathcal{C}([0,1], \mathbb{R})E=C([0,1],R) de la norme ∥f∥1=∫01∣f(t)∣ dt\|f\|_1 = \int_0^1 |f(t)|\,dt∥f∥1​=∫01​∣f(t)∣dt. L'espace (E,∥⋅∥1)(E, \|\cdot\|_1)(E,∥⋅∥1​) est-il un espace de Banach ?

Exercice 4 Théorème de Baire

Palier 4 · défi

Dans un espace métrique complet (E,d)(E, d)(E,d), que stipule le théorème de Baire pour toute suite (On)(O_n)(On​) d'ouverts denses ?

  1. L'intersection ⋂n=1∞On\bigcap_{n=1}^\infty O_n⋂n=1∞​On​ est dense dans EEE
  2. L'intersection est vide
  3. L'intersection est compacte
  4. L'union est fermée
Un indice

Pour montrer qu'une partie est dense, il suffit de montrer qu'elle rencontre toute boule ouverte B0B_0B0​ de EEE.

Voir la correction

Bonne réponse : A. L'intersection ⋂n=1∞On\bigcap_{n=1}^\infty O_n⋂n=1∞​On​ est dense dans EEE

Le théorème de Baire énonce que dans tout espace métrique complet (ou localement compact), toute intersection dénombrable d'ouverts denses est dense.
