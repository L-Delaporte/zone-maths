Licence 3 · Analyse Fonctionnelle · L3-05

Cours et exercices corrigés de L3 : Complétude, Espaces de Banach et Théorème du Point Fixe de Picard

Suites de Cauchy, espaces métriques complets, espaces de Banach (EVN complets), prolongement des applications uniformément continues, théorème du point fixe de Picard-Banach, théorème de Cauchy-Lipschitz pour les EDO, théorème de Baire.

Objectifs du chapitre

  • Définir les suites de Cauchy et les espaces de Banach (espaces vectoriels normés complets).
  • Définir les espaces de Hilbert, l'orthogonalité, et énoncer le Théorème de Projection sur un convexe fermé.
  • Énoncer et appliquer le Théorème de Représentation de Riesz pour le dual d'un espace de Hilbert.
  • Comprendre les grands théorèmes de l'analyse fonctionnelle : Théorème de Baire, Banach-Steinhaus, et Théorème du Point Fixe de Picard.

Le cours

1. Suites de Cauchy et Espaces de Banach

  • Suite de Cauchy : Une suite (xn)n∈N(x_n)_{n \in \mathbb{N}}(xn​)n∈N​ dans un EVN (E,∥⋅∥)(E, \|\cdot\|)(E,∥⋅∥) est de Cauchy si :

∀ε>0,  ∃N∈N,  ∀p,q≥N,∥xp−xq∥<ε\forall \varepsilon > 0, \; \exists N \in \mathbb{N}, \; \forall p, q \ge N, \quad \|x_p - x_q\| < \varepsilon∀ε>0,∃N∈N,∀p,q≥N,∥xp​−xq​∥<ε

  • Espace complet : Un espace métrique est dit complet si toute suite de Cauchy y est convergente.
  • Espace de Banach : Un espace de Banach est un espace vectoriel normé complet.

- En dimension finie, tout EVN est un espace de Banach.
- (C([a,b],R),∥⋅∥∞)(\mathcal{C}([a, b], \mathbb{R}), \|\cdot\|_\infty)(C([a,b],R),∥⋅∥∞​) et les espaces Lp(μ)L^p(\mu)Lp(μ) sont des espaces de Banach.
- Contre-exemple : (C([0,1],R),∥⋅∥1)(\mathcal{C}([0, 1], \mathbb{R}), \|\cdot\|_1)(C([0,1],R),∥⋅∥1​) n'est pas complet.

2. Espaces de Hilbert et Théorème de Projection Orthogonale

  • Espace de Hilbert : Un espace préhilbertien (H,⟨⋅,⋅⟩)(H, \langle \cdot, \cdot \rangle)(H,⟨⋅,⋅⟩) complet pour la norme euclidienne/hermitienne associée ∥x∥=⟨x,x⟩\|x\| = \sqrt{\langle x, x \rangle}∥x∥=⟨x,x⟩​.
  • Identité du parallélogramme : Un EVN est préhilbertien ssi sa norme vérifie :

∥x+y∥2+∥x−y∥2=2(∥x∥2+∥y∥2)\|x + y\|^2 + \|x - y\|^2 = 2(\|x\|^2 + \|y\|^2)∥x+y∥2+∥x−y∥2=2(∥x∥2+∥y∥2)

  • Théorème de projection sur un convexe fermé : Soit CCC un sous-ensemble convexe fermé non vide de HHH. Pour tout x∈Hx \in Hx∈H, il existe un unique y0=pC(x)∈Cy_0 = p_C(x) \in Cy0​=pC​(x)∈C tel que :

∥x−y0∥=dist(x,C)=inf⁡y∈C∥x−y∥\|x - y_0\| = \text{dist}(x, C) = \inf_{y \in C} \|x - y\|∥x−y0​∥=dist(x,C)=y∈Cinf​∥x−y∥
Caractérisation variationnelle : ∀y∈C,  Re⟨x−y0,y−y0⟩≤0\forall y \in C, \; \text{Re}\langle x - y_0, y - y_0 \rangle \le 0∀y∈C,Re⟨x−y0​,y−y0​⟩≤0.

  • Si FFF est un sous-espace vectoriel fermé, la projection pF(x)p_F(x)pF​(x) est linéaire et caractérisée par x−pF(x)∈F⊥x - p_F(x) \in F^\perpx−pF​(x)∈F⊥, avec décomposition orthogonale : H=F⊕F⊥H = F \oplus F^\perpH=F⊕F⊥.

3. Dualité et Théorème de Représentation de Riesz

  • Dual topologique E∗E^*E∗ : Espace L(E,K)\mathcal{L}(E, \mathbb{K})L(E,K) des formes linéaires continues sur EEE, muni de la norme ∥∥φ∥∥=sup⁡∥x∥≤1∣φ(x)∣\|\|\varphi\|\| = \sup_{\|x\| \le 1} |\varphi(x)|∥∥φ∥∥=sup∥x∥≤1​∣φ(x)∣. Le dual est toujours un espace de Banach.
  • Théorème de Représentation de Riesz-Fréchet : Soit HHH un espace de Hilbert réel (ou complexe). Pour toute forme linéaire continue φ∈H∗\varphi \in H^*φ∈H∗, il existe un unique vecteur y∈Hy \in Hy∈H tel que :

∀x∈H,φ(x)=⟨x,y⟩\forall x \in H, \quad \varphi(x) = \langle x, y \rangle∀x∈H,φ(x)=⟨x,y⟩
De plus, l'application y↦φy \mapsto \varphiy↦φ est une isométrie : ∥∥φ∥∥H∗=∥y∥H\|\|\varphi\|\|_{H^*} = \|y\|_H∥∥φ∥∥H∗​=∥y∥H​.

4. Théorème de Baire et Théorème du Point Fixe de Picard

  • Théorème de Baire : Dans un espace métrique complet, toute intersection dénombrable d'ouverts denses est dense (un espace complet n'est pas réunion dénombrable de fermés d'intérieurs vides).
  • Conséquences fondamentales :

- Théorème de Banach-Steinhaus (borne uniforme) : Une famille d'opérateurs continus ponctuellement bornée sur un Banach est uniformément bornée.
- Théorème de l'application ouverte : Tout opérateur linéaire continu surjectif entre Banach est une application ouverte.

  • Théorème du point fixe de Banach-Picard : Soit (X,d)(X, d)(X,d) un espace métrique complet non vide et f:X→Xf : X \to Xf:X→X une application kkk-contractante (k∈[0,1[k \in [0, 1[k∈[0,1[) : ∀x,y,d(f(x),f(y))≤kd(x,y)\forall x, y, d(f(x), f(y)) \le k d(x, y)∀x,y,d(f(x),f(y))≤kd(x,y). Alors fff admet un unique point fixe x∗∈Xx^* \in Xx∗∈X, et pour tout x0x_0x0​, la suite xn+1=f(xn)x_{n+1} = f(x_n)xn+1​=f(xn​) converge vers x∗x^*x∗ avec majoration géométrique : d(xn,x∗)≤kn1−kd(x0,x1)d(x_n, x^*) \le \frac{k^n}{1-k} d(x_0, x_1)d(xn​,x∗)≤1−kkn​d(x0​,x1​).

Méthodes et exemples rédigés

Méthode : Trouver la projection orthogonale d'un vecteur sur un sous-espace

Exemple

Dans H=L2([−1,1])H = L^2([-1, 1])H=L2([−1,1]), projeter f(t)=t2f(t) = t^2f(t)=t2 sur le sous-espace F=Vect(1,t)F = \text{Vect}(1, t)F=Vect(1,t).

  1. Étape 1 (Orthogonalité de la base) : Calculer le produit scalaire ⟨1,t⟩=∫−11t dt=0\langle 1, t \rangle = \int_{-1}^1 t \, dt = 0⟨1,t⟩=∫−11​tdt=0. La famille (e0=1,e1=t)(e_0 = 1, e_1 = t)(e0​=1,e1​=t) est une base orthogonale de FFF.

  2. Étape 2 (Normes des vecteurs de base) : ∥e0∥2=∫−111dt=2\|e_0\|^2 = \int_{-1}^1 1 dt = 2∥e0​∥2=∫−11​1dt=2 et ∥e1∥2=∫−11t2dt=23\|e_1\|^2 = \int_{-1}^1 t^2 dt = \frac{2}{3}∥e1​∥2=∫−11​t2dt=32​.

  3. Étape 3 (Formule des coefficients de Fourier) : pF(f)=⟨f,e0⟩∥e0∥2e0+⟨f,e1⟩∥e1∥2e1p_F(f) = \frac{\langle f, e_0 \rangle}{\|e_0\|^2} e_0 + \frac{\langle f, e_1 \rangle}{\|e_1\|^2} e_1pF​(f)=∥e0​∥2⟨f,e0​⟩​e0​+∥e1​∥2⟨f,e1​⟩​e1​.

    • ⟨f,e0⟩=∫−11t2dt=23\langle f, e_0 \rangle = \int_{-1}^1 t^2 dt = \frac{2}{3}⟨f,e0​⟩=∫−11​t2dt=32​.
    • ⟨f,e1⟩=∫−11t3dt=0\langle f, e_1 \rangle = \int_{-1}^1 t^3 dt = 0⟨f,e1​⟩=∫−11​t3dt=0 (parité impaire).

  4. Conclusion : pF(f)=2/32⋅1+0=13p_F(f) = \frac{2/3}{2} \cdot 1 + 0 = \frac{1}{3}pF​(f)=22/3​⋅1+0=31​. Le meilleur polynôme de degré ≤1\le 1≤1 approchant t2t^2t2 au sens des moindres carrés est la constante 13\frac{1}{3}31​.

Pièges fréquents

  • Pour que le théorème de projection s'applique, le sous-espace FFF doit obligatoirement être fermé (ce qui est toujours vrai en dimension finie, mais pas en dimension infinie) !
  • L'identité du parallélogramme caractérise exclusivement les normes issues d'un produit scalaire (les normes ∥⋅∥p\|\cdot\|_p∥⋅∥p​ pour p≠2p \neq 2p=2 ne la vérifient pas).

Exercices corrigés

Exercice 1 Théorème du point fixe de Picard-Banach

Palier 1 · découverte

Soit (E,d)(E, d)(E,d) un espace métrique complet et f:E→Ef : E \to Ef:E→E une application strictement contractante (k<1k < 1k<1). Que garantit le théorème de Banach ?

  1. fff admet un unique point fixe
  2. fff admet une infinité de points fixes
  3. fff est surjective mais n'a pas de point fixe
  4. fff est bornée
Un indice

Théorème fondamental d'analyse appliqué aux suites d'approximations successives xn+1=f(xn)x_{n+1} = f(x_n)xn+1​=f(xn​).

Voir la correction

Bonne réponse : A. fff admet un unique point fixe

Le théorème du point fixe de Banach affirme que toute application strictement contractante d'un espace métrique complet dans lui-même possède un unique point fixe.

Exercice 2 Espace de Banach

Palier 2 · application

Un espace vectoriel normé (E,∥⋅∥)(E, \|\cdot\|)(E,∥⋅∥) est appelé un espace de Banach lorsqu'il est :

  1. Complet pour la distance induite par la norme
  2. De dimension finie
  3. Muni d'un produit scalaire
  4. Séparable
Un indice

Un espace de Banach est un evn complet.

Voir la correction

Bonne réponse : A. Complet pour la distance induite par la norme

Par définition, un espace de Banach est un espace vectoriel normé complet pour la métrique issue de sa norme.

Exercice 3 Un espace vectoriel normé non complet

Palier 3 · approfondissement

On munit E=C([0,1],R)E = \mathcal{C}([0,1], \mathbb{R})E=C([0,1],R) de la norme ∥f∥1=∫01∣f(t)∣ dt\|f\|_1 = \int_0^1 |f(t)|\,dt∥f∥1​=∫01​∣f(t)∣dt. L'espace (E,∥⋅∥1)(E, \|\cdot\|_1)(E,∥⋅∥1​) est-il un espace de Banach ?

  1. Non : une suite de fonctions continues qui approche une fonction échelon est de Cauchy pour ∥⋅∥1\|\cdot\|_1∥⋅∥1​ mais n'a pas de limite continue
  2. Oui : C([0,1],R)\mathcal{C}([0,1], \mathbb{R})C([0,1],R) est complet pour toute norme
  3. Oui : car [0,1][0,1][0,1] est compact
  4. Non : car ∥⋅∥1\|\cdot\|_1∥⋅∥1​ n'est pas une norme sur EEE
Un indice

Pense à fnf_nfn​ valant 000 sur [0,12][0, \frac12][0,21​], 111 sur [12+1n,1][\frac12 + \frac1n, 1][21​+n1​,1] et affine entre les deux.

Bonne réponse : A. Non : une suite de fonctions continues qui approche une fonction échelon est de Cauchy pour ∥⋅∥1\|\cdot\|_1∥⋅∥1​ mais n'a pas de limite continue

Soit fnf_nfn​ nulle sur [0,12][0, \frac12][0,21​], égale à 111 sur [12+1n,1][\frac12 + \frac1n, 1][21​+n1​,1] et affine sur [12,12+1n][\frac12, \frac12 + \frac1n][21​,21​+n1​]. Si fn→ff_n \to ffn​→f dans (E,∥⋅∥1)(E, \|\cdot\|_1)(E,∥⋅∥1​) avec fff continue, alors ∫01/2∣f∣≤∥fn−f∥1→0\int_0^{1/2} |f| \le \|f_n - f\|_1 \to 0∫01/2​∣f∣≤∥fn​−f∥1​→0, donc f=0f = 0f=0 sur [0,12][0, \frac12][0,21​] ; et pour tout a>12a > \frac12a>21​, ∫a1∣f−1∣≤∥fn−f∥1\int_a^1 |f - 1| \le \|f_n - f\|_1∫a1​∣f−1∣≤∥fn​−f∥1​ dès que 12+1n≤a\frac12 + \frac1n \le a21​+n1​≤a, donc f=1f = 1f=1 sur ]12,1]]\frac12, 1]]21​,1]. Exercice 4 Théorème de Baire

Palier 4 · défi

Dans un espace métrique complet (E,d)(E, d)(E,d), que stipule le théorème de Baire pour toute suite (On)(O_n)(On​) d'ouverts denses ?

  1. L'intersection ⋂n=1∞On\bigcap_{n=1}^\infty O_n⋂n=1∞​On​ est dense dans EEE
  2. L'intersection est vide
  3. L'intersection est compacte
  4. L'union est fermée
Un indice

Théorème de catégorie de Baire.

Voir la correction

Bonne réponse : A. L'intersection ⋂n=1∞On\bigcap_{n=1}^\infty O_n⋂n=1∞​On​ est dense dans EEE

Le théorème de Baire énonce que dans tout espace métrique complet (ou localement compact), toute intersection dénombrable d'ouverts denses est dense.
