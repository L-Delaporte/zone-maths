Licence 3 · Optimisation · L3-13

Cours et exercices corrigés de L3 : Programmation linéaire, algorithme du Simplexe et dualité

Problèmes d'optimisation sous contraintes, forme standard de la programmation linéaire, polyèdres convexes et sommets extrêmes, algorithme du simplexe (tableaux, variables d'écart, pivotage), problème dual et théorème fort de la dualité.

Objectifs du chapitre

  • Formaliser un programme linéaire sous forme standard et définir les solutions de base admissibles.
  • Énoncer le théorème fondamental de la programmation linéaire (optimum atteint en un sommet).
  • Dérouler l'algorithme du simplexe (variable entrante, test du ratio, pivot) et détecter un problème non borné.
  • Écrire le dual d'un programme linéaire, démontrer la dualité faible et utiliser la dualité forte et les écarts complémentaires.
  • Énoncer les conditions de Karush-Kuhn-Tucker pour un problème d'optimisation convexe.

Le cours

1. Polyèdres et forme standard

  • Polyèdre : intersection finie de demi-espaces fermés, P={x∈Rn∣Ax≤b}P = \{x \in \mathbb{R}^n \mid Ax \le b\}P={x∈Rn∣Ax≤b} ; il est convexe et fermé. Un polyèdre borné est un polytope.
  • Point extrême (sommet) : x∈Px \in Px∈P qui n'est le milieu d'aucun segment [y;z]⊂P[y ; z] \subset P[y;z]⊂P avec y≠zy \neq zy=z.
  • Forme standard :

avec A∈Mm,n(R)A \in \mathcal{M}_{m,n}(\mathbb{R})A∈Mm,n​(R) de rang m≤nm \le nm≤n.

2. Solutions de base admissibles et théorème fondamental

  • Base : ensemble BBB de mmm indices tel que la sous-matrice ABA_BAB​ soit inversible ; NNN désigne les autres indices. La solution de base associée est xN=0x_N = 0xN​=0, xB=AB−1bx_B = A_B^{-1}bxB​=AB−1​b.
  • Solution de base admissible (SBA) : solution de base avec xB≥0x_B \ge 0xB​≥0. Théorème : les SBA sont exactement les sommets du polyèdre {Ax=b, x≥0}\{Ax = b, \, x \ge 0\}{Ax=b,x≥0}. Il y en a au plus (nm)\binom{n}{m}(mn​).
  • Dégénérescence : une SBA est dégénérée si une variable de base est nulle ; plusieurs bases peuvent alors définir le même sommet.
  • Théorème fondamental : pour un programme linéaire sous forme standard,

1. si l'ensemble admissible est non vide, il possède au moins un sommet ;
2. si le problème admet une solution optimale, il existe une SBA optimale ;
3. si l'ensemble admissible est non vide et l'objectif majoré sur cet ensemble, une solution optimale existe.

  • L'ensemble des solutions optimales est une face du polyèdre : il peut y avoir une infinité d'optima (une arête entière, par exemple).

Pièges fréquents

  • Si, pour la variable entrante, tous les coefficients de la colonne pivot sont ≤0\le 0≤0, le problème est non borné : on peut augmenter indéfiniment cette variable sans violer les contraintes.
  • Sens des inégalités au passage au dual : pour un primal max⁡\maxmax avec contraintes ≤\le≤ et x≥0x \ge 0x≥0, le dual est un min⁡\minmin avec contraintes ≥\ge≥ et y≥0y \ge 0y≥0 ; une contrainte primale d'égalité donne une variable duale de signe quelconque.
  • La dégénérescence peut faire stagner, voire cycler, le simplexe (pivots sans gain) : utiliser la règle de Bland garantit la terminaison.
  • Un optimum atteint en un sommet n'est pas forcément unique : pour max⁡ x1+x2\max\, x_1 + x_2maxx1​+x2​ sous x1+x2≤1x_1 + x_2 \le 1x1​+x2​≤1, x≥0x \ge 0x≥0, tout le segment joignant (1,0)(1, 0)(1,0) et (0,1)(0, 1)(0,1) est optimal.
  • Si le primal est irréalisable, le dual n'est pas forcément non borné : les deux problèmes peuvent être irréalisables simultanément.
