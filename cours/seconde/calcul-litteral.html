Objectifs du chapitre

  • Développer et réduire des expressions algébriques du second degré.
  • Maîtriser les 3 identités remarquables dans les deux sens (développement et factorisation).
  • Factoriser par recherche d'un facteur commun ou identité remarquable.
  • Calculer avec des expressions fractionnaires (somme, quotient) en précisant les valeurs interdites.
  • Utiliser les règles de calcul sur les puissances entières (positives et négatives).
  • Démontrer qu'une égalité est vraie (par le calcul) ou fausse (par un contre-exemple).
  • Automatiser les règles du calcul fractionnaire et des signes (−(a−b)=b−a-(a - b) = b - a−(a−b)=b−a, division par une fraction…).
  • Programmer en Python la recherche de la première puissance d'un nombre dépassant un seuil.

Le cours

1. Les 3 identités remarquables fondamentales

Pour tous nombres réels aaa et bbb :
1. Carré d'une somme : (a+b)2=a2+2ab+b2(a + b)^2 = a^2 + 2ab + b^2(a+b)2=a2+2ab+b2
2. Carré d'une différence : (a−b)2=a2−2ab+b2(a - b)^2 = a^2 - 2ab + b^2(a−b)2=a2−2ab+b2
3. Différence de deux carrés : (a−b)(a+b)=a2−b2(a - b)(a + b) = a^2 - b^2(a−b)(a+b)=a2−b2

  • Dans le sens direct : on développe un produit en une somme.
  • Dans le sens réciproque : on factorise une somme en un produit (très utile pour résoudre des équations produit-nul).

2. Techniques avancées de factorisation

  • Facteur commun évident ou composé :

A(x)=(2x−3)(x+5)−(2x−3)(4x−1)=(2x−3)[(x+5)−(4x−1)]=(2x−3)(−3x+6)A(x) = (2x - 3)(x + 5) - (2x - 3)(4x - 1) = (2x - 3)[(x + 5) - (4x - 1)] = (2x - 3)(-3x + 6)A(x)=(2x−3)(x+5)−(2x−3)(4x−1)=(2x−3)[(x+5)−(4x−1)]=(2x−3)(−3x+6)

  • Reconnaissance d'une identité remarquable :

B(x)=9x2−25=(3x)2−52=(3x−5)(3x+5)B(x) = 9x^2 - 25 = (3x)^2 - 5^2 = (3x - 5)(3x + 5)B(x)=9x2−25=(3x)2−52=(3x−5)(3x+5)

3. Distributivité simple et double

Pour tous réels kkk, aaa, bbb, ccc, ddd :
k(a+b)=ka+kb(a+b)(c+d)=ac+ad+bc+bdk(a + b) = ka + kb \qquad (a + b)(c + d) = ac + ad + bc + bdk(a+b)=ka+kb(a+b)(c+d)=ac+ad+bc+bd
Exemple : (2x+3)(x−4)=2x2−8x+3x−12=2x2−5x−12(2x + 3)(x - 4) = 2x^2 - 8x + 3x - 12 = 2x^2 - 5x - 12(2x+3)(x−4)=2x2−8x+3x−12=2x2−5x−12.

  • Développer : transformer un produit en somme. Factoriser : transformer une somme en produit. Réduire : regrouper les termes de même degré.

4. Règles de calcul sur les puissances

Pour tous réels aaa et bbb non nuls et tous entiers relatifs nnn et mmm :

  • an×am=an+ma^n \times a^m = a^{n+m}an×am=an+m et anam=an−m\frac{a^n}{a^m} = a^{n-m}aman​=an−m
  • (an)m=an×m(a^n)^m = a^{n \times m}(an)m=an×m et (a×b)n=an×bn(a \times b)^n = a^n \times b^n(a×b)n=an×bn
  • a0=1a^0 = 1a0=1 et a−n=1ana^{-n} = \frac{1}{a^n}a−n=an1​

Exemple : 27×2−223=27−2−3=22=4\frac{2^7 \times 2^{-2}}{2^3} = 2^{7 - 2 - 3} = 2^2 = 42327×2−2​=27−2−3=22=4.
Attention : (a+b)n≠an+bn(a + b)^n \neq a^n + b^n(a+b)n=an+bn en général.

5. Expressions fractionnaires et valeurs interdites

Un quotient A(x)B(x)\frac{A(x)}{B(x)}B(x)A(x)​ n'existe que si B(x)≠0B(x) \neq 0B(x)=0 : les valeurs de xxx qui annulent le dénominateur sont les valeurs interdites.
Pour additionner deux quotients, on les réduit au même dénominateur : ab+cd=ad+bcbd\frac{a}{b} + \frac{c}{d} = \frac{ad + bc}{bd}ba​+dc​=bdad+bc​.
Exemple : pour x≠0x \neq 0x=0 et x≠−1x \neq -1x=−1 :
1x+2x+1=(x+1)+2xx(x+1)=3x+1x(x+1)\frac{1}{x} + \frac{2}{x + 1} = \frac{(x + 1) + 2x}{x(x + 1)} = \frac{3x + 1}{x(x + 1)}x1​+x+12​=x(x+1)(x+1)+2x​=x(x+1)3x+1​

6. Démontrer ou réfuter une égalité

  • Pour démontrer qu'une égalité est vraie pour tout xxx, on transforme un membre (en général le plus compliqué) jusqu'à obtenir l'autre, ou on développe les deux membres séparément.
  • Pour prouver qu'elle est fausse, un seul contre-exemple suffit.

Exemple : l'égalité (a+b)2=a2+b2(a + b)^2 = a^2 + b^2(a+b)2=a2+b2 est fausse : avec a=b=1a = b = 1a=b=1, on obtient (1+1)2=4(1 + 1)^2 = 4(1+1)2=4 mais 12+12=21^2 + 1^2 = 212+12=2.

9. Illustration géométrique de (a+b)2(a + b)^2(a+b)2

Pour a>0a > 0a>0 et b>0b > 0b>0, on découpe un carré de côté a+ba + ba+b en quatre morceaux : un carré de côté aaa (aire a2a^2a2), un carré de côté bbb (aire b2b^2b2) et deux rectangles de dimensions a×ba \times ba×b (aire ababab chacun).
L'aire totale vaut donc a2+ab+ab+b2a^2 + ab + ab + b^2a2+ab+ab+b2, ce qui illustre :
(a+b)2=a2+2ab+b2(a + b)^2 = a^2 + 2ab + b^2(a+b)2=a2+2ab+b2
Les deux rectangles expliquent le double produit 2ab2ab2ab que l'on oublie souvent.

10. Python : première puissance dépassant un seuil

Pour un nombre q>1q > 1q>1, les puissances q1,q2,q3,…q^1, q^2, q^3, \dotsq1,q2,q3,… finissent par dépasser n'importe quel seuil. On cherche la première qui le dépasse avec une boucle non bornée :

def premiere_puissance(q, seuil):
    n = 0
    p = 1
    while p <= seuil:
        p = p * q
        n = n + 1
    return n


print(premiere_puissance(2, 1000))   # affiche 10 car 29 = 512 et 210 = 1024

Pour 0<q<10 < q < 10<q<1, les puissances diminuent : on cherche la première puissance inférieure à un seuil en remplaçant la condition par while p >= seuil:.

Méthodes et exemples rédigés

Méthode : Factoriser une expression avec différence de deux carrés composés

Exemple

Factoriser E(x)=(3x−2)2−(x+4)2E(x) = (3x - 2)^2 - (x + 4)^2E(x)=(3x−2)2−(x+4)2.

  1. Étape 1 : On reconnaît la forme a2−b2=(a−b)(a+b)a^2 - b^2 = (a - b)(a + b)a2−b2=(a−b)(a+b) avec a=(3x−2)a = (3x - 2)a=(3x−2) et b=(x+4)b = (x + 4)b=(x+4).

  2. Étape 2 : On écrit les facteurs en conservant les parenthèses intérieures : E(x)=[(3x−2)−(x+4)][(3x−2)+(x+4)]E(x) = [(3x - 2) - (x + 4)][(3x - 2) + (x + 4)]E(x)=[(3x−2)−(x+4)][(3x−2)+(x+4)].

  3. Étape 3 : On supprime les parenthèses avec précaution : E(x)=[3x−2−x−4][3x−2+x+4]=(2x−6)(4x+2)E(x) = [3x - 2 - x - 4][3x - 2 + x + 4] = (2x - 6)(4x + 2)E(x)=[3x−2−x−4][3x−2+x+4]=(2x−6)(4x+2).

Méthode : Factoriser un trinôme carré parfait

Exemple

Factoriser F(x)=4x2−12x+9F(x) = 4x^2 - 12x + 9F(x)=4x2−12x+9.

  1. Étape 1 : On repère deux carrés : 4x2=(2x)24x^2 = (2x)^24x2=(2x)2 et 9=329 = 3^29=32. On pose a=2xa = 2xa=2x et b=3b = 3b=3.

  2. Étape 2 : On vérifie le double produit : 2ab=2×2x×3=12x2ab = 2 \times 2x \times 3 = 12x2ab=2×2x×3=12x. Il apparaît avec le signe −-−, on reconnaît donc a2−2ab+b2a^2 - 2ab + b^2a2−2ab+b2.

  3. Étape 3 : On applique l'identité a2−2ab+b2=(a−b)2a^2 - 2ab + b^2 = (a - b)^2a2−2ab+b2=(a−b)2 : F(x)=(2x−3)2F(x) = (2x - 3)^2F(x)=(2x−3)2.

  4. Conclusion : F(x)=(2x−3)2F(x) = (2x - 3)^2F(x)=(2x−3)2. Contrôle : (2x−3)2=4x2−12x+9(2x - 3)^2 = 4x^2 - 12x + 9(2x−3)2=4x2−12x+9.

Méthode : Écrire une expression sous forme d'un seul quotient

Exemple

Pour x≠1x \neq 1x=1, écrire A(x)=2−3x−1A(x) = 2 - \frac{3}{x - 1}A(x)=2−x−13​ sous la forme d'un seul quotient.

  1. Étape 1 : On écrit 222 avec le dénominateur x−1x - 1x−1 : 2=2(x−1)x−12 = \frac{2(x - 1)}{x - 1}2=x−12(x−1)​.

  2. Étape 2 : On soustrait les numérateurs : A(x)=2(x−1)−3x−1A(x) = \frac{2(x - 1) - 3}{x - 1}A(x)=x−12(x−1)−3​.

  3. Étape 3 : On développe et on réduit le numérateur : 2(x−1)−3=2x−2−3=2x−52(x - 1) - 3 = 2x - 2 - 3 = 2x - 52(x−1)−3=2x−2−3=2x−5.

  4. Conclusion : pour x≠1x \neq 1x=1, A(x)=2x−5x−1A(x) = \frac{2x - 5}{x - 1}A(x)=x−12x−5​. Contrôle avec x=2x = 2x=2 : 2−31=−12 - \frac{3}{1} = -12−13​=−1 et 4−51=−1\frac{4 - 5}{1} = -114−5​=−1.

Méthode : Faire apparaître un facteur commun caché

Exemple

Factoriser H(x)=x2−9+(x−3)(2x+1)H(x) = x^2 - 9 + (x - 3)(2x + 1)H(x)=x2−9+(x−3)(2x+1).

  1. Étape 1 : On factorise d'abord x2−9x^2 - 9x2−9 avec a2−b2a^2 - b^2a2−b2 : x2−9=(x−3)(x+3)x^2 - 9 = (x - 3)(x + 3)x2−9=(x−3)(x+3).

  2. Étape 2 : On voit apparaître le facteur commun (x−3)(x - 3)(x−3) : H(x)=(x−3)(x+3)+(x−3)(2x+1)=(x−3)[(x+3)+(2x+1)]H(x) = (x - 3)(x + 3) + (x - 3)(2x + 1) = (x - 3)[(x + 3) + (2x + 1)]H(x)=(x−3)(x+3)+(x−3)(2x+1)=(x−3)[(x+3)+(2x+1)].

  3. Étape 3 : On réduit le second facteur : (x+3)+(2x+1)=3x+4(x + 3) + (2x + 1) = 3x + 4(x+3)+(2x+1)=3x+4.

  4. Conclusion : H(x)=(x−3)(3x+4)H(x) = (x - 3)(3x + 4)H(x)=(x−3)(3x+4). Contrôle avec x=0x = 0x=0 : −9+(−3)×1=−12-9 + (-3) \times 1 = -12−9+(−3)×1=−12 et (−3)×4=−12(-3) \times 4 = -12(−3)×4=−12.

Pièges fréquents

  • Erreur classique de parenthèse : −(x+4)=−x−4-(x + 4) = -x - 4−(x+4)=−x−4 et non −x+4-x + 4−x+4 !
  • (a+b)2≠a2+b2(a+b)^2 \neq a^2 + b^2(a+b)2=a2+b2 : il ne faut jamais oublier le double produit 2ab2ab2ab !
  • (3x)2=9x2(3x)^2 = 9x^2(3x)2=9x2 et non 3x23x^23x2 : le carré porte sur tout le produit.
  • −32=−9-3^2 = -9−32=−9 alors que (−3)2=9(-3)^2 = 9(−3)2=9 : sans parenthèses, le carré ne porte que sur 333.
  • On ne simplifie jamais un terme d'une somme : x+3x≠3\frac{x + 3}{x} \neq 3xx+3​=3. Seul un facteur commun au numérateur et au dénominateur se simplifie : 3(x+1)5(x+1)=35\frac{3(x + 1)}{5(x + 1)} = \frac{3}{5}5(x+1)3(x+1)​=53​ pour x≠−1x \neq -1x=−1.
  • ab÷cd≠a÷cb÷d\frac{a}{b} \div \frac{c}{d} \neq \frac{a \div c}{b \div d}ba​÷dc​=b÷da÷c​ en pratique : on multiplie par l'inverse de la seconde fraction, ab×dc\frac{a}{b} \times \frac{d}{c}ba​×cd​.
