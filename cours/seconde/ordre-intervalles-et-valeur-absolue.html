Notation des intervalles [a; b], intersection et réunion, encadrements, définition et interprétation géométrique de la valeur absolue |x - a| ≤ r.

Objectifs du chapitre

  • Manipuler la notation des intervalles et les opérations d'intersection ∩\cap∩ et réunion ∪\cup∪.
  • Comprendre la définition de la valeur absolue d'un nombre réel : ∣x∣=x|x| = x∣x∣=x si x≥0x \ge 0x≥0, et ∣x∣=−x|x| = -x∣x∣=−x si x<0x < 0x<0.
  • Interpréter ∣x−a∣|x - a|∣x−a∣ comme la distance géométrique entre xxx et aaa sur la droite numérique.
  • Résoudre des équations et inéquations du type ∣x−a∣=r|x - a| = r∣x−a∣=r et ∣x−a∣≤r|x - a| \le r∣x−a∣≤r.
  • Utiliser les règles de l'ordre (addition, multiplication par un réel positif ou négatif) pour résoudre des inéquations.
  • Comparer deux nombres en étudiant le signe de leur différence.

Le cours

1. Intervalles de R\mathbb{R}R, intersection et réunion

  • Intersection I∩JI \cap JI∩J : ensemble des réels appartenant à la fois à III et à JJJ.
  • Réunion I∪JI \cup JI∪J : ensemble des réels appartenant à au moins l'un des deux intervalles III ou JJJ.

Exemple : Si I=[−3;4]I = [-3 ; 4]I=[−3;4] et J=[1;7[J = [1 ; 7[J=[1;7[, alors :
I∩J=[1;4]etI∪J=[−3;7[I \cap J = [1 ; 4] \quad \text{et} \quad I \cup J = [-3 ; 7[I∩J=[1;4]etI∪J=[−3;7[

  • Inégalités strictes et larges : crochet tourné vers l'extérieur pour exclu (]a;b[]a; b[]a;b[), vers l'intérieur pour inclus ([a;b][a; b][a;b]).

2. Valeur absolue et distance sur la droite numérique

  • Définition : La valeur absolue d'un réel xxx, notée ∣x∣|x|∣x∣, est sa distance à l'origine 000 :

∣x∣={xsi x≥0−xsi x<0|x| = \begin{cases} x & \text{si } x \ge 0 \\ -x & \text{si } x < 0 \end{cases}∣x∣={x−x​si x≥0si x<0​

  • Propriété géométrique : Pour tous réels xxx et aaa, ∣x−a∣|x - a|∣x−a∣ est la distance entre les points d'abscisses xxx et aaa sur la droite graduée.
  • Résolution d'inéquations : Pour r>0r > 0r>0 :

3. Ordre et opérations

Pour tous réels aaa, bbb et ccc :

  • Addition : a<b  ⟺  a+c<b+ca < b \iff a + c < b + ca<b⟺a+c<b+c (on peut ajouter ou soustraire un même nombre).
  • Multiplication par un nombre strictement positif : si c>0c > 0c>0, alors a<b  ⟺  ac<bca < b \iff ac < bca<b⟺ac<bc (le sens est conservé).
  • Multiplication par un nombre strictement négatif : si c<0c < 0c<0, alors a<b  ⟺  ac>bca < b \iff ac > bca<b⟺ac>bc (le sens est inversé).

Exemple : −2x<6  ⟺  x>6−2  ⟺  x>−3-2x < 6 \iff x > \frac{6}{-2} \iff x > -3−2x<6⟺x>−26​⟺x>−3.

4. Comparer deux nombres

  • Par la différence : a≤b  ⟺  b−a≥0a \le b \iff b - a \ge 0a≤b⟺b−a≥0. Pour comparer deux nombres, on étudie le signe de leur différence.

Méthodes et exemples rédigés

Méthode : Résoudre une inéquation avec valeur absolue

Exemple

Résoudre dans R\mathbb{R}R l'inéquation ∣x−3∣≤2|x - 3| \le 2∣x−3∣≤2.

  1. Étape 1 (Interprétation) : On cherche les abscisses xxx dont la distance au centre a=3a = 3a=3 est inférieure ou égale au rayon r=2r = 2r=2.

  2. Étape 2 (Bornes) : La borne inférieure est 3−2=13 - 2 = 13−2=1 et la borne supérieure est 3+2=53 + 2 = 53+2=5.

  3. Étape 3 (Conclusion) : L'ensemble des solutions est l'intervalle S=[1;5]S = [1 ; 5]S=[1;5].

Méthode : Résoudre une inéquation du type ∣x−a∣>r|x - a| > r∣x−a∣>r

Exemple

Résoudre dans R\mathbb{R}R l'inéquation ∣x+1∣>4|x + 1| > 4∣x+1∣>4.

  1. Étape 1 (Interprétation) : ∣x+1∣=∣x−(−1)∣|x + 1| = |x - (-1)|∣x+1∣=∣x−(−1)∣ est la distance entre xxx et −1-1−1. On cherche les réels dont la distance à −1-1−1 est strictement supérieure à 444.

  2. Étape 2 (Bornes) : les réels à distance exactement 444 de −1-1−1 sont −1−4=−5-1 - 4 = -5−1−4=−5 et −1+4=3-1 + 4 = 3−1+4=3.

  3. Étape 3 : les solutions sont à l'extérieur de l'intervalle [−5;3][-5 ; 3][−5;3], bornes exclues car l'inégalité est stricte : x<−5x < -5x<−5 ou x>3x > 3x>3.

  4. Conclusion : S=]−∞;−5[∪]3;+∞[S = ]-\infty ; -5[ \cup ]3 ; +\infty[S=]−∞;−5[∪]3;+∞[. Contrôle : pour x=4x = 4x=4, ∣4+1∣=5>4|4 + 1| = 5 > 4∣4+1∣=5>4.

Méthode : Comparer deux expressions par le signe de leur différence

Exemple

Montrer que pour tout réel xxx, (x+1)2≥2x+1(x + 1)^2 \ge 2x + 1(x+1)2≥2x+1.

  1. Étape 1 : On calcule la différence : (x+1)2−(2x+1)=x2+2x+1−2x−1(x + 1)^2 - (2x + 1) = x^2 + 2x + 1 - 2x - 1(x+1)2−(2x+1)=x2+2x+1−2x−1.

  2. Étape 2 : On réduit : (x+1)2−(2x+1)=x2(x + 1)^2 - (2x + 1) = x^2(x+1)2−(2x+1)=x2.

  3. Étape 3 : Un carré est toujours positif ou nul : x2≥0x^2 \ge 0x2≥0 pour tout réel xxx.

  4. Conclusion : (x+1)2−(2x+1)≥0(x + 1)^2 - (2x + 1) \ge 0(x+1)2−(2x+1)≥0, donc (x+1)2≥2x+1(x + 1)^2 \ge 2x + 1(x+1)2≥2x+1 pour tout réel xxx, avec égalité uniquement pour x=0x = 0x=0.

Méthode : Intersection et réunion d'intervalles définis par des inégalités

Exemple

On pose III l'ensemble des réels xxx tels que −2<x≤5-2 < x \le 5−2<x≤5, JJJ celui des réels tels que x≥3x \ge 3x≥3, et K=]−∞;−4]K = ]-\infty ; -4]K=]−∞;−4]. Déterminer I∩JI \cap JI∩J, I∪JI \cup JI∪J et I∩KI \cap KI∩K.

  2. Étape 2 : On représente III et JJJ sur une même droite graduée. Les réels communs vont de 333 (inclus) à 555 (inclus) : I∩J=[3;5]I \cap J = [3 ; 5]I∩J=[3;5].

  3. Étape 3 : Les réels appartenant à l'un au moins des deux intervalles vont de −2-2−2 (exclu) jusqu'à +∞+\infty+∞ : I∪J=]−2;+∞[I \cup J = ]-2 ; +\infty[I∪J=]−2;+∞[.

Pièges fréquents

  • Pour l'expression ∣x+4∣|x + 4|∣x+4∣, le centre est −4-4−4 car ∣x+4∣=∣x−(−4)∣|x + 4| = |x - (-4)|∣x+4∣=∣x−(−4)∣ !
  • Une valeur absolue est toujours positive ou nulle : l'équation ∣x−2∣=−3|x - 2| = -3∣x−2∣=−3 n'a aucune solution (S=∅S = \emptysetS=∅).
  • Multiplier ou diviser une inégalité par un nombre négatif change son sens : −3x≤12  ⟺  x≥−4-3x \le 12 \iff x \ge -4−3x≤12⟺x≥−4.
  • Le crochet est toujours ouvert en ±∞\pm\infty±∞ : on écrit [2;+∞[[2 ; +\infty[[2;+∞[, jamais [2;+∞][2 ; +\infty][2;+∞].
  • ∣a+b∣≠∣a∣+∣b∣|a + b| \neq |a| + |b|∣a+b∣=∣a∣+∣b∣ en général : ∣3+(−5)∣=2|3 + (-5)| = 2∣3+(−5)∣=2 alors que ∣3∣+∣−5∣=8|3| + |-5| = 8∣3∣+∣−5∣=8.

Exercice 1 Inéquation avec valeur absolue
