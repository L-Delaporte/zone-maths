Seconde · Analyse et Fonctions · 2A1

Notion générale de fonction, ensemble de définition et courbes — cours de seconde

Ensemble de définition, image, antécédent(s), courbe représentative, résolution graphique d'équations f(x) = k et inéquations f(x) < g(x).

Objectifs du chapitre

  • Déterminer l'ensemble de définition d'une fonction numérique.
  • Calculer l'image d'un réel et déterminer algébriquement ou graphiquement ses antécédents.
  • Tracer et exploiter la courbe représentative Cf\mathcal{C}_fCf​ dans un repère.
  • Résoudre graphiquement des équations f(x)=kf(x) = kf(x)=k et inéquations f(x)≤kf(x) \le kf(x)≤k.
  • Savoir qu'une fonction peut être définie par une formule, une courbe, un tableau de valeurs ou un programme Python.
  • Déterminer par le calcul si un point appartient à une courbe et les points d'intersection de deux courbes.

Le cours

1. Définition, image et antécédents

Une fonction fff associe à tout réel xxx de son ensemble de définition Df\mathcal{D}_fDf​ un unique réel noté f(x)f(x)f(x) appelé l'image de xxx.

  • Tout nombre xxx tel que f(x)=yf(x) = yf(x)=y est appelé un antécédent de yyy par fff.
  • Un nombre peut avoir aucun, un ou plusieurs antécédents, mais possède au plus une image.

2. Courbe représentative et résolutions graphiques

La courbe représentative Cf\mathcal{C}_fCf​ est l'ensemble des points M(x;y)M(x ; y)M(x;y) tels que x∈Dfx \in \mathcal{D}_fx∈Df​ et y=f(x)y = f(x)y=f(x).

  • Pour résoudre graphiquement f(x)=kf(x) = kf(x)=k, on trace la droite horizontale y=ky = ky=k et on lit les abscisses des points d'intersection.
  • Pour résoudre f(x)≤g(x)f(x) \le g(x)f(x)≤g(x), on relève les intervalles d'abscisses où la courbe Cf\mathcal{C}_fCf​ est située en dessous de Cg\mathcal{C}_gCg​.

3. Différentes façons de définir une fonction

  • Par une formule : f(x)=x2−3xf(x) = x^2 - 3xf(x)=x2−3x.
  • Par une courbe : on lit les images sur l'axe des ordonnées.
  • Par un tableau de valeurs : on ne connaît alors que quelques images.
  • Par un programme : en Python, def f(x): return x*2 - 3x ; l'appel f(4) renvoie 42−3×4=44^2 - 3 \times 4 = 442−3×4=4.

4. Ensemble de définition : les deux règles de Seconde

  • Quotient : A(x)B(x)\frac{A(x)}{B(x)}B(x)A(x)​ est défini si et seulement si B(x)≠0B(x) \neq 0B(x)=0.

Exemple : f(x)=1x−3f(x) = \frac{1}{x - 3}f(x)=x−31​ a pour ensemble de définition Df=R∖{3}=]−∞;3[∪]3;+∞[\mathcal{D}_f = \mathbb{R} \setminus \{3\} = ]-\infty ; 3[ \cup ]3 ; +\infty[Df​=R∖{3}=]−∞;3[∪]3;+∞[.

  • Racine carrée : A(x)\sqrt{A(x)}A(x)​ est définie si et seulement si A(x)≥0A(x) \ge 0A(x)≥0.

Exemple : g(x)=2x+4g(x) = \sqrt{2x + 4}g(x)=2x+4​ : 2x+4≥0  ⟺  x≥−22x + 4 \ge 0 \iff x \ge -22x+4≥0⟺x≥−2, donc Dg=[−2;+∞[\mathcal{D}_g = [-2 ; +\infty[Dg​=[−2;+∞[.

  • Un polynôme (par exemple x2−3x+1x^2 - 3x + 1x2−3x+1) est défini sur R\mathbb{R}R tout entier.

5. Appartenance d'un point à une courbe

Un point M(a;b)M(a ; b)M(a;b) appartient à la courbe Cf\mathcal{C}_fCf​ si et seulement si a∈Dfa \in \mathcal{D}_fa∈Df​ et f(a)=bf(a) = bf(a)=b.
Exemple avec f(x)=x2−2xf(x) = x^2 - 2xf(x)=x2−2x :

  • A(3;3)A(3 ; 3)A(3;3) : f(3)=9−6=3f(3) = 9 - 6 = 3f(3)=9−6=3, donc A∈CfA \in \mathcal{C}_fA∈Cf​.
  • B(−1;2)B(-1 ; 2)B(−1;2) : f(−1)=1+2=3≠2f(-1) = 1 + 2 = 3 \neq 2f(−1)=1+2=3=2, donc B∉CfB \notin \mathcal{C}_fB∈/Cf​.

Méthodes et exemples rédigés

Méthode : Trouver les antécédents de 0 par le calcul

Exemple

Soit f(x)=x2−9f(x) = x^2 - 9f(x)=x2−9. Déterminer les antécédents de 0 par fff.

  1. Étape 1 : On pose l'équation f(x)=0  ⟺  x2−9=0f(x) = 0 \iff x^2 - 9 = 0f(x)=0⟺x2−9=0.

  2. Étape 2 : On factorise avec l'identité remarquable a2−b2a^2 - b^2a2−b2 : (x−3)(x+3)=0(x - 3)(x + 3) = 0(x−3)(x+3)=0.

  3. Étape 3 : Règle du produit-nul : x−3=0x - 3 = 0x−3=0 ou x+3=0x + 3 = 0x+3=0, donc x=3x = 3x=3 ou x=−3x = -3x=−3. Les antécédents de 0 sont −3-3−3 et 333.

Méthode : Déterminer l'ensemble de définition d'une fonction

Exemple

Déterminer l'ensemble de définition de f(x)=6−2xf(x) = \sqrt{6 - 2x}f(x)=6−2x​ et de g(x)=2x+1x2−4g(x) = \frac{2x + 1}{x^2 - 4}g(x)=x2−42x+1​.

  1. Étape 1 (Racine) : f(x)f(x)f(x) existe si et seulement si 6−2x≥0  ⟺  −2x≥−6  ⟺  x≤36 - 2x \ge 0 \iff -2x \ge -6 \iff x \le 36−2x≥0⟺−2x≥−6⟺x≤3 (division par −2<0-2 < 0−2<0, le sens change).

  2. Étape 2 : donc Df=]−∞;3]\mathcal{D}_f = ]-\infty ; 3]Df​=]−∞;3].

  3. Étape 3 (Quotient) : on cherche les valeurs interdites de ggg : x2−4=0  ⟺  (x−2)(x+2)=0  ⟺  x=2x^2 - 4 = 0 \iff (x - 2)(x + 2) = 0 \iff x = 2x2−4=0⟺(x−2)(x+2)=0⟺x=2 ou x=−2x = -2x=−2.

  4. Conclusion : Df=]−∞;3]\mathcal{D}_f = ]-\infty ; 3]Df​=]−∞;3] et Dg=R∖{−2;2}\mathcal{D}_g = \mathbb{R} \setminus \{-2 ; 2\}Dg​=R∖{−2;2}.

Méthode : Calculer les points d'intersection de deux courbes

Exemple

Soient f(x)=x2+2x−3f(x) = x^2 + 2x - 3f(x)=x2+2x−3 et g(x)=2x+1g(x) = 2x + 1g(x)=2x+1 définies sur R\mathbb{R}R. Déterminer les points d'intersection de Cf\mathcal{C}_fCf​ et Cg\mathcal{C}_gCg​.

  1. Étape 1 : Les abscisses des points d'intersection sont les solutions de f(x)=g(x)f(x) = g(x)f(x)=g(x), soit x2+2x−3=2x+1x^2 + 2x - 3 = 2x + 1x2+2x−3=2x+1.

  2. Étape 2 : On simplifie : x2−4=0  ⟺  (x−2)(x+2)=0  ⟺  x=2x^2 - 4 = 0 \iff (x - 2)(x + 2) = 0 \iff x = 2x2−4=0⟺(x−2)(x+2)=0⟺x=2 ou x=−2x = -2x=−2.

  3. Étape 3 : On calcule les ordonnées : g(2)=5g(2) = 5g(2)=5 et g(−2)=−3g(-2) = -3g(−2)=−3. Contrôle : f(2)=4+4−3=5f(2) = 4 + 4 - 3 = 5f(2)=4+4−3=5 et f(−2)=4−4−3=−3f(-2) = 4 - 4 - 3 = -3f(−2)=4−4−3=−3.

  4. Conclusion : les courbes se coupent aux points (−2;−3)(-2 ; -3)(−2;−3) et (2;5)(2 ; 5)(2;5).

Méthode : Construire un tableau de valeurs avec Python

Exemple

Écrire un programme Python affichant les images des entiers de −2-2−2 à 333 par f(x)=x2−3xf(x) = x^2 - 3xf(x)=x2−3x, puis l'exploiter.

  1. Étape 1 : On définit la fonction : def f(x): return x*2 - 3x.

  2. Étape 2 : On parcourt les entiers avec une boucle : for x in range(-2, 4): print(x, f(x)) (range(-2, 4) donne −2,−1,0,1,2,3-2, -1, 0, 1, 2, 3−2,−1,0,1,2,3).

  3. Étape 3 : Le programme affiche : f(−2)=10f(-2) = 10f(−2)=10, f(−1)=4f(-1) = 4f(−1)=4, f(0)=0f(0) = 0f(0)=0, f(1)=−2f(1) = -2f(1)=−2, f(2)=−2f(2) = -2f(2)=−2, f(3)=0f(3) = 0f(3)=0.

  4. Conclusion : on lit que 000 et 333 sont des antécédents de 000, et que −2-2−2 a (au moins) deux antécédents, 111 et 222.

Pièges fréquents

  • Confusion image / antécédent : l'image se lit sur l'axe des ordonnées (yyy), l'antécédent sur l'axe des abscisses (xxx).
  • Pour l'ensemble de définition, le dénominateur ne doit jamais être nul et l'expression sous une racine carrée doit être ≥0\ge 0≥0.
  • Pour l'image d'un nombre négatif, on met des parenthèses : si f(x)=x2f(x) = x^2f(x)=x2, alors f(−3)=(−3)2=9f(-3) = (-3)^2 = 9f(−3)=(−3)2=9 et non −9-9−9.
  • f(x+1)f(x + 1)f(x+1) n'est pas f(x)+1f(x) + 1f(x)+1 : pour f(x)=x2f(x) = x^2f(x)=x2, f(x+1)=(x+1)2=x2+2x+1f(x + 1) = (x + 1)^2 = x^2 + 2x + 1f(x+1)=(x+1)2=x2+2x+1.
  • Une courbe ne représente une fonction que si toute droite verticale la coupe en au plus un point (chaque xxx a au plus une image) : un cercle n'est pas la courbe d'une fonction.

Questions de révision

Essaie de répondre de tête avant d'afficher la réponse.

Combien d'images un réel xxx peut-il avoir au maximum par une fonction fff ?

Une seule image (par définition même d'une fonction).

Comment résout-on graphiquement l'équation f(x)=2f(x) = 2f(x)=2 ?

On trace la droite horizontale d'équation y=2y = 2y=2 et on lit les abscisses xxx des points d'intersection avec la courbe Cf\mathcal{C}_fCf​.

Le point A(2;5)A(2 ; 5)A(2;5) appartient-il à la courbe de f(x)=3x−1f(x) = 3x - 1f(x)=3x−1 ?

Oui, car f(2)=3×2−1=5f(2) = 3 \times 2 - 1 = 5f(2)=3×2−1=5.

Quel est l'ensemble de définition de x↦x−4x \mapsto \sqrt{x - 4}x↦x−4​ ?

x−4≥0  ⟺  x≥4x - 4 \ge 0 \iff x \ge 4x−4≥0⟺x≥4, donc [4;+∞[[4 ; +\infty[[4;+∞[.

Comment lit-on graphiquement l'image de 333 par fff ?

On repère le point de Cf\mathcal{C}_fCf​ d'abscisse 333 et on lit son ordonnée.

  2. 555
  3. −3-3−3

Bonne réponse : A. 212121

Palier 2 · application

Quels sont les antécédents de 555 par la fonction g(x)=x2+1g(x) = x^2 + 1g(x)=x2+1 ?
