Cours et exercices corrigés de seconde : Algorithmique et programmation : variables, instructions conditionnelles, boucles et fonctions

Variables et types (entier, flottant, chaîne, booléen), affectation, instructions conditionnelles if/elif/else, boucles bornées for et non bornées while, fonctions Python avec paramètres et valeur renvoyée.

Objectifs du chapitre

  • Choisir ou déterminer le type d'une variable : entier (int), flottant (float), chaîne de caractères (str), booléen (bool).
  • Concevoir et exécuter à la main une suite d'affectations en suivant l'évolution des variables.
  • Écrire une instruction conditionnelle if … elif … else à l'aide de conditions et de connecteurs and, or, not.
  • Programmer une boucle bornée (for i in range(…)) et une boucle non bornée (while condition:), et savoir laquelle choisir.
  • Écrire une fonction Python avec un ou plusieurs paramètres et une valeur renvoyée (return), puis l'appeler.
  • Utiliser les opérateurs // (quotient entier), % (reste) et ** (puissance) dans des problèmes mathématiques.

Le cours

1. Variables, types et affectation

Une variable est un nom associé à une valeur stockée en mémoire. L'affectation x = 5 range la valeur 555 dans la variable x (le signe = n'est pas une égalité mathématique : il se lit « prend la valeur »).

  • int : nombre entier (7, -3) ;
  • float : nombre à virgule flottante, écrit avec un point (2.5, 0.1) ;
  • str : chaîne de caractères entre guillemets ("Bonjour") ;
  • bool : booléen, True ou False (résultat d'une comparaison comme 3 < 5).

Opérations utiles : +, -, *, / (division décimale, résultat flottant : 7 / 2 vaut 3,53{,}53,5), // (quotient entier : 7 // 2 vaut 333), % (reste : 7 % 2 vaut 111), (puissance : 2 5 vaut 323232).

a = 7
b = 2
q = a // b    # 3
r = a % b     # 1
print(q, r)   # affiche 3 1

2. Exécuter un programme à la main

Les instructions s'exécutent dans l'ordre, de haut en bas. Chaque affectation utilise les valeurs actuelles des variables : l'ancienne valeur est écrasée.
Pour suivre un programme, on dresse un tableau d'état des variables, ligne après ligne.

a = 3
b = 5
a = a + b     # a vaut 8
b = a - b     # b vaut 3
a = a - b     # a vaut 5

Ce programme échange les valeurs de a et b. On peut aussi écrire a, b = b, a (affectation simultanée) ou utiliser une variable auxiliaire c.

3. Instructions conditionnelles

Une instruction conditionnelle exécute un bloc seulement si une condition est vraie. Les blocs sont délimités par l'indentation (4 espaces) et la ligne de test se termine par :.

if delta > 0:
    nb = 2
elif delta == 0:
    nb = 1
else:
    nb = 0

  • Comparaisons : == (égal), != (différent), <, <=, >, >=.
  • Connecteurs logiques : and (les deux conditions), or (au moins l'une), not (négation).
  • Tester la parité : n % 2 == 0 est vrai si et seulement si nnn est pair.

4. Boucle bornée for

On utilise une boucle bornée quand on connaît à l'avance le nombre de répétitions.

  • range(n) parcourt 0,1,…,n−10, 1, \dots, n - 10,1,…,n−1 (nnn valeurs) ;
  • range(a, b) parcourt a,a+1,…,b−1a, a + 1, \dots, b - 1a,a+1,…,b−1 (la borne bbb est exclue) ;
  • range(a, b, p) avance avec un pas ppp.

Exemple : calcul de 1+2+⋯+1001 + 2 + \dots + 1001+2+⋯+100 avec un accumulateur s.

s = 0
for i in range(1, 101):
    s = s + i
print(s)      # affiche 5050

5. Boucle non bornée while

On utilise une boucle non bornée quand on répète une action tant qu'une condition est vraie, sans connaître à l'avance le nombre de tours (recherche d'un seuil).

capital = 1000
annees = 0
while capital < 2000:
    capital = capital * 1.05
    annees = annees + 1
print(annees)   # affiche 15

La condition est testée avant chaque tour. Il faut s'assurer que la condition finit par devenir fausse, sinon le programme ne s'arrête jamais (boucle infinie).

6. Fonctions

Une fonction regroupe des instructions réutilisables. Elle reçoit des paramètres et renvoie un résultat avec return (l'exécution de la fonction s'arrête alors).

def image(x):
    return 3  x * 2 - 5


def est_multiple(n, d):
    return n % d == 0


print(image(2))            # affiche 7
print(est_multiple(21, 7)) # affiche True

Ne pas confondre return (la fonction renvoie une valeur utilisable dans un calcul) et print (qui affiche seulement une valeur à l'écran).

Méthodes et exemples rédigés

Méthode : Faire tourner un programme à la main

Exemple

Qu'affiche le programme suivant ?

x = 4
y = 1
for k in range(3):
    y = y * x
    x = x - 1
print(y)

  1. Étape 1 (État initial) : x = 4, y = 1. La boucle s'exécute 3 fois (k vaut 0, 1, 2).

  2. Étape 2 (Tour 1) : y = 1 × 4 = 4, puis x = 3.

  3. Étape 3 (Tours 2 et 3) : y = 4 × 3 = 12, x = 2 ; puis y = 12 × 2 = 24, x = 1.

  4. Conclusion : le programme affiche 242424, c'est-à-dire 4×3×24 \times 3 \times 24×3×2.

Méthode : Choisir entre boucle for et boucle while

Exemple

Une population de bactéries double toutes les heures, à partir de 500 bactéries. Écrire un programme donnant le nombre d'heures nécessaires pour dépasser 100 000 bactéries.

  1. Étape 1 (Analyse) : on ne connaît pas à l'avance le nombre d'heures : on choisit une boucle non bornée while.

  2. Étape 2 (Condition) : on continue tant que la population est inférieure ou égale à 100 000 : while p <= 100000:.

  3. Étape 3 (Programme) :

    p = 500
    h = 0
    while p <= 100000:
        p = 2 * p
        h = h + 1
    print(h)

  4. Conclusion : 500×27=64 000500 \times 2^7 = 64\,000500×27=64000 et 500×28=128 000500 \times 2^8 = 128\,000500×28=128000, donc le programme affiche 888 heures.

Méthode : Écrire une fonction avec une instruction conditionnelle

Exemple

Écrire une fonction tarif(age) qui renvoie le prix d'une entrée de cinéma : 5 euros avant 12 ans, 7 euros de 12 à 25 ans inclus, 10 euros ensuite. Que renvoie tarif(25) ?

  1. Étape 1 (Cas) : trois cas qui s'excluent, testés dans l'ordre : if … elif … else.

  2. Étape 2 (Programme) :

    def tarif(age):
        if age < 12:
            return 5
        elif age <= 25:
            return 7
        else:
            return 10

  3. Étape 3 (Appel) : pour age = 25, le test age < 12 est faux, age <= 25 est vrai : la fonction renvoie 777.

  4. Conclusion : tarif(25) vaut 777 ; attention à bien choisir < ou <= selon que la borne est incluse ou non.

Méthode : Utiliser le quotient et le reste

Exemple

Écrire un programme qui convertit une durée de 7 384 secondes en heures, minutes et secondes.

  1. Étape 1 (Heures) : une heure vaut 3 600 s : h = 7384 // 3600 donne 222 et il reste 7384 % 3600, soit 184184184 s.

  2. Étape 2 (Minutes et secondes) : m = 184 // 60 donne 333 et s = 184 % 60 donne 444.

  3. Étape 3 (Programme) :

    t = 7384
    h = t // 3600
    reste = t % 3600
    m = reste // 60
    s = reste % 60
    print(h, m, s)   # affiche 2 3 4

  4. Conclusion : 7 3847\,3847384 s =2= 2=2 h 333 min 444 s, car 2×3600+3×60+4=7 3842 \times 3600 + 3 \times 60 + 4 = 7\,3842×3600+3×60+4=7384.

Pièges fréquents

  • range(1, 10) s'arrête à 999 : la borne de droite est exclue. Pour aller jusqu'à nnn inclus, on écrit range(1, n + 1).
  • Ne pas confondre = (affectation) et == (test d'égalité) : if x = 3: provoque une erreur.
  • En Python, / donne toujours un flottant (6 / 2 vaut 3.0), alors que // donne le quotient entier. Les nombres décimaux s'écrivent avec un point : 2.5 et non 2,5.
  • Dans une boucle while, la condition est celle pour continuer, pas pour s'arrêter : pour s'arrêter dès que u dépasse 100, on écrit while u <= 100:.
  • L'indentation fait partie du langage : une instruction mal indentée change de bloc (et donc le résultat), ou provoque une erreur.

Questions de révision

Essaie de répondre de tête avant d'afficher la réponse.

Quelles valeurs prend i dans for i in range(2, 6): ?

222, 333, 444 et 555 (la borne 666 est exclue).

Que valent 17 // 5 et 17 % 5 ?

333 et 222, car 17=5×3+217 = 5 \times 3 + 217=5×3+2.

Quand utilise-t-on une boucle while plutôt qu'une boucle for ?

Quand on ne connaît pas à l'avance le nombre de répétitions : on répète tant qu'une condition est vraie (recherche de seuil).

Quelle est la différence entre return et print dans une fonction ?

return renvoie une valeur réutilisable (et termine la fonction) ; print se contente de l'afficher à l'écran.

Quel est le type de la valeur de 3 < 5 ?

Un booléen (bool) : ici True.

Comment tester en Python qu'un entier n est pair ?

Avec la condition n % 2 == 0 (le reste de la division par 2 est nul).

Exercices corrigés

Exercice 1 Suivre des affectations

Palier 1 · découverte

Qu'affiche le programme Python suivant ?

a = 5
b = 2
a = a * b
b = a - b
print(a, b)

  1. « 10 8 »
  2. « 10 3 »
  3. « 5 2 »
  4. « 10 2 »
Un indice

Chaque affectation utilise les valeurs actuelles des variables.

Voir la correction

Bonne réponse : A. « 10 8 »

a = 5 × 2 = 10, puis b = a - b = 10 - 2 = 8 (on utilise la nouvelle valeur de a). Le programme affiche « 10 8 ».

Exercice 2 Boucle bornée et accumulateur

Palier 2 · application

Qu'affiche le programme Python suivant ?

s = 0
for i in range(1, 6):
    s = s + 2 * i
print(s)

  1. 303030
  2. 424242
  3. 202020
  4. 151515
Un indice

range(1, 6) parcourt les entiers de 111 à 555.

Voir la correction

Bonne réponse : A. 303030

i prend les valeurs 1,2,3,4,51, 2, 3, 4, 51,2,3,4,5 (la borne 666 est exclue). Donc s=2+4+6+8+10=30s = 2 + 4 + 6 + 8 + 10 = 30s=2+4+6+8+10=30.

Exercice 3 Boucle while et seuil

Palier 3 · approfondissement

Un capital de 500500500 euros augmente de 101010 euros par mois. Le programme ci-dessous détermine au bout de combien de mois il dépasse strictement 600600600 euros. Qu'affiche-t-il ?

c = 500
m = 0
while c <= 600:
    c = c + 10
    m = m + 1
print(m)

  1. 111111
  2. 101010
  3. 121212
  4. 610610610
Un indice

La boucle continue tant que c <= 600.

Voir la correction

Bonne réponse : A. 111111

Après mmm tours, c vaut 500+10m500 + 10m500+10m. Pour m=10m = 10m=10, c = 600 et c <= 600 est encore vrai : on fait un tour de plus. Pour m=11m = 11m=11, c = 610 : la boucle s'arrête. Le programme affiche 111111.

Exercice 4 Fonction booléenne

Palier 4 · défi

On considère la fonction Python suivante.

def mystere(n):
    for d in range(2, n):
        if n % d == 0:
            return False
    return True

Pour un entier n≥2n \ge 2n≥2, que teste cette fonction ?

  1. Si nnn est un nombre premier
  2. Si nnn est un nombre pair
  3. Si nnn est un carré parfait
  4. Si nnn est divisible par tous les entiers de 222 à n−1n - 1n−1
Un indice

n % d == 0 signifie que ddd divise nnn.

Voir la correction

Bonne réponse : A. Si nnn est un nombre premier

La fonction cherche un diviseur de nnn parmi 2,3,…,n−12, 3, \dots, n - 12,3,…,n−1. Si elle en trouve un, elle renvoie False ; sinon elle renvoie True. Elle renvoie donc True exactement lorsque nnn n'a pas d'autre diviseur que 111 et lui-même : elle teste si nnn est premier.
