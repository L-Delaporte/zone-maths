Objectifs du chapitre

  • Comprendre la définition formelle de la croissance et de la décroissance sur un intervalle.
  • Dresser et interpréter un tableau de variations complet.
  • Définir et identifier le maximum et le minimum d'une fonction sur un intervalle.
  • Comparer des images à l'aide du sens de variation sans calcul explicite.
  • Démontrer le sens de variation d'une fonction affine ou de la fonction carré à l'aide de la définition.
  • Exploiter un tableau de variations pour déterminer le nombre de solutions d'une équation f(x)=kf(x) = kf(x)=k.
  • Interpréter le coefficient mmm d'une fonction affine comme un taux d'accroissement.
  • Approcher un extremum ou une longueur de courbe à l'aide d'un algorithme (balayage, dichotomie).
  • Traiter un problème d'optimisation.

Le cours

1. Définitions formelles de la monotonie

Soit fff une fonction définie sur un intervalle III :

  • fff est strictement croissante sur III si pour tous a,b∈Ia, b \in Ia,b∈I :

a<b  ⟹  f(a)<f(b)a < b \implies f(a) < f(b)a<b⟹f(a)<f(b) (la fonction conserve l'ordre).

  • fff est strictement décroissante sur III si pour tous a,b∈Ia, b \in Ia,b∈I :

a<b  ⟹  f(a)>f(b)a < b \implies f(a) > f(b)a<b⟹f(a)>f(b) (la fonction inverse l'ordre).

  • On dit plus largement que fff est croissante sur III si pour tous a,b∈Ia, b \in Ia,b∈I, a<b  ⟹  f(a)≤f(b)a < b \implies f(a) \le f(b)a<b⟹f(a)≤f(b), et décroissante si a<b  ⟹  f(a)≥f(b)a < b \implies f(a) \ge f(b)a<b⟹f(a)≥f(b). Une fonction constante est à la fois croissante et décroissante.

2. Extremums : Maximum et Minimum

Soit fff définie sur III et x0∈Ix_0 \in Ix0​∈I :

  • M=f(x0)M = f(x_0)M=f(x0​) est le maximum de fff sur III si pour tout x∈Ix \in Ix∈I, f(x)≤Mf(x) \le Mf(x)≤M.
  • m=f(x0)m = f(x_0)m=f(x0​) est le minimum de fff sur III si pour tout x∈Ix \in Ix∈I, f(x)≥mf(x) \ge mf(x)≥m.

3. Tableau de variations

Une fonction est monotone sur un intervalle III si elle est soit croissante, soit décroissante sur tout III.
Le tableau de variations résume les intervalles de monotonie :

  • 1re ligne : les valeurs de xxx (bornes de Df\mathcal{D}_fDf​ et abscisses où le sens de variation change) ;
  • 2e ligne : des flèches montantes (croissance) ou descendantes (décroissance), avec les images aux extrémités des flèches.

4. Démonstration : sens de variation d'une fonction affine

Soit f(x)=mx+pf(x) = mx + pf(x)=mx+p définie sur R\mathbb{R}R.

  • Si m>0m > 0m>0, fff est strictement croissante ; si m<0m < 0m<0, fff est strictement décroissante ; si m=0m = 0m=0, fff est constante.

Démonstration : soient deux réels a<ba < ba<b. Alors
f(b)−f(a)=(mb+p)−(ma+p)=m(b−a)f(b) - f(a) = (mb + p) - (ma + p) = m(b - a)f(b)−f(a)=(mb+p)−(ma+p)=m(b−a)
Comme b−a>0b - a > 0b−a>0, f(b)−f(a)f(b) - f(a)f(b)−f(a) a le signe de mmm :

  • si m>0m > 0m>0, f(b)−f(a)>0f(b) - f(a) > 0f(b)−f(a)>0, soit f(a)<f(b)f(a) < f(b)f(a)<f(b) : l'ordre est conservé, fff est strictement croissante ;
  • si m<0m < 0m<0, f(b)−f(a)<0f(b) - f(a) < 0f(b)−f(a)<0, soit f(a)>f(b)f(a) > f(b)f(a)>f(b) : l'ordre est inversé, fff est strictement décroissante ;
  • si m=0m = 0m=0, f(a)=f(b)f(a) = f(b)f(a)=f(b) : fff est constante.

Interprétation de mmm : pour a≠ba \neq ba=b, f(b)−f(a)b−a=m\frac{f(b) - f(a)}{b - a} = mb−af(b)−f(a)​=m. Le coefficient mmm est le taux d'accroissement : quand xxx augmente de 111, f(x)f(x)f(x) varie de mmm. Et p=f(0)p = f(0)p=f(0) est l'ordonnée à l'origine.
Exemple : un forfait téléphonique coûte f(x)=0,2x+15f(x) = 0{,}2x + 15f(x)=0,2x+15 euros pour xxx minutes hors forfait : chaque minute supplémentaire coûte 0,200{,}200,20 €, et 151515 € est le prix de base.

5. Existence d'un extremum

  • Un maximum peut être atteint au sommet d'une flèche montante ou en une borne de l'intervalle : il faut comparer toutes les valeurs « hautes » du tableau.
  • Une fonction n'admet pas toujours de maximum : sur ]0;1[]0 ; 1[]0;1[, la fonction x↦xx \mapsto xx↦x prend des valeurs aussi proches de 111 que l'on veut, sans jamais atteindre 111.
  • En Python, on peut approcher le maximum par balayage :
def maximum(f, a, b, pas):
    M = f(a)
    x = a
    while x <= b:
        if f(x) > M:
            M = f(x)
        x = x + pas
    return M

6. Algorithmes : dichotomie et longueur d'une courbe

  • Approcher un maximum par dichotomie : on suppose fff croissante puis décroissante sur [a;b][a ; b][a;b]. On coupe l'intervalle en son milieu mmm ; si fff augmente encore juste après mmm, le maximum est à droite de mmm, sinon il est à gauche (à un petit pas ddd près). On recommence jusqu'à la précision eee voulue.
def maximum_dicho(f, a, b, e):
    d = e / 10
    while b - a > e:
        m = (a + b) / 2
        if f(m) < f(m + d):
            a = m
        else:
            b = m + d
    return a, b
Avec f(x)=−x2+4x+1f(x) = -x^2 + 4x + 1f(x)=−x2+4x+1 sur [0;5][0 ; 5][0;5] et e=0,01e = 0{,}01e=0,01, on obtient un intervalle d'amplitude inférieure à 0,010{,}010,01 contenant 222 : le maximum est atteint en x=2x = 2x=2 et vaut f(2)=5f(2) = 5f(2)=5.
  • Longueur approchée d'une courbe : on remplace la courbe de fff sur [a;b][a ; b][a;b] par nnn petits segments et on additionne leurs longueurs (formule de la distance dans un repère orthonormé).
from math import sqrt

def longueur(f, a, b, n):
    h = (b - a) / n
    L = 0
    for k in range(n):
        x1 = a + k * h
        x2 = x1 + h
        L = L + sqrt(h  2 + (f(x2) - f(x1))  2)
    return L

Pour la parabole y=x2y = x^2y=x2 entre x=0x = 0x=0 et x=1x = 1x=1 : n=10n = 10n=10 donne environ 1,478 21{,}478\,21,4782 et n=1 000n = 1\,000n=1000 environ 1,478 91{,}478\,91,4789. Plus nnn est grand, meilleure est l'approximation.

7. Un problème d'optimisation

Problème : parmi les rectangles de périmètre 202020 cm, lequel a la plus grande aire ?

  • Si xxx est la longueur d'un côté (0<x<100 < x < 100<x<10), l'autre côté mesure 10−x10 - x10−x et l'aire vaut A(x)=x(10−x)=10x−x2A(x) = x(10 - x) = 10x - x^2A(x)=x(10−x)=10x−x2.
  • On vérifie en développant que A(x)=25−(x−5)2A(x) = 25 - (x - 5)^2A(x)=25−(x−5)2. Comme (x−5)2≥0(x - 5)^2 \ge 0(x−5)2≥0, on a A(x)≤25A(x) \le 25A(x)≤25 pour tout xxx, avec égalité si et seulement si x=5x = 5x=5.
  • Conclusion : l'aire maximale est 252525 cm², obtenue pour le carré de côté 555 cm.

On peut aussi conjecturer ce résultat avec un tableau de valeurs, une courbe (calculatrice, logiciel) ou l'algorithme de balayage du paragraphe 5, puis le démontrer comme ci-dessus.

Méthodes et exemples rédigés

Méthode : Comparer deux images avec le tableau de variations

Exemple

Sachant que fff est strictement décroissante sur [1;5][1 ; 5][1;5], comparer f(2)f(2)f(2) et f(4,5)f(4{,}5)f(4,5).

  1. Étape 1 : On compare les antécédents : 1≤2<4,5≤51 \le 2 < 4{,}5 \le 51≤2<4,5≤5.

  2. Étape 2 : On applique la propriété de décroissance : une fonction décroissante change le sens des inégalités.

  3. Étape 3 : On conclut : f(2)>f(4,5)f(2) > f(4{,}5)f(2)>f(4,5).

Méthode : Démontrer un sens de variation avec la définition

Exemple

Démontrer que la fonction carré f(x)=x2f(x) = x^2f(x)=x2 est strictement croissante sur [0;+∞[[0 ; +\infty[[0;+∞[.

  1. Étape 1 : Soient aaa et bbb deux réels de [0;+∞[[0 ; +\infty[[0;+∞[ tels que a<ba < ba<b. On étudie le signe de f(b)−f(a)f(b) - f(a)f(b)−f(a).

  2. Étape 2 : f(b)−f(a)=b2−a2=(b−a)(b+a)f(b) - f(a) = b^2 - a^2 = (b - a)(b + a)f(b)−f(a)=b2−a2=(b−a)(b+a) (identité remarquable).

  3. Étape 3 : b−a>0b - a > 0b−a>0 car a<ba < ba<b, et b+a>0b + a > 0b+a>0 car a≥0a \ge 0a≥0 et b>a≥0b > a \ge 0b>a≥0. Le produit est donc strictement positif.

  4. Conclusion : f(b)−f(a)>0f(b) - f(a) > 0f(b)−f(a)>0, donc f(a)<f(b)f(a) < f(b)f(a)<f(b) : fff est strictement croissante sur [0;+∞[[0 ; +\infty[[0;+∞[.

Méthode : Exploiter un tableau de variations

Exemple

fff est définie sur [−4;6][-4 ; 6][−4;6] : elle croît de f(−4)=2f(-4) = 2f(−4)=2 à f(−1)=7f(-1) = 7f(−1)=7, décroît jusqu'à f(3)=−2f(3) = -2f(3)=−2, puis croît jusqu'à f(6)=4f(6) = 4f(6)=4 (sa courbe est tracée d'un seul tenant). Déterminer ses extremums et le nombre de solutions de f(x)=0f(x) = 0f(x)=0.

  1. Étape 1 (Maximum) : les valeurs « hautes » sont f(−1)=7f(-1) = 7f(−1)=7 et f(6)=4f(6) = 4f(6)=4. Le maximum de fff sur [−4;6][-4 ; 6][−4;6] est 777, atteint en x=−1x = -1x=−1.

Méthode : Extremums d'une fonction de référence sur un intervalle

Exemple

Déterminer le minimum et le maximum de f(x)=x2f(x) = x^2f(x)=x2 sur l'intervalle [−2;3][-2 ; 3][−2;3].

Méthode : Interpréter les coefficients d'une fonction affine

Exemple

Un réservoir contient 500500500 L d'eau et se vide de 202020 L par minute. On note V(t)V(t)V(t) le volume (en L) au bout de ttt minutes. Exprimer V(t)V(t)V(t), donner son sens de variation et l'instant où le réservoir est vide.

  1. Étape 1 : le volume diminue de 202020 L chaque minute à partir de 500500500 L : V(t)=−20t+500V(t) = -20t + 500V(t)=−20t+500, fonction affine de coefficient m=−20m = -20m=−20 (taux d'accroissement : −20-20−20 L/min) et d'ordonnée à l'origine p=500p = 500p=500 (volume initial).

  2. Étape 2 : m=−20<0m = -20 < 0m=−20<0, donc VVV est strictement décroissante.

  3. Étape 3 : V(t)=0  ⟺  −20t+500=0  ⟺  t=25V(t) = 0 \iff -20t + 500 = 0 \iff t = 25V(t)=0⟺−20t+500=0⟺t=25.

  4. Conclusion : VVV décroît et le réservoir est vide au bout de 252525 minutes ; le modèle n'a de sens que pour t∈[0;25]t \in [0 ; 25]t∈[0;25].

Pièges fréquents

  • Un extremum est une valeur de la fonction (en ordonnée), atteint en un point (en abscisse). Ex: « le maximum est 8, atteint en x=3x = 3x=3 ».
  • Ne pas déduire le signe d'une fonction de ses variations : une fonction croissante peut être négative !
  • On ne peut comparer f(a)f(a)f(a) et f(b)f(b)f(b) grâce au sens de variation que si aaa et bbb appartiennent à un même intervalle où fff est monotone.
  • Le maximum n'est pas forcément au sommet d'une flèche : il peut être atteint à une extrémité de l'intervalle d'étude.
  • « fff est croissante » ne signifie pas « f(x)f(x)f(x) est grand » : x↦x−100x \mapsto x - 100x↦x−100 est croissante et pourtant f(50)=−50<0f(50) = -50 < 0f(50)=−50<0.

Questions de révision

Essaie de répondre de tête avant d'afficher la réponse.

Si fff est strictement décroissante et a<ba < ba<b, que peut-on dire de f(a)f(a)f(a) et f(b)f(b)f(b) ?

f(a)>f(b)f(a) > f(b)f(a)>f(b) (l'ordre est inversé).

Où se lit le maximum d'une fonction dans un tableau de variations ?

Sur la ligne des valeurs de f(x)f(x)f(x) : au sommet d'une flèche montante ou à une extrémité du tableau (il faut comparer ces valeurs).

Quel est le sens de variation de f(x)=−2x+7f(x) = -2x + 7f(x)=−2x+7 sur R\mathbb{R}R ?

Strictement décroissante, car le coefficient directeur m=−2m = -2m=−2 est négatif.

fff est strictement croissante sur [0;10][0 ; 10][0;10]. Comparer f(3)f(3)f(3) et f(7)f(7)f(7).

3<73 < 73<7 et fff conserve l'ordre, donc f(3)<f(7)f(3) < f(7)f(3)<f(7).

Non : x↦xx \mapsto xx↦x sur ]0;1[]0 ; 1[]0;1[ n'a pas de maximum.

Exercice 1 Sens de variation d'une fonction affine

Palier 1 · découverte

Quel est le sens de variation de la fonction affine f(x)=−3x+8f(x) = -3x + 8f(x)=−3x+8 sur R\mathbb{R}R ?

  1. Strictement décroissante
  2. Strictement croissante
  3. Constante
  4. D'abord croissante puis décroissante
Un indice

Le coefficient directeur est m=−3m = -3m=−3.

Voir la correction

Bonne réponse : A. Strictement décroissante

m=−3<0m = -3 < 0m=−3<0, donc la fonction est strictement décroissante sur R\mathbb{R}R.

Exercice 2 Lire un extremum dans un tableau de variations

Palier 2 · application

Une fonction fff est définie sur [−3;5][-3 ; 5][−3;5]. Elle est croissante sur [−3;1][-3 ; 1][−3;1] avec f(−3)=−2f(-3) = -2f(−3)=−2 et f(1)=4f(1) = 4f(1)=4, puis décroissante sur [1;5][1 ; 5][1;5] avec f(5)=0f(5) = 0f(5)=0.
Quel est le maximum de fff sur [−3;5][-3 ; 5][−3;5] ?

  1. 444, atteint en x=1x = 1x=1
  2. 111, atteint en x=4x = 4x=4
  3. 555, atteint en x=0x = 0x=0
  4. 000, atteint en x=5x = 5x=5
Un indice

Dresse le tableau de variations : la fonction « monte » jusqu'en x=1x = 1x=1 puis « descend ».

Voir la correction

Bonne réponse : A. 444, atteint en x=1x = 1x=1

Sur [−3;1][-3 ; 1][−3;1], fff croît de −2-2−2 à 444 ; sur [1;5][1 ; 5][1;5], elle décroît de 444 à 000. Donc pour tout x∈[−3;5]x \in [-3 ; 5]x∈[−3;5], f(x)≤f(1)=4f(x) \le f(1) = 4f(x)≤f(1)=4.
Le maximum de fff est 444, atteint en x=1x = 1x=1 (et le minimum est −2-2−2, atteint en x=−3x = -3x=−3).
Erreur fréquente : confondre le maximum (444, une image) et l'endroit où il est atteint (x=1x = 1x=1).

Exercice 3 Comparer des images grâce au sens de variation

Palier 3 · approfondissement

La fonction fff est strictement décroissante sur [0;10][0 ; 10][0;10]. Sans autre information, comment se comparent f(2,7)f(2{,}7)f(2,7) et f(3,1)f(3{,}1)f(3,1) ?

  1. f(2,7)>f(3,1)f(2{,}7) > f(3{,}1)f(2,7)>f(3,1)
  2. f(2,7)<f(3,1)f(2{,}7) < f(3{,}1)f(2,7)<f(3,1)
  3. f(2,7)=f(3,1)f(2{,}7) = f(3{,}1)f(2,7)=f(3,1)
  4. On ne peut pas les comparer
Un indice

Une fonction strictement décroissante « renverse » l'ordre : si a<ba < ba<b alors f(a)>f(b)f(a) > f(b)f(a)>f(b).

Voir la correction

Bonne réponse : A. f(2,7)>f(3,1)f(2{,}7) > f(3{,}1)f(2,7)>f(3,1)

2,72{,}72,7 et 3,13{,}13,1 appartiennent à [0;10][0 ; 10][0;10], intervalle sur lequel fff est strictement décroissante.

Exercice 4 Maximum d'une fonction écrite sous forme canonique

Palier 4 · défi

On considère la fonction fff définie sur R\mathbb{R}R par f(x)=5−2(x−3)2f(x) = 5 - 2(x - 3)^2f(x)=5−2(x−3)2. Que peut-on affirmer ?

  2. fff admet un maximum égal à 333, atteint en x=5x = 5x=5
  3. fff admet un minimum égal à 555, atteint en x=3x = 3x=3
