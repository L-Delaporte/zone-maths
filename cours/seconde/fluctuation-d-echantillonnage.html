Objectifs du chapitre

  • Comprendre la variabilité d'une fréquence observée d'un échantillon à l'autre.
  • Pour aller plus loin : connaître le critère ∣f−p∣≤1n|f - p| \le \frac{1}{\sqrt{n}}∣f−p∣≤n​1​, vérifié par environ 95 %95\,\%95% des échantillons de taille nnn.
  • Lire et écrire un script Python simulant une expérience aléatoire (module random).
  • Pour aller plus loin : prendre une décision sur une proportion ppp à l'aide d'un échantillon.
  • Simuler NNN échantillons de taille nnn en Python et observer la proportion de ceux pour lesquels ∣f−p∣≤1n|f - p| \le \frac{1}{\sqrt{n}}∣f−p∣≤n​1​.
  • Pour aller plus loin : déterminer une taille d'échantillon permettant d'obtenir une précision donnée.
  • Écrire une fonction Python renvoyant le résultat d'une expérience aléatoire et observer la loi des grands nombres par simulation.

Le cours

1. Échantillon, fréquence et loi des grands nombres

  • Un échantillon de taille nnn est obtenu en répétant nnn fois, de façon indépendante, une même expérience aléatoire à deux issues (succès de probabilité ppp, ou échec).
  • Si kkk est le nombre de succès, la fréquence observée est f=knf = \frac{k}{n}f=nk​.
  • Loi des grands nombres (version vulgarisée) : « lorsque nnn est grand, sauf exception, la fréquence observée est proche de la probabilité ».
  • Le choix d'une loi de probabilité (par exemple l'équiprobabilité pour un dé équilibré) est une hypothèse de modèle : elle ne se démontre pas. Pour un phénomène réel (lancer d'une punaise), on peut construire le modèle à partir des fréquences observées sur un grand nombre d'essais.

2. Algorithmique en Python : simulation d'échantillons

En Python, on utilise la bibliothèque random :

import random


def frequence_pile(n):
    nb_pile = 0
    for i in range(n):
        if random.random() < 0.5:
            nb_pile += 1
    return nb_pile / n

3. Fonction renvoyant un nombre aléatoire et loi des grands nombres

  • randint(a, b) (module random) renvoie un entier aléatoire entre aaa et bbb inclus ; random() renvoie un nombre aléatoire de [0;1[[0 ; 1[[0;1[.
  • En appelant plusieurs fois une telle fonction, on obtient une série statistique dont on peut calculer la fréquence d'une issue :
from random import randint

def lancer_de():
    return randint(1, 6)


def frequence_six(n):
    nb = 0
    for i in range(n):
        if lancer_de() == 6:
            nb = nb + 1
    return nb / n


for n in [10, 100, 10000]:
    print(n, frequence_six(n))

  • Les résultats changent à chaque exécution. Avec n=10n = 10n=10 la fréquence peut être très éloignée de 16≈0,167\frac{1}{6} \approx 0{,}16761​≈0,167 (par exemple 0,30{,}30,3) ; avec n=10 000n = 10\,000n=10000 elle est presque toujours très proche de 0,1670{,}1670,167 : on observe la loi des grands nombres.

4. Pour aller plus loin : fluctuation et critère 1n\frac{1}{\sqrt{n}}n​1​

Ce critère n'est pas un attendu du programme de seconde : le programme demande d'observer la fluctuation d'échantillonnage et la loi des grands nombres par simulation (voir les paragraphes 1 et 3).
Soit ppp la proportion d'un caractère dans une population générale. Lorsqu'on prélève au hasard un échantillon de taille nnn (avec nnn assez grand ; à titre indicatif n≥25n \ge 25n≥25 et 0,2≤p≤0,80{,}2 \le p \le 0{,}80,2≤p≤0,8) :

  • La fréquence observée fff varie d'un échantillon à un autre : c'est la fluctuation d'échantillonnage.
  • L'intervalle de fluctuation à 95% est :

I=[p−1n;p+1n]I = \left[p - \frac{1}{\sqrt{n}} ; p + \frac{1}{\sqrt{n}}\right]I=[p−n​1​;p+n​1​]
Pour nnn assez grand, dans environ 95 % (au moins) des échantillons de taille nnn, la fréquence observée fff appartient à cet intervalle.

5. Pour aller plus loin : écart entre fréquence et probabilité

Dire que f∈[p−1n;p+1n]f \in \left[p - \frac{1}{\sqrt{n}} ; p + \frac{1}{\sqrt{n}}\right]f∈[p−n​1​;p+n​1​] équivaut à dire que la distance entre fff et ppp vérifie :
∣f−p∣≤1n|f - p| \le \frac{1}{\sqrt{n}}∣f−p∣≤n​1​
Résultat admis : pour nnn assez grand, cette inégalité est vérifiée pour environ 95 %95\,\%95% (ou plus) des échantillons de taille nnn.

  • Plus nnn est grand, plus l'intervalle est étroit : la fréquence fluctue moins.

6. Pour aller plus loin : simuler de nombreux échantillons en Python

from random import random
from math import sqrt

def frequence(n, p):
    k = 0
    for i in range(n):
        if random() < p:
            k = k + 1
    return k / n


def proportion_proches(N, n, p):
    c = 0
    for j in range(N):
        if abs(frequence(n, p) - p) <= 1 / sqrt(n):
            c = c + 1
    return c / N

random() renvoie un nombre aléatoire de [0;1[[0 ; 1[[0;1[ : la condition random() < p est réalisée avec la probabilité ppp. L'appel proportion_proches(1000, 100, 0.3) renvoie en général une valeur proche de 0,950{,}950,95 ou au-dessus.

Pour aller plus loin — Méthode : Prendre une décision à l'aide d'un échantillon

Exemple

Une pièce est lancée 100100100 fois et tombe 626262 fois sur pile. Peut-on considérer, au seuil de 95 %95\,\%95%, que la pièce est équilibrée ?

  1. Étape 1 (Proportion théorique) : pour une pièce équilibrée, p=0,5p = 0{,}5p=0,5 (compris entre 0,20{,}20,2 et 0,80{,}80,8) et n=100≥25n = 100 \ge 25n=100≥25 : le critère s'applique.

  2. Étape 2 (Intervalle) : 1100=0,1\frac{1}{\sqrt{100}} = 0{,}1100​1​=0,1, donc I=[0,5−0,1;0,5+0,1]=[0,4;0,6]I = [0{,}5 - 0{,}1 ; 0{,}5 + 0{,}1] = [0{,}4 ; 0{,}6]I=[0,5−0,1;0,5+0,1]=[0,4;0,6].

  3. Étape 3 (Fréquence observée) : f=62100=0,62f = \frac{62}{100} = 0{,}62f=10062​=0,62 et 0,62∉[0,4;0,6]0{,}62 \notin [0{,}4 ; 0{,}6]0,62∈/[0,4;0,6].

  4. Conclusion : on rejette l'hypothèse « la pièce est équilibrée », avec un risque d'erreur d'environ 5 %5\,\%5%. (Avec 555555 piles, f=0,55∈If = 0{,}55 \in If=0,55∈I : on ne pourrait pas rejeter l'hypothèse.)

Pour aller plus loin — Méthode : Vérifier la conformité d'un échantillon

Exemple

Un fabricant affirme que 90 %90\,\%90% de ses ampoules fonctionnent plus de 1000 heures. Sur un échantillon de 400400400 ampoules, 348348348 dépassent 1000 heures. Ce résultat remet-il en cause l'affirmation ?

Pour aller plus loin — Méthode : Déterminer une taille d'échantillon

Exemple

Quelle taille minimale nnn doit avoir un échantillon pour que l'intervalle [p−1n;p+1n]\left[p - \frac{1}{\sqrt{n}} ; p + \frac{1}{\sqrt{n}}\right][p−n​1​;p+n​1​] ait une amplitude inférieure ou égale à 0,040{,}040,04 ?

  1. Étape 1 : L'amplitude de l'intervalle vaut 2n\frac{2}{\sqrt{n}}n​2​. On veut 2n≤0,04\frac{2}{\sqrt{n}} \le 0{,}04n​2​≤0,04.

  2. Étape 2 : Comme n>0\sqrt{n} > 0n​>0, cela équivaut à n≥20,04=50\sqrt{n} \ge \frac{2}{0{,}04} = 50n​≥0,042​=50.

  3. Étape 3 : La fonction carré est croissante sur [0;+∞[[0 ; +\infty[[0;+∞[, donc n≥502=2500n \ge 50^2 = 2500n≥502=2500.

  4. Conclusion : il faut un échantillon d'au moins 250025002500 individus.

Pièges fréquents

  • L'amplitude de l'intervalle est de 2n\frac{2}{\sqrt{n}}n​2​ : pour diviser la marge d'erreur par 2, il faut quadrupler la taille de l'échantillon !
  • Ne pas confondre la proportion théorique ppp (fixe dans la population) et la fréquence observée fff (qui fluctue selon l'échantillon).
  • Une fréquence située dans l'intervalle ne prouve pas que la proportion vaut ppp : on dit seulement que l'échantillon ne permet pas de rejeter cette hypothèse.
  • Même si l'hypothèse est vraie, environ 5 %5\,\%5% des échantillons tombent en dehors de l'intervalle : une décision de rejet comporte donc un risque d'erreur.
  • En Python, randint(1, 6) peut renvoyer 111 comme 666 (bornes incluses), alors que range(1, 6) s'arrête à 555.

Exercices corrigés

Exercice 1 Loi des grands nombres

Palier 1 · découverte

On simule 10 00010\,00010000 lancers d'un dé équilibré et on calcule la fréquence d'apparition du 666. De quelle valeur cette fréquence est-elle très probablement proche ?

  1. 0,1670{,}1670,167
  2. 0,60{,}60,6
  3. 0,50{,}50,5
  4. 0,060{,}060,06
Un indice

Pour un grand nombre de lancers, la fréquence observée est, sauf exception, proche de la probabilité.

Voir la correction

Bonne réponse : A. 0,1670{,}1670,167

D'après la loi des grands nombres (version vulgarisée), pour n=10 000n = 10\,000n=10000 la fréquence observée est très probablement proche de P(6)=16≈0,167P(6) = \frac{1}{6} \approx 0{,}167P(6)=61​≈0,167.

Exercice 2 Simuler une pièce en Python

Palier 2 · application

Avec from random import randint, quelle instruction simule le lancer d'une pièce équilibrée, en codant Pile par 111 et Face par 000 ?

  1. randint(0, 1)
  2. randint(0, 2)
  3. randint(1, 2) / 2
  4. range(0, 1)
Un indice

randint(a, b) renvoie un entier aléatoire entre aaa et bbb, les deux bornes étant incluses.

Voir la correction

Bonne réponse : A. randint(0, 1)

randint(0, 1) renvoie 000 ou 111 avec la même probabilité 12\frac{1}{2}21​. randint(0, 2) a trois issues, randint(1, 2) / 2 renvoie 0,50{,}50,5 ou 111, et range(0, 1) n'est pas un nombre aléatoire.

Exercice 4 Construire un modèle à partir de fréquences

Palier 4 · défi

On lance 5 0005\,0005000 fois une punaise : elle tombe 3 1003\,1003100 fois sur la pointe. Quelle probabilité est-il raisonnable de choisir, dans le modèle, pour l'événement « la punaise tombe sur la pointe » ?

  1. 0,620{,}620,62
  2. 0,50{,}50,5
  3. 0,310{,}310,31
  4. 3 1003\,1003100
Un indice

Pour un phénomène réel, on peut construire le modèle à partir de la fréquence observée sur un grand nombre d'essais.

Voir la correction

Bonne réponse : A. 0,620{,}620,62

La fréquence observée vaut 3 1005 000=0,62\frac{3\,100}{5\,000} = 0{,}6250003100​=0,62. Le nombre d'essais étant grand, on choisit le modèle P(pointe)=0,62P(\text{pointe}) = 0{,}62P(pointe)=0,62. Rien ne justifie l'équiprobabilité (0,50{,}50,5) ; ce choix reste une hypothèse de modèle.
