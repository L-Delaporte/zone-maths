Licence 2 · Calcul Différentiel · L2-15

Calcul différentiel à plusieurs variables, gradient et extremums — cours de L2

Fonctions de R^n dans R^p, dérivées partielles, différentielle comme application linéaire, matrice jacobienne, règle de composition (Chain Rule), gradient ∇f, dérivées secondes et matrice hessienne, recherche d'extremums locaux libres.

Objectifs du chapitre

  • Définir la différentiabilité au sens de Fréchet pour une fonction de plusieurs variables.
  • Calculer le vecteur gradient et la matrice jacobienne.
  • Énoncer et appliquer le Théorème de Schwarz sur la symétrie des dérivées partielles secondes.
  • Déterminer et classifier les points critiques d'une fonction à l'aide de la matrice hessienne.

Le cours

1. Dérivées partielles, différentielle et Gradient

Soit UUU un ouvert de Rn\mathbb{R}^nRn et f:U→Rf : U \to \mathbb{R}f:U→R :

2. Théorème de Schwarz et dérivées d'ordre supérieur

  • Théorème de Schwarz (Symétrie des dérivées croisées) : Si f:U→Rf : U \to \mathbb{R}f:U→R est de classe C2\mathcal{C}^2C2 sur un ouvert UUU, alors pour tous i,j∈{1,…,n}i, j \in \{1, \dots, n\}i,j∈{1,…,n} :

∂2f∂xi∂xj=∂2f∂xj∂xi\frac{\partial^2 f}{\partial x_i \partial x_j} = \frac{\partial^2 f}{\partial x_j \partial x_i}∂xi​∂xj​∂2f​=∂xj​∂xi​∂2f​

  • L'ordre de dérivation par rapport aux variables n'a donc pas d'importance.

4. Classification des extremums locaux

  • Condition nécessaire du premier ordre : Si fff admet un extremum local en a∈Ua \in Ua∈U ouvert, alors aaa est un point critique :

∇f(a)=0⃗\nabla f(a) = \vec{0}∇f(a)=0

  • Condition suffisante du second ordre (via les valeurs propres de Hf(a)H_f(a)Hf​(a)) :

- Si toutes les valeurs propres de Hf(a)H_f(a)Hf​(a) sont strictement positives : aaa est un minimum local strict.
- Si toutes les valeurs propres sont strictement négatives : aaa est un maximum local strict.
- Si Hf(a)H_f(a)Hf​(a) admet des valeurs propres de signes opposés : aaa est un point col (selle) (pas d'extremum).

  • En dimension 2 (n=2n = 2n=2) : En posant r=∂2f∂x2r = \frac{\partial^2 f}{\partial x^2}r=∂x2∂2f​, s=∂2f∂x∂ys = \frac{\partial^2 f}{\partial x \partial y}s=∂x∂y∂2f​, t=∂2f∂y2t = \frac{\partial^2 f}{\partial y^2}t=∂y2∂2f​, le déterminant hessien vaut Δ=rt−s2\Delta = rt - s^2Δ=rt−s2 :

- Δ>0\Delta > 0Δ>0 et r>0  ⟹  r > 0 \impliesr>0⟹ minimum local.
- Δ>0\Delta > 0Δ>0 et r<0  ⟹  r < 0 \impliesr<0⟹ maximum local.
- Δ<0  ⟹  \Delta < 0 \impliesΔ<0⟹ point selle.

Méthode : Trouver et classifier les points critiques en dimension 2

Exemple

Classifier les points critiques de f(x,y)=x3+y3−3xyf(x, y) = x^3 + y^3 - 3xyf(x,y)=x3+y3−3xy.

Pièges fréquents

  • L'existence des dérivées partielles n'implique PAS la continuité de fff (il faut que les dérivées partielles soient continues, c'est-à-dire C1\mathcal{C}^1C1) !
  • Si det⁡Hf(a)=0\det H_f(a) = 0detHf​(a)=0 (ou valeur propre nulle), le test du second ordre est indécis : il faut pousser l'étude locale à un ordre supérieur.

Questions de révision

Essaie de répondre de tête avant d'afficher la réponse.

Que dit le théorème de Schwarz sur les dérivées partielles secondes d'une fonction C^2 ?

Elles sont symétriques : ∂2f∂xi∂xj=∂2f∂xj∂xi\frac{\partial^2 f}{\partial x_i \partial x_j} = \frac{\partial^2 f}{\partial x_j \partial x_i}∂xi​∂xj​∂2f​=∂xj​∂xi​∂2f​.

Quelle condition sur les valeurs propres de la matrice hessienne garantit un minimum local strict en un point critique ?

Toutes ses valeurs propres doivent être strictement positives (matrice définie positive).

Exercice 4 Théorème de Schwarz et symétrie hessienne

Palier 4 · défi

Que garantit le théorème de Schwarz pour une fonction f:U⊂R2→Rf : U \subset \mathbb{R}^2 \to \mathbb{R}f:U⊂R2→R de classe C2\mathcal{C}^2C2 ?

  1. ∂2f∂x∂y=∂2f∂y∂x\frac{\partial^2 f}{\partial x \partial y} = \frac{\partial^2 f}{\partial y \partial x}∂x∂y∂2f​=∂y∂x∂2f​
  2. Δf=0\Delta f = 0Δf=0
  3. ∂f∂x=∂f∂y\frac{\partial f}{\partial x} = \frac{\partial f}{\partial y}∂x∂f​=∂y∂f​
  4. La matrice hessienne est toujours de trace nulle
Un indice

L'ordre des dérivations partielles peut être interverti si la fonction est C2\mathcal{C}^2C2.

Voir la correction

Bonne réponse : A. ∂2f∂x∂y=∂2f∂y∂x\frac{\partial^2 f}{\partial x \partial y} = \frac{\partial^2 f}{\partial y \partial x}∂x∂y∂2f​=∂y∂x∂2f​

Le théorème de Schwarz affirme que pour toute fonction de classe C2\mathcal{C}^2C2, les dérivées partielles croisées sont égales : ∂2f∂x∂y=∂2f∂y∂x\frac{\partial^2 f}{\partial x \partial y} = \frac{\partial^2 f}{\partial y \partial x}∂x∂y∂2f​=∂y∂x∂2f​.
