Cours et exercices corrigés de prépa BCPST : Probabilités et variables aléatoires discrètes

Objectifs du chapitre

  • Calculer des probabilités avec les probabilités conditionnelles, la formule des probabilités totales et la formule de Bayes.
  • Reconnaître des événements ou des variables indépendants.
  • Calculer l'espérance et la variance d'une variable discrète et connaître les lois usuelles.
  • Étudier un couple de variables discrètes : lois marginales, indépendance, covariance.

Le cours

1. Espace probabilisé

Une probabilité sur (Ω,A)(\Omega, \mathcal{A})(Ω,A) vérifie P(Ω)=1P(\Omega) = 1P(Ω)=1 et, pour toute suite (An)(A_n)(An​) d'événements deux à deux incompatibles, P(⋃nAn)=∑nP(An)P\left(\bigcup_n A_n\right) = \sum_n P(A_n)P(⋃n​An​)=∑n​P(An​).
Conséquences : P(A‾)=1−P(A)P(\overline{A}) = 1 - P(A)P(A)=1−P(A) ; si A⊂BA \subset BA⊂B, P(A)≤P(B)P(A) \leq P(B)P(A)≤P(B) ; P(A∪B)=P(A)+P(B)−P(A∩B)P(A \cup B) = P(A) + P(B) - P(A \cap B)P(A∪B)=P(A)+P(B)−P(A∩B).
Continuité monotone : si (An)(A_n)(An​) est croissante, P(⋃nAn)=lim⁡P(An)P\left(\bigcup_n A_n\right) = \lim P(A_n)P(⋃n​An​)=limP(An​) ; si elle est décroissante, P(⋂nAn)=lim⁡P(An)P\left(\bigcap_n A_n\right) = \lim P(A_n)P(⋂n​An​)=limP(An​).
En situation d'équiprobabilité sur Ω\OmegaΩ fini : P(A)=card(A)card(Ω)P(A) = \dfrac{\text{card}(A)}{\text{card}(\Omega)}P(A)=card(Ω)card(A)​.

2. Conditionnement, probabilités totales, Bayes

Si P(B)>0P(B) > 0P(B)>0 : PB(A)=P(A∩B)P(B)P_B(A) = \dfrac{P(A \cap B)}{P(B)}PB​(A)=P(B)P(A∩B)​, et PBP_BPB​ est une probabilité.

  • Probabilités composées : P(A1∩⋯∩An)=P(A1)PA1(A2)⋯PA1∩⋯∩An−1(An)P(A_1 \cap \cdots \cap A_n) = P(A_1)P_{A_1}(A_2) \cdots P_{A_1 \cap \cdots \cap A_{n-1}}(A_n)P(A1​∩⋯∩An​)=P(A1​)PA1​​(A2​)⋯PA1​∩⋯∩An−1​​(An​) (si les conditionnements ont un sens).
  • Probabilités totales : si (Ai)(A_i)(Ai​) est un système complet d'événements de probabilités non nulles, P(B)=∑iP(Ai)PAi(B)P(B) = \sum_i P(A_i)P_{A_i}(B)P(B)=∑i​P(Ai​)PAi​​(B).
  • Formule de Bayes : PB(Aj)=P(Aj)PAj(B)∑iP(Ai)PAi(B)P_B(A_j) = \dfrac{P(A_j)P_{A_j}(B)}{\sum_i P(A_i)P_{A_i}(B)}PB​(Aj​)=∑i​P(Ai​)PAi​​(B)P(Aj​)PAj​​(B)​ ; elle « retourne » un conditionnement.

3. Indépendance

AAA et BBB sont indépendants si P(A∩B)=P(A)P(B)P(A \cap B) = P(A)P(B)P(A∩B)=P(A)P(B) ; si P(B)>0P(B) > 0P(B)>0, cela équivaut à PB(A)=P(A)P_B(A) = P(A)PB​(A)=P(A). Si AAA et BBB sont indépendants, AAA et B‾\overline{B}B le sont aussi.
Des événements A1,…,AnA_1, \ldots, A_nA1​,…,An​ sont mutuellement indépendants si P(⋂i∈JAi)=∏i∈JP(Ai)P\left(\bigcap_{i \in J} A_i\right) = \prod_{i \in J} P(A_i)P(⋂i∈J​Ai​)=∏i∈J​P(Ai​) pour toute partie JJJ : c'est plus fort que l'indépendance deux à deux.
Indépendance et incompatibilité sont des notions différentes : deux événements incompatibles de probabilités non nulles ne sont jamais indépendants.

4. Variables discrètes, espérance et variance

La loi d'une variable discrète XXX est donnée par X(Ω)X(\Omega)X(Ω) et les P(X=x)P(X = x)P(X=x), de somme 111.

  • Espérance : E(X)=∑xxP(X=x)E(X) = \sum_{x} xP(X = x)E(X)=∑x​xP(X=x), si la série converge absolument. Transfert : E(g(X))=∑xg(x)P(X=x)E(g(X)) = \sum_{x} g(x)P(X = x)E(g(X))=∑x​g(x)P(X=x). L'espérance est linéaire et croissante.
  • Variance : V(X)=E((X−E(X))2)=E(X2)−E(X)2V(X) = E\big((X - E(X))^{2}\big) = E(X^{2}) - E(X)^{2}V(X)=E((X−E(X))2)=E(X2)−E(X)2 (formule de Koenig-Huygens) ; σ(X)=V(X)\sigma(X) = \sqrt{V(X)}σ(X)=V(X)​.
  • E(aX+b)=aE(X)+bE(aX + b) = aE(X) + bE(aX+b)=aE(X)+b et V(aX+b)=a2V(X)V(aX + b) = a^{2}V(X)V(aX+b)=a2V(X).

5. Lois usuelles discrètes

  • Uniforme sur [ ⁣[1;n] ⁣][\![1 ; n]\!][[1;n]] : P(X=k)=1nP(X = k) = \frac{1}{n}P(X=k)=n1​, E(X)=n+12E(X) = \frac{n+1}{2}E(X)=2n+1​, V(X)=n2−112V(X) = \frac{n^{2} - 1}{12}V(X)=12n2−1​.
  • Bernoulli B(p)\mathcal{B}(p)B(p) : E(X)=pE(X) = pE(X)=p, V(X)=p(1−p)V(X) = p(1 - p)V(X)=p(1−p).
  • Binomiale B(n,p)\mathcal{B}(n, p)B(n,p), nombre de succès dans nnn épreuves de Bernoulli indépendantes : P(X=k)=(nk)pk(1−p)n−kP(X = k) = \binom{n}{k}p^{k}(1 - p)^{n-k}P(X=k)=(kn​)pk(1−p)n−k, E(X)=npE(X) = npE(X)=np, V(X)=np(1−p)V(X) = np(1 - p)V(X)=np(1−p).
  • Géométrique G(p)\mathcal{G}(p)G(p), rang du premier succès : P(X=k)=(1−p)k−1pP(X = k) = (1 - p)^{k-1}pP(X=k)=(1−p)k−1p pour k≥1k \geq 1k≥1, E(X)=1pE(X) = \frac{1}{p}E(X)=p1​, V(X)=1−pp2V(X) = \frac{1 - p}{p^{2}}V(X)=p21−p​.
  • Poisson P(λ)\mathcal{P}(\lambda)P(λ) : P(X=k)=e−λλkk!P(X = k) = e^{-\lambda}\frac{\lambda^{k}}{k!}P(X=k)=e−λk!λk​ pour k∈Nk \in \mathbb{N}k∈N, E(X)=V(X)=λE(X) = V(X) = \lambdaE(X)=V(X)=λ.

6. Couples de variables et covariance

La loi conjointe de (X,Y)(X, Y)(X,Y) est donnée par les P(X=x,Y=y)P(X = x, Y = y)P(X=x,Y=y) ; les lois marginales s'en déduisent : P(X=x)=∑yP(X=x,Y=y)P(X = x) = \sum_{y} P(X = x, Y = y)P(X=x)=∑y​P(X=x,Y=y).

  • XXX et YYY sont indépendantes si P(X=x,Y=y)=P(X=x)P(Y=y)P(X = x, Y = y) = P(X = x)P(Y = y)P(X=x,Y=y)=P(X=x)P(Y=y) pour tous xxx, yyy ; alors E(XY)=E(X)E(Y)E(XY) = E(X)E(Y)E(XY)=E(X)E(Y).
  • Covariance : Cov(X,Y)=E(XY)−E(X)E(Y)\text{Cov}(X, Y) = E(XY) - E(X)E(Y)Cov(X,Y)=E(XY)−E(X)E(Y), et V(X+Y)=V(X)+V(Y)+2 Cov(X,Y)V(X + Y) = V(X) + V(Y) + 2\,\text{Cov}(X, Y)V(X+Y)=V(X)+V(Y)+2Cov(X,Y).
  • Indépendance ⇒\Rightarrow⇒ covariance nulle, mais la réciproque est fausse.
  • Stabilité : si X∼B(n,p)X \sim \mathcal{B}(n, p)X∼B(n,p) et Y∼B(m,p)Y \sim \mathcal{B}(m, p)Y∼B(m,p) sont indépendantes, X+Y∼B(n+m,p)X + Y \sim \mathcal{B}(n + m, p)X+Y∼B(n+m,p) ; si X∼P(λ)X \sim \mathcal{P}(\lambda)X∼P(λ) et Y∼P(μ)Y \sim \mathcal{P}(\mu)Y∼P(μ) sont indépendantes, X+Y∼P(λ+μ)X + Y \sim \mathcal{P}(\lambda + \mu)X+Y∼P(λ+μ).

Méthodes et exemples rédigés

Méthode : Utiliser la formule de Bayes pour un test de dépistage

Exemple

Une maladie touche 2 % d'un cheptel. Un test est positif chez 95 % des animaux malades et chez 10 % des animaux sains. Un animal a un test positif : quelle est la probabilité qu'il soit malade ?

  1. Étape 1 (Données) : P(M)=0,02P(M) = 0{,}02P(M)=0,02, PM(T)=0,95P_M(T) = 0{,}95PM​(T)=0,95 et PM‾(T)=0,10P_{\overline{M}}(T) = 0{,}10PM​(T)=0,10, où (M,M‾)(M, \overline{M})(M,M) est un système complet.

  2. Étape 2 (Probabilités totales) : P(T)=0,02×0,95+0,98×0,10=0,019+0,098=0,117P(T) = 0{,}02 \times 0{,}95 + 0{,}98 \times 0{,}10 = 0{,}019 + 0{,}098 = 0{,}117P(T)=0,02×0,95+0,98×0,10=0,019+0,098=0,117.

  3. Étape 3 (Bayes) : PT(M)=0,0190,117≈0,16P_T(M) = \dfrac{0{,}019}{0{,}117} \approx 0{,}16PT​(M)=0,1170,019​≈0,16. Malgré un test assez fiable, un positif sur six environ est réellement malade, car la maladie est rare.

Méthode : Calculer l'espérance d'une loi géométrique

Exemple

Soit X∼G(p)X \sim \mathcal{G}(p)X∼G(p) avec 0<p<10 < p < 10<p<1 et q=1−pq = 1 - pq=1−p. Montrer que E(X)=1pE(X) = \frac{1}{p}E(X)=p1​.

  1. Étape 1 (Série) : E(X)=∑k=1+∞kqk−1pE(X) = \sum_{k=1}^{+\infty} kq^{k-1}pE(X)=∑k=1+∞​kqk−1p, série à termes positifs.

  2. Étape 2 (Série de référence) : comme 0≤q<10 \leq q < 10≤q<1, ∑k=1+∞kqk−1=1(1−q)2\sum_{k=1}^{+\infty} kq^{k-1} = \dfrac{1}{(1 - q)^{2}}∑k=1+∞​kqk−1=(1−q)21​ : la série converge.

  3. Étape 3 (Conclure) : E(X)=p(1−q)2=pp2=1pE(X) = \dfrac{p}{(1 - q)^{2}} = \dfrac{p}{p^{2}} = \dfrac{1}{p}E(X)=(1−q)2p​=p2p​=p1​.

Méthode : Étudier un couple à partir de sa loi conjointe

Exemple

XXX et YYY prennent les valeurs 000 et 111, avec P(0,0)=0,4P(0, 0) = 0{,}4P(0,0)=0,4, P(0,1)=0,1P(0, 1) = 0{,}1P(0,1)=0,1, P(1,0)=0,2P(1, 0) = 0{,}2P(1,0)=0,2 et P(1,1)=0,3P(1, 1) = 0{,}3P(1,1)=0,3. Calculer Cov(X,Y)\text{Cov}(X, Y)Cov(X,Y).

  1. Étape 1 (Marginales) : P(X=1)=0,2+0,3=0,5P(X = 1) = 0{,}2 + 0{,}3 = 0{,}5P(X=1)=0,2+0,3=0,5 et P(Y=1)=0,1+0,3=0,4P(Y = 1) = 0{,}1 + 0{,}3 = 0{,}4P(Y=1)=0,1+0,3=0,4, d'où E(X)=0,5E(X) = 0{,}5E(X)=0,5 et E(Y)=0,4E(Y) = 0{,}4E(Y)=0,4.

  2. Étape 2 (Produit) : XYXYXY vaut 111 seulement si X=Y=1X = Y = 1X=Y=1, donc E(XY)=0,3E(XY) = 0{,}3E(XY)=0,3.

  3. Étape 3 (Conclure) : Cov(X,Y)=0,3−0,5×0,4=0,1≠0\text{Cov}(X, Y) = 0{,}3 - 0{,}5 \times 0{,}4 = 0{,}1 \neq 0Cov(X,Y)=0,3−0,5×0,4=0,1=0 : les variables ne sont pas indépendantes.

Méthode : Reconnaître une loi binomiale

Exemple

Deux parents hétérozygotes AaAaAa ont 4 descendants. Chaque descendant est aaaaaa avec probabilité 14\frac{1}{4}41​, indépendamment des autres. Quelle est la probabilité qu'au moins un descendant soit aaaaaa ?

  1. Étape 1 (Modèle) : le nombre XXX de descendants aaaaaa compte les succès de 4 épreuves de Bernoulli indépendantes de paramètre 14\frac{1}{4}41​ : X∼B(4,14)X \sim \mathcal{B}\left(4, \frac{1}{4}\right)X∼B(4,41​).

  2. Étape 2 (Complémentaire) : P(X≥1)=1−P(X=0)=1−(34)4P(X \geq 1) = 1 - P(X = 0) = 1 - \left(\frac{3}{4}\right)^{4}P(X≥1)=1−P(X=0)=1−(43​)4.

  3. Étape 3 (Calcul) : P(X≥1)=1−81256=175256≈0,68P(X \geq 1) = 1 - \frac{81}{256} = \frac{175}{256} \approx 0{,}68P(X≥1)=1−25681​=256175​≈0,68 ; de plus E(X)=4×14=1E(X) = 4 \times \frac{1}{4} = 1E(X)=4×41​=1.

Pièges fréquents

  • Ne confondez pas PA(B)P_A(B)PA​(B) et PB(A)P_B(A)PB​(A) : la formule de Bayes sert justement à passer de l'une à l'autre.
  • Incompatibles ne veut pas dire indépendants : si P(A)>0P(A) > 0P(A)>0, P(B)>0P(B) > 0P(B)>0 et A∩B=∅A \cap B = \emptysetA∩B=∅, alors P(A∩B)=0≠P(A)P(B)P(A \cap B) = 0 \neq P(A)P(B)P(A∩B)=0=P(A)P(B).
  • Pour XXX et YYY indépendantes, V(X−Y)=V(X)+V(Y)V(X - Y) = V(X) + V(Y)V(X−Y)=V(X)+V(Y) : les variances s'additionnent, elles ne se soustraient pas.
  • Une covariance nulle ne prouve pas l'indépendance ; pour prouver la non-indépendance, il suffit d'un couple (x,y)(x, y)(x,y) avec P(X=x,Y=y)≠P(X=x)P(Y=y)P(X = x, Y = y) \neq P(X = x)P(Y = y)P(X=x,Y=y)=P(X=x)P(Y=y).
