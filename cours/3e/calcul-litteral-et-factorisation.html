Recherche de facteur commun évident, facteur commun parenthèse (type Brevet), factorisation par identité remarquable a² - b².

Objectifs du chapitre

  • Comprendre que « Factoriser, c'est transformer une somme ou différence en produit (faire réapparaître des parenthèses) ».
  • Savoir repérer et extraire un facteur commun évident (un nombre, la lettre xxx ou un monôme kxkxkx).
  • Connaître par cœur l'identité remarquable a2−b2=(a−b)(a+b)a^2 - b^2 = (a-b)(a+b)a2−b2=(a−b)(a+b) pour factoriser une différence de deux carrés.
  • Maîtriser la factorisation par facteur commun parenthèse (ax+b)(ax+b)(ax+b) de type Brevet.

Le cours

1. Qu'est-ce que factoriser ? « Faire réapparaître les parenthèses »

  • Factoriser, c'est transformer une somme ou une différence en un produit de facteurs.
  • C'est l'opération inverse du développement.
  • Développé : 6x+156x + 156x+15   ⟺  \iff⟺ Factorisé : 3(2x+5)3(2x + 5)3(2x+5).

2. Méthode 1 : Recherche d'un facteur commun évident

  • Facteur numérique : 12x−8=4×3x−4×2=4(3x−2)12x - 8 = 4 \times 3x - 4 \times 2 = 4(3x - 2)12x−8=4×3x−4×2=4(3x−2).
  • Facteur en xxx : x2+5x=x×x+x×5=x(x+5)x^2 + 5x = x \times x + x \times 5 = x(x + 5)x2+5x=x×x+x×5=x(x+5).
  • Facteur monôme kxkxkx : 15x2−10x=5x×3x−5x×2=5x(3x−2)15x^2 - 10x = 5x \times 3x - 5x \times 2 = 5x(3x - 2)15x2−10x=5x×3x−5x×2=5x(3x−2).
  • Règle d'or du 1 : 7x+7=7(x+1)7x + 7 = 7(x + 1)7x+7=7(x+1) (ne JAMAIS oublier le +1+1+1 !).

3. Méthode 2 : L'identité remarquable a2−b2a^2 - b^2a2−b2 (Différence de deux carrés)

Pour tous nombres aaa et bbb :
a2−b2=(a−b)(a+b)a^2 - b^2 = (a - b)(a + b)a2−b2=(a−b)(a+b)

  • Ex 1 : x2−49=x2−72=(x−7)(x+7)x^2 - 49 = x^2 - 7^2 = (x - 7)(x + 7)x2−49=x2−72=(x−7)(x+7).
  • Ex 2 : 9x2−16=(3x)2−42=(3x−4)(3x+4)9x^2 - 16 = (3x)^2 - 4^2 = (3x - 4)(3x + 4)9x2−16=(3x)2−42=(3x−4)(3x+4).
  • Ex 3 : 4x2−25=(2x)2−52=(2x−5)(2x+5)4x^2 - 25 = (2x)^2 - 5^2 = (2x - 5)(2x + 5)4x2−25=(2x)2−52=(2x−5)(2x+5).

4. Méthode 3 (Brevet) : Facteur commun parenthèse

  • Structure : A=(ax+b)(cx+d)+(ax+b)(ex+f)=(ax+b)[(cx+d)+(ex+f)]A = (ax+b)(cx+d) + (ax+b)(ex+f) = (ax+b)[(cx+d)+(ex+f)]A=(ax+b)(cx+d)+(ax+b)(ex+f)=(ax+b)[(cx+d)+(ex+f)].
  • On souligne le bloc commun (ax+b)(ax+b)(ax+b), on le place devant et on rassemble tout le reste dans des crochets.
  • Attention si le deuxième terme est soustrait : distribuer le signe moins dans les crochets !

À retenir pour le brevet

  • Factoriser, c'est transformer une somme en produit ; c'est l'inverse de développer.
  • On cherche d'abord un facteur commun (un nombre, xxx, ou une parenthèse entière).
  • Sinon, on cherche une différence de deux carrés : a2−b2=(a−b)(a+b)a^2 - b^2 = (a-b)(a+b)a2−b2=(a−b)(a+b).
  • On vérifie toujours une factorisation en la redéveloppant.
  • Factoriser permet de résoudre une équation grâce à la propriété du produit nul.

Automatismes (questions flash) :

  • Factoriser x2−64x^2 - 64x2−64 → (x−8)(x+8)(x-8)(x+8)(x−8)(x+8).
  • Factoriser 6x2+9x6x^2 + 9x6x2+9x → 3x(2x+3)3x(2x+3)3x(2x+3).
  • Factoriser 7x−77x - 77x−7 → 7(x−1)7(x-1)7(x−1).

Méthodes et exemples rédigés

Méthode : Factoriser une expression de Brevet avec facteur commun parenthèse

Exemple

Factoriser F=(2x−3)(4x+1)−(2x−3)(x−2)F = (2x - 3)(4x + 1) - (2x - 3)(x - 2)F=(2x−3)(4x+1)−(2x−3)(x−2).

  1. Étape 1 (Souligner le facteur commun) : (2x−3)(2x - 3)(2x−3) est présent dans les deux blocs.

  2. Étape 2 (Mettre en facteur devant des crochets) : F=(2x−3)[(4x+1)−(x−2)]F = (2x - 3) [ (4x + 1) - (x - 2) ]F=(2x−3)[(4x+1)−(x−2)].

  3. Étape 3 (Supprimer les parenthèses intérieures) : Le signe moins inverse les signes : F=(2x−3)[4x+1−x+2]F = (2x - 3) [ 4x + 1 - x + 2 ]F=(2x−3)[4x+1−x+2].

  4. Étape 4 (Réduire les crochets) : 4x−x=3x4x - x = 3x4x−x=3x et 1+2=31 + 2 = 31+2=3. D'où : F=(2x−3)(3x+3)F = (2x - 3)(3x + 3)F=(2x−3)(3x+3).

  5. Étape 5 (Factorisation maximale) : Comme 3x+3=3(x+1)3x + 3 = 3(x + 1)3x+3=3(x+1), le résultat final est : F=3(2x−3)(x+1)F = 3(2x - 3)(x + 1)F=3(2x−3)(x+1).

Méthode : Factoriser avec a2−b2a^2 - b^2a2−b2 pour résoudre une équation

Exemple

Factoriser E=(2x+1)2−9E = (2x+1)^2 - 9E=(2x+1)2−9, puis résoudre l'équation E=0E = 0E=0.

  1. Étape 1 (Reconnaître une différence de deux carrés) : 9=329 = 3^29=32, donc E=(2x+1)2−32E = (2x+1)^2 - 3^2E=(2x+1)2−32 est de la forme a2−b2a^2 - b^2a2−b2 avec a=2x+1a = 2x+1a=2x+1 et b=3b = 3b=3.

  2. Étape 2 (Appliquer l'identité) : E=(2x+1−3)(2x+1+3)=(2x−2)(2x+4)E = (2x + 1 - 3)(2x + 1 + 3) = (2x - 2)(2x + 4)E=(2x+1−3)(2x+1+3)=(2x−2)(2x+4).

  3. Étape 3 (Factorisation complète, facultative) : 2x−2=2(x−1)2x - 2 = 2(x-1)2x−2=2(x−1) et 2x+4=2(x+2)2x + 4 = 2(x+2)2x+4=2(x+2), donc E=4(x−1)(x+2)E = 4(x-1)(x+2)E=4(x−1)(x+2).

  4. Étape 4 (Équation produit nul) : E=0  ⟺  x−1=0E = 0 \iff x - 1 = 0E=0⟺x−1=0 ou x+2=0  ⟺  x=1x + 2 = 0 \iff x = 1x+2=0⟺x=1 ou x=−2x = -2x=−2.

  5. Étape 5 (Vérification) : pour x=1x = 1x=1 : 32−9=03^2 - 9 = 032−9=0 ; pour x=−2x = -2x=−2 : (−3)2−9=0(-3)^2 - 9 = 0(−3)2−9=0. Les solutions sont −2-2−2 et 111.

Pièges fréquents

  • Oublier le 1 lors de la factorisation : 5x+5=5(x+1)5x + 5 = 5(x + 1)5x+5=5(x+1) et NON 5x5x5x !
  • Confondre a2−b2a^2 - b^2a2−b2 et (a−b)2(a - b)^2(a−b)2 : a2−b2=(a−b)(a+b)a^2 - b^2 = (a-b)(a+b)a2−b2=(a−b)(a+b), alors que (a−b)2=a2−2ab+b2(a-b)^2 = a^2 - 2ab + b^2(a−b)2=a2−2ab+b2.
  • Signe « - » devant la deuxième parenthèse : (x+1)(2x+3)−(x+1)(x−4)=(x+1)[(2x+3)−(x−4)]=(x+1)(2x+3−x+4)=(x+1)(x+7)(x+1)(2x+3) - (x+1)(x-4) = (x+1)[(2x+3) - (x-4)] = (x+1)(2x+3-x+4) = (x+1)(x+7)(x+1)(2x+3)−(x+1)(x−4)=(x+1)[(2x+3)−(x−4)]=(x+1)(2x+3−x+4)=(x+1)(x+7).
  • Une factorisation se vérifie en redéveloppant : 4(x−1)(x+2)=4(x2+x−2)=4x2+4x−84(x-1)(x+2) = 4(x^2 + x - 2) = 4x^2 + 4x - 84(x−1)(x+2)=4(x2+x−2)=4x2+4x−8, qui est bien égal à (2x+1)2−9=4x2+4x+1−9(2x+1)^2 - 9 = 4x^2 + 4x + 1 - 9(2x+1)2−9=4x2+4x+1−9.

Questions de révision

Essaie de répondre de tête avant d'afficher la réponse.

Que signifie « factoriser une expression » ?

C'est transformer une somme ou une différence en un produit de facteurs (« faire réapparaître les parenthèses »).

Quelle est la formule de factorisation de a2−b2a^2 - b^2a2−b2 ?

a2−b2=(a−b)(a+b)a^2 - b^2 = (a - b)(a + b)a2−b2=(a−b)(a+b)

Comment factorise-t-on 9x2−169x^2 - 169x2−16 ?

(3x−4)(3x+4)(car (3x)2−42)(3x - 4)(3x + 4) \quad (\text{car } (3x)^2 - 4^2)(3x−4)(3x+4)(car (3x)2−42)

Quelle est la factorisation de 15x2−10x15x^2 - 10x15x2−10x par son facteur commun maximal ?

5x(3x−2)5x(3x - 2)5x(3x−2)

Que vaut la factorisation de 4x+44x + 44x+4 ?

4(x+1)4(x + 1)4(x+1)
(Attention à ne jamais oublier le +1+1+1 !)

Factoriser x2−64x^2 - 64x2−64.

x2−82=(x−8)(x+8)x^2 - 8^2 = (x-8)(x+8)x2−82=(x−8)(x+8).

Résoudre x2−49=0x^2 - 49 = 0x2−49=0 en factorisant.

(x−7)(x+7)=0(x-7)(x+7) = 0(x−7)(x+7)=0, donc x=7x = 7x=7 ou x=−7x = -7x=−7.

Exercices corrigés

Exercice 1 Facteur commun évident

Palier 1 · découverte

Factoriser au maximum l'expression A=12x−8A = 12x - 8A=12x−8 (mettre en facteur le plus grand facteur commun).

  1. 4(3x−2)4(3x - 2)4(3x−2)
  2. 2(6x−4)2(6x - 4)2(6x−4)
  3. 4(3x+2)4(3x + 2)4(3x+2)
  4. 4x(3−2)4x(3 - 2)4x(3−2)
Un indice

Cherche le plus grand diviseur commun entre 12 et 8.

Voir la correction

Bonne réponse : A. 4(3x−2)4(3x - 2)4(3x−2)

Exact ! 4 est le plus grand diviseur commun de 12 et 8 : 12x=4×3x12x = 4 \times 3x12x=4×3x et 8=4×28 = 4 \times 28=4×2.

A=4×3x−4×2=4(3x−2)A = 4 \times 3x - 4 \times 2 = 4(3x - 2)A=4×3x−4×2=4(3x−2)

Exercice 2 Différence de deux carrés a2−b2a^2 - b^2a2−b2

Palier 2 · application

Factoriser l'expression à l'aide d'une identité remarquable :
B=9x2−25B = 9x^2 - 25B=9x2−25

  1. (3x−5)(3x+5)(3x - 5)(3x + 5)(3x−5)(3x+5)
  2. (3x−5)2(3x - 5)^2(3x−5)2
  3. (9x−5)(9x+5)(9x - 5)(9x + 5)(9x−5)(9x+5)
  4. (3x−25)(3x+25)(3x - 25)(3x + 25)(3x−25)(3x+25)
Un indice

Reconnais la forme a2−b2=(a−b)(a+b)a^2 - b^2 = (a - b)(a + b)a2−b2=(a−b)(a+b) avec a2=9x2a^2 = 9x^2a2=9x2 et b2=25b^2 = 25b2=25.

Voir la correction

Bonne réponse : A. (3x−5)(3x+5)(3x - 5)(3x + 5)(3x−5)(3x+5)

Parfait ! 9x2−25=(3x)2−52=(3x−5)(3x+5)9x^2 - 25 = (3x)^2 - 5^2 = (3x - 5)(3x + 5)9x2−25=(3x)2−52=(3x−5)(3x+5).

B=(3x)2−52=(3x−5)(3x+5)B = (3x)^2 - 5^2 = (3x - 5)(3x + 5)B=(3x)2−52=(3x−5)(3x+5)

Exercice 3 Facteur commun parenthèse (Type Brevet)

Palier 3 · approfondissement

Factoriser l'expression suivante :
C=(2x−3)(x+5)+(2x−3)(3x−1)C = (2x - 3)(x + 5) + (2x - 3)(3x - 1)C=(2x−3)(x+5)+(2x−3)(3x−1)

  1. (2x−3)(4x+4)(2x - 3)(4x + 4)(2x−3)(4x+4) ou 4(2x−3)(x+1)4(2x - 3)(x + 1)4(2x−3)(x+1)
  2. (2x−3)(4x−6)(2x - 3)(4x - 6)(2x−3)(4x−6)
  3. (2x−3)2(4x+4)(2x - 3)^2(4x + 4)(2x−3)2(4x+4)
  4. (2x−3)(2x+6)(2x - 3)(2x + 6)(2x−3)(2x+6)
Un indice

Souligne le facteur commun (2x−3)(2x - 3)(2x−3) présent dans les deux termes, puis ouvre un grand crochet.

Voir la correction

Bonne réponse : A. (2x−3)(4x+4)(2x - 3)(4x + 4)(2x−3)(4x+4) ou 4(2x−3)(x+1)4(2x - 3)(x + 1)4(2x−3)(x+1)

Brillant ! (2x−3)(2x-3)(2x−3) est le facteur commun. On rassemble : [(x+5)+(3x−1)]=[4x+4]=4(x+1)[(x+5) + (3x-1)] = [4x + 4] = 4(x+1)[(x+5)+(3x−1)]=[4x+4]=4(x+1).

C=(2x−3)[(x+5)+(3x−1)]=(2x−3)(x+5+3x−1)=(2x−3)(4x+4)=4(2x−3)(x+1)C = (2x - 3)[ (x + 5) + (3x - 1) ] = (2x - 3)(x + 5 + 3x - 1) = (2x - 3)(4x + 4) = 4(2x - 3)(x + 1)C=(2x−3)[(x+5)+(3x−1)]=(2x−3)(x+5+3x−1)=(2x−3)(4x+4)=4(2x−3)(x+1)

Exercice 4 Défi Seconde : Différence de deux carrés complexe

Palier 4 · défi

Factoriser complètement l'expression :
D=(2x−3)2−25D = (2x - 3)^2 - 25D=(2x−3)2−25

  1. (2x−8)(2x+2)(2x - 8)(2x + 2)(2x−8)(2x+2) ou 4(x−4)(x+1)4(x - 4)(x + 1)4(x−4)(x+1)
  2. (2x−28)(2x+22)(2x - 28)(2x + 22)(2x−28)(2x+22)
  3. (2x−8)2(2x - 8)^2(2x−8)2
  4. 4x2−12x−164x^2 - 12x - 164x2−12x−16
Un indice

Reconnais la structure a2−b2=(a−b)(a+b)a^2 - b^2 = (a-b)(a+b)a2−b2=(a−b)(a+b), sachant que 25=5225 = 5^225=52.

Voir la correction

Bonne réponse : A. (2x−8)(2x+2)(2x - 8)(2x + 2)(2x−8)(2x+2) ou 4(x−4)(x+1)4(x - 4)(x + 1)4(x−4)(x+1)

Brillant ! C'est la forme a2−b2=(a−b)(a+b)a^2 - b^2 = (a-b)(a+b)a2−b2=(a−b)(a+b) avec a=(2x−3)a = (2x-3)a=(2x−3) et b=5b = 5b=5.

D=(2x−3)2−52=[(2x−3)−5][(2x−3)+5]=(2x−8)(2x+2)=4(x−4)(x+1)D = (2x - 3)^2 - 5^2 = [ (2x - 3) - 5 ][ (2x - 3) + 5 ] = (2x - 8)(2x + 2) = 4(x - 4)(x + 1)D=(2x−3)2−52=[(2x−3)−5][(2x−3)+5]=(2x−8)(2x+2)=4(x−4)(x+1)
