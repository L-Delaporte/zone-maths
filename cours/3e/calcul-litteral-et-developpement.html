Cours et exercices corrigés de 3e : Calcul littéral et développement

Distributivité simple et double, les 3 identités remarquables en développement, suppressions de parenthèses et réductions.

Objectifs du chapitre

  • Maîtriser la distributivité simple k(a+b)=ka+kbk(a+b) = ka+kbk(a+b)=ka+kb et la double distributivité (a+b)(c+d)=ac+ad+bc+bd(a+b)(c+d) = ac+ad+bc+bd(a+b)(c+d)=ac+ad+bc+bd.
  • Comprendre que « Développer, c'est transformer un produit en somme algébrique (perdre les parenthèses) ».
  • Connaître par cœur et savoir appliquer les 3 identités remarquables pour développer.
  • Savoir supprimer des parenthèses précédées d'un signe +++ ou d'un signe −-− et réduire une expression.

Le cours

1. Distributivité simple et double : « Perdre les parenthèses »

  • Développer, c'est transformer un produit en somme ou différence (perdre les parenthèses).
  • Simple distributivité : k(a+b)=ka+kbk(a + b) = ka + kbk(a+b)=ka+kb et k(a−b)=ka−kbk(a - b) = ka - kbk(a−b)=ka−kb
  • Double distributivité : (a+b)(c+d)=ac+ad+bc+bd(a + b)(c + d) = ac + ad + bc + bd(a+b)(c+d)=ac+ad+bc+bd
  • Règle des signes en produit : (+)×(+)=+(+) \times (+) = +(+)×(+)=+ ; (−)×(−)=+(-) \times (-) = +(−)×(−)=+ ; (+)×(−)=−(+) \times (-) = -(+)×(−)=−.

2. Les 3 identités remarquables (Formules de développement du Brevet)

Pour tous nombres réels aaa et bbb :
1. Carré d'une somme : (a+b)2=a2+2ab+b2(a + b)^2 = a^2 + 2ab + b^2(a+b)2=a2+2ab+b2
2. Carré d'une différence : (a−b)2=a2−2ab+b2(a - b)^2 = a^2 - 2ab + b^2(a−b)2=a2−2ab+b2
3. Produit de la somme par la différence : (a−b)(a+b)=a2−b2(a - b)(a + b) = a^2 - b^2(a−b)(a+b)=a2−b2
Attention : ne jamais oublier le double produit 2ab2ab2ab !

3. Suppression de parenthèses précédées de + ou -

  • Précédées de +++ : on retire les parenthèses sans rien modifier : A+(B−C)=A+B−CA + (B - C) = A + B - CA+(B−C)=A+B−C.
  • Précédées de −-− : on change TOUS les signes intérieurs : A−(B−C)=A−B+CA - (B - C) = A - B + CA−(B−C)=A−B+C.
  • Si un produit est précédé d'un signe −-− : développer d'abord le produit à l'intérieur de crochets protecteurs, puis distribuer le signe moins !

4. Réduction et simplification d'expressions littérales

  • Réduire, c'est regrouper les termes de même nature : les termes en x2x^2x2 ensemble, les termes en xxx ensemble, et les constantes ensemble.
  • Exemple : 3x2+5x−7+2x2−8x+4=(3+2)x2+(5−8)x+(−7+4)=5x2−3x−33x^2 + 5x - 7 + 2x^2 - 8x + 4 = (3+2)x^2 + (5-8)x + (-7+4) = 5x^2 - 3x - 33x2+5x−7+2x2−8x+4=(3+2)x2+(5−8)x+(−7+4)=5x2−3x−3.

À retenir pour le brevet

  • Développer, c'est transformer un produit en somme : k(a+b)=ka+kbk(a+b) = ka + kbk(a+b)=ka+kb et (a+b)(c+d)=ac+ad+bc+bd(a+b)(c+d) = ac + ad + bc + bd(a+b)(c+d)=ac+ad+bc+bd.
  • Les trois identités remarquables : (a+b)2=a2+2ab+b2(a+b)^2 = a^2 + 2ab + b^2(a+b)2=a2+2ab+b2, (a−b)2=a2−2ab+b2(a-b)^2 = a^2 - 2ab + b^2(a−b)2=a2−2ab+b2, (a−b)(a+b)=a2−b2(a-b)(a+b) = a^2 - b^2(a−b)(a+b)=a2−b2.
  • Un signe moins devant un produit : on développe d'abord le produit entre crochets, puis on change tous les signes.
  • Pour prouver qu'une égalité est vraie pour tout xxx, on développe ; un seul contre-exemple suffit pour prouver qu'elle est fausse.

Automatismes (questions flash) :

  • Développer (x+4)2(x+4)^2(x+4)2 → x2+8x+16x^2 + 8x + 16x2+8x+16.
  • Calculer 99299^2992 de tête → (100−1)2=10 000−200+1=9 801(100-1)^2 = 10\,000 - 200 + 1 = 9\,801(100−1)2=10000−200+1=9801.
  • Calculer 49×5149 \times 5149×51 de tête → (50−1)(50+1)=2 500−1=2 499(50-1)(50+1) = 2\,500 - 1 = 2\,499(50−1)(50+1)=2500−1=2499.

Méthodes et exemples rédigés

Méthode : Développer une expression complexe avec crochets protecteurs

Exemple

Développer et réduire E=(3x−2)2−(2x+1)(x−4)E = (3x - 2)^2 - (2x + 1)(x - 4)E=(3x−2)2−(2x+1)(x−4).

  1. Étape 1 (Identité remarquable) : (3x−2)2=(3x)2−2×3x×2+22=9x2−12x+4(3x - 2)^2 = (3x)^2 - 2 \times 3x \times 2 + 2^2 = 9x^2 - 12x + 4(3x−2)2=(3x)2−2×3x×2+22=9x2−12x+4.

  2. Étape 2 (Double distributivité entre crochets) : (2x+1)(x−4)=[2x2−8x+x−4]=[2x2−7x−4](2x + 1)(x - 4) = [ 2x^2 - 8x + x - 4 ] = [ 2x^2 - 7x - 4 ](2x+1)(x−4)=[2x2−8x+x−4]=[2x2−7x−4].

  3. Étape 3 (Distribuer le signe moins) : E=(9x2−12x+4)−[2x2−7x−4]=9x2−12x+4−2x2+7x+4E = (9x^2 - 12x + 4) - [ 2x^2 - 7x - 4 ] = 9x^2 - 12x + 4 - 2x^2 + 7x + 4E=(9x2−12x+4)−[2x2−7x−4]=9x2−12x+4−2x2+7x+4.

  4. Étape 4 (Réduction finale) : E=(9−2)x2+(−12+7)x+(4+4)=7x2−5x+8E = (9 - 2)x^2 + (-12 + 7)x + (4 + 4) = 7x^2 - 5x + 8E=(9−2)x2+(−12+7)x+(4+4)=7x2−5x+8.

Méthode : Démontrer une égalité « pour tout nombre xxx »

Exemple

Démontrer que, pour tout nombre xxx, (x+3)2−(x−3)2=12x(x+3)^2 - (x-3)^2 = 12x(x+3)2−(x−3)2=12x. En déduire la valeur de 1032−972103^2 - 97^21032−972 sans calculatrice.

  1. Étape 1 (Développer le premier carré) : (x+3)2=x2+2×x×3+32=x2+6x+9(x+3)^2 = x^2 + 2 \times x \times 3 + 3^2 = x^2 + 6x + 9(x+3)2=x2+2×x×3+32=x2+6x+9.

  2. Étape 2 (Développer le second carré) : (x−3)2=x2−6x+9(x-3)^2 = x^2 - 6x + 9(x−3)2=x2−6x+9.

  3. Étape 3 (Soustraire en gardant les parenthèses) :
    (x2+6x+9)−(x2−6x+9)=x2+6x+9−x2+6x−9=12x(x^2 + 6x + 9) - (x^2 - 6x + 9) = x^2 + 6x + 9 - x^2 + 6x - 9 = 12x(x2+6x+9)−(x2−6x+9)=x2+6x+9−x2+6x−9=12x.
    L'égalité est donc vraie pour tout nombre xxx.

  4. Étape 4 (Application) : avec x=100x = 100x=100, on a x+3=103x + 3 = 103x+3=103 et x−3=97x - 3 = 97x−3=97, donc 1032−972=12×100=1 200103^2 - 97^2 = 12 \times 100 = 1\,2001032−972=12×100=1200.
    (Contrôle : 10 609−9 409=1 20010\,609 - 9\,409 = 1\,20010609−9409=1200.)

Pièges fréquents

  • Oublier le double produit 2ab2ab2ab : (a+b)2≠a2+b2(a+b)^2 \neq a^2 + b^2(a+b)2=a2+b2 ! (x+3)2=x2+6x+9(x+3)^2 = x^2 + 6x + 9(x+3)2=x2+6x+9.
  • Dans (2x)2(2x)^2(2x)2, oublier d'élever le 2 au carré : (2x)2=4x2(2x)^2 = 4x^2(2x)2=4x2 et NON 2x22x^22x2 !
  • Attention au signe −-− devant un produit : A−(x−1)(x+2)=A−[x2+x−2]=A−x2−x+2A - (x-1)(x+2) = A - [x^2 + x - 2] = A - x^2 - x + 2A−(x−1)(x+2)=A−[x2+x−2]=A−x2−x+2.
  • Tester quelques valeurs ne prouve pas qu'une égalité est vraie pour tout xxx : il faut développer. En revanche, un seul contre-exemple suffit à prouver qu'elle est fausse.

Questions de révision

Essaie de répondre de tête avant d'afficher la réponse.

Quelle est la formule développée de (a+b)2(a + b)^2(a+b)2 ?

(a+b)2=a2+2ab+b2(a + b)^2 = a^2 + 2ab + b^2(a+b)2=a2+2ab+b2
(Ne jamais oublier le double produit 2ab2ab2ab !)

Quelle est la formule développée de (a−b)(a+b)(a - b)(a + b)(a−b)(a+b) ?

(a−b)(a+b)=a2−b2(a - b)(a + b) = a^2 - b^2(a−b)(a+b)=a2−b2

Que donne le développement de (2x−3)2(2x - 3)^2(2x−3)2 ?

(2x)2−2×2x×3+32=4x2−12x+9(2x)^2 - 2 \times 2x \times 3 + 3^2 = 4x^2 - 12x + 9(2x)2−2×2x×3+32=4x2−12x+9

Que signifie « développer une expression » ?

C'est transformer un produit en une somme algébrique (« perdre les parenthèses »).

Que donne le développement de (x−5)2(x - 5)^2(x−5)2 ?

x2−10x+25x^2 - 10x + 25x2−10x+25

Développer 3x(2x−5)3x(2x - 5)3x(2x−5).

3x×2x−3x×5=6x2−15x3x \times 2x - 3x \times 5 = 6x^2 - 15x3x×2x−3x×5=6x2−15x.

Calculer 49×5149 \times 5149×51 sans calculatrice.

(50−1)(50+1)=502−12=2 500−1=2 499(50-1)(50+1) = 50^2 - 1^2 = 2\,500 - 1 = 2\,499(50−1)(50+1)=502−12=2500−1=2499.

Exercices corrigés

Exercice 1 Simple distributivité

Palier 1 · découverte

Développer et réduire l'expression :
A=4(3x−5)A = 4(3x - 5)A=4(3x−5)

  1. 12x−2012x - 2012x−20
  2. 12x−512x - 512x−5
  3. 7x−207x - 207x−20
  4. 12x+2012x + 2012x+20
Un indice

Distribue le 444 sur chacun des deux termes dans la parenthèse : k(a−b)=ka−kbk(a - b) = ka - kbk(a−b)=ka−kb.

Voir la correction

Bonne réponse : A. 12x−2012x - 2012x−20

Parfait ! 4×3x=12x4 \times 3x = 12x4×3x=12x et 4×(−5)=−204 \times (-5) = -204×(−5)=−20.

A=4×3x+4×(−5)=12x−20A = 4 \times 3x + 4 \times (-5) = 12x - 20A=4×3x+4×(−5)=12x−20

Exercice 2 Double distributivité avec soustraction

Palier 2 · application

Développer et réduire au maximum :
D=(2x+1)(3x−4)D = (2x + 1)(3x - 4)D=(2x+1)(3x−4)

  1. 6x2−5x−46x^2 - 5x - 46x2−5x−4
  2. 6x2+5x−46x^2 + 5x - 46x2+5x−4
  3. 6x2−46x^2 - 46x2−4
  4. 5x2−5x−45x^2 - 5x - 45x2−5x−4
Un indice

Applique (a+b)(c+d)=ac+ad+bc+bd(a+b)(c+d) = ac + ad + bc + bd(a+b)(c+d)=ac+ad+bc+bd. Attention aux signes !

Voir la correction

Bonne réponse : A. 6x2−5x−46x^2 - 5x - 46x2−5x−4

Exact ! 2x×3x=6x22x \times 3x = 6x^22x×3x=6x2, 2x×(−4)=−8x2x \times (-4) = -8x2x×(−4)=−8x, 1×3x=3x1 \times 3x = 3x1×3x=3x, −8x+3x=−5x-8x + 3x = -5x−8x+3x=−5x, et 1×(−4)=−41 \times (-4) = -41×(−4)=−4.

D=2x×3x+2x×(−4)+1×3x+1×(−4)=6x2−8x+3x−4=6x2−5x−4D = 2x \times 3x + 2x \times (-4) + 1 \times 3x + 1 \times (-4) = 6x^2 - 8x + 3x - 4 = 6x^2 - 5x - 4D=2x×3x+2x×(−4)+1×3x+1×(−4)=6x2−8x+3x−4=6x2−5x−4

Exercice 3 Développer une expression avec parenthèses précédées de (-) (Brevet)

Palier 3 · approfondissement

On considère l'expression F=(2x+3)2−(x−1)(2x+3)F = (2x + 3)^2 - (x - 1)(2x + 3)F=(2x+3)2−(x−1)(2x+3).
Développer et réduire FFF. Quel coefficient obtient-on devant x2x^2x2 ?

Un indice

Développe (2x+3)2(2x+3)^2(2x+3)2 avec l'identité remarquable, et développe (x−1)(2x+3)(x-1)(2x+3)(x−1)(2x+3) entre crochets pour ne pas te tromper avec le signe moins.

Voir la correction

Réponse attendue : 2

1. Développons (2x+3)2=4x2+12x+9(2x+3)^2 = 4x^2 + 12x + 9(2x+3)2=4x2+12x+9.
2. Développons le produit : (x−1)(2x+3)=2x2+3x−2x−3=2x2+x−3(x - 1)(2x + 3) = 2x^2 + 3x - 2x - 3 = 2x^2 + x - 3(x−1)(2x+3)=2x2+3x−2x−3=2x2+x−3.
3. Soustraction en changeant les signes :
F=(4x2+12x+9)−(2x2+x−3)=4x2+12x+9−2x2−x+3=2x2+11x+12F = (4x^2 + 12x + 9) - (2x^2 + x - 3) = 4x^2 + 12x + 9 - 2x^2 - x + 3 = 2x^2 + 11x + 12F=(4x2+12x+9)−(2x2+x−3)=4x2+12x+9−2x2−x+3=2x2+11x+12
Le coefficient devant x2x^2x2 est donc bien 222.

Exercice 4 Défi Seconde : Enchaînement de développements complexes

Palier 4 · défi

Développer et réduire au maximum l'expression suivante :
G=(3x+2)2−(2x−1)(3x+2)G = (3x + 2)^2 - (2x - 1)(3x + 2)G=(3x+2)2−(2x−1)(3x+2)

  1. 3x2+11x+63x^2 + 11x + 63x2+11x+6
  2. 3x2+13x+63x^2 + 13x + 63x2+13x+6
  3. 3x2+11x+23x^2 + 11x + 23x2+11x+2
  4. 9x2+11x+69x^2 + 11x + 69x2+11x+6
Un indice

Développe (3x+2)2(3x+2)^2(3x+2)2 d'un côté, et développe le produit (2x−1)(3x+2)(2x-1)(3x+2)(2x−1)(3x+2) entre crochets, puis distribue le signe moins.

Voir la correction

Bonne réponse : A. 3x2+11x+63x^2 + 11x + 63x2+11x+6

Brillant ! (3x+2)2=9x2+12x+4(3x+2)^2 = 9x^2 + 12x + 4(3x+2)2=9x2+12x+4 et (2x−1)(3x+2)=6x2+x−2(2x-1)(3x+2) = 6x^2 + x - 2(2x−1)(3x+2)=6x2+x−2. En soustrayant : (9−6)x2+(12−1)x+(4−(−2))=3x2+11x+6(9-6)x^2 + (12-1)x + (4-(-2)) = 3x^2 + 11x + 6(9−6)x2+(12−1)x+(4−(−2))=3x2+11x+6.

1. Premier carré : (3x+2)2=9x2+12x+4(3x + 2)^2 = 9x^2 + 12x + 4(3x+2)2=9x2+12x+4
2. Second produit entre crochets :
(2x−1)(3x+2)=[6x2+4x−3x−2]=[6x2+x−2](2x - 1)(3x + 2) = [ 6x^2 + 4x - 3x - 2 ] = [ 6x^2 + x - 2 ](2x−1)(3x+2)=[6x2+4x−3x−2]=[6x2+x−2]
3. Soustraction en inversant les signes :
G=(9x2+12x+4)−[6x2+x−2]=9x2+12x+4−6x2−x+2=3x2+11x+6G = (9x^2 + 12x + 4) - [ 6x^2 + x - 2 ] = 9x^2 + 12x + 4 - 6x^2 - x + 2 = 3x^2 + 11x + 6G=(9x2+12x+4)−[6x2+x−2]=9x2+12x+4−6x2−x+2=3x2+11x+6
