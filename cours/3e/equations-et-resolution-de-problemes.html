Objectifs du chapitre

  • Résoudre une équation linéaire du premier degré ax+b=cx+dax + b = cx + dax+b=cx+d.
  • Énoncer et appliquer le théorème de l'équation produit-nul (ax+b)(cx+d)=0(ax + b)(cx + d) = 0(ax+b)(cx+d)=0.
  • Résoudre les équations du type x2=ax^2 = ax2=a selon le signe de aaa.
  • Complément (utile en seconde) : résoudre une inéquation du premier degré en changeant le sens quand on multiplie ou divise par un nombre négatif.
  • Mettre un problème en équation et conclure.

Le cours

1. Résolution d'équation du premier degré : ax + b = cx + d

  • On regroupe les termes en xxx d'un côté (en changeant de signe le terme déplacé) et les nombres de l'autre côté :

ax−cx=d−b  ⟹  (a−c)x=d−bax - cx = d - b \implies (a - c)x = d - bax−cx=d−b⟹(a−c)x=d−b

  • On isole xxx en divisant par le coefficient devant xxx : x=d−ba−cx = \frac{d - b}{a - c}x=a−cd−b​.
  • On vérifie toujours sa solution en la réinjectant dans l'équation d'origine.

2. Théorème de l'équation produit-nul

Propriété d'or du cours : « Si un produit de facteurs est nul, alors l'un au moins de ses facteurs est nul » :
(ax+b)(cx+d)=0  ⟺  ax+b=0oucx+d=0(ax + b)(cx + d) = 0 \iff ax + b = 0 \quad \text{ou} \quad cx + d = 0(ax+b)(cx+d)=0⟺ax+b=0oucx+d=0
L'équation admet alors au maximum deux solutions distinctes : x=−bax = -\frac{b}{a}x=−ab​ ou x=−dcx = -\frac{d}{c}x=−cd​.

3. Équations du type x2=ax^2 = ax2=a

Selon le signe du nombre réel aaa :

  • Si a>0a > 0a>0 : l'équation admet DEUX solutions : x=ax = \sqrt{a}x=a​ ou x=−ax = -\sqrt{a}x=−a​.
  • Si a=0a = 0a=0 : l'équation admet UNE unique solution : x=0x = 0x=0.
  • Si a<0a < 0a<0 : l'équation n'admet AUCUNE solution réelle (car un carré est toujours positif ou nul).

4. Complément (utile en seconde) : inéquations et changement de sens

Les inéquations ne figurent plus au programme du collège ; ce paragraphe prépare la seconde.
On résout une inéquation comme une équation, avec une règle capitale :
quand on multiplie ou divise les deux membres par un nombre strictement négatif, on change le sens de l'inégalité :
−3x≤12  ⟺  x≥12−3  ⟺  x≥−4-3x \le 12 \iff x \ge \frac{12}{-3} \iff x \ge -4−3x≤12⟺x≥−312​⟺x≥−4
Les solutions forment un intervalle : ici [−4;+∞[[-4 ; +\infty[[−4;+∞[.

À retenir pour le brevet

  • Pour résoudre ax+b=cx+dax + b = cx + dax+b=cx+d : regrouper les xxx d'un côté, les nombres de l'autre, puis diviser par le coefficient de xxx.
  • Produit nul : A×B=0  ⟺  A=0A \times B = 0 \iff A = 0A×B=0⟺A=0 ou B=0B = 0B=0.
  • x2=ax^2 = ax2=a : deux solutions a\sqrt{a}a​ et −a-\sqrt{a}−a​ si a>0a > 0a>0, une seule (000) si a=0a = 0a=0, aucune si a<0a < 0a<0.
  • Dans un problème : inconnue, équation, résolution, vérification, phrase de conclusion avec l'unité.

Automatismes (questions flash) :

  • Résoudre 3x−7=83x - 7 = 83x−7=8 → 3x=153x = 153x=15, donc x=5x = 5x=5.
  • Résoudre x2=36x^2 = 36x2=36 → x=6x = 6x=6 ou x=−6x = -6x=−6.
  • −2-2−2 est-il solution de x2+3x+2=0x^2 + 3x + 2 = 0x2+3x+2=0 ? → oui : 4−6+2=04 - 6 + 2 = 04−6+2=0.

Méthodes et exemples rédigés

Méthode : Résoudre une équation produit-nul rédigée

Exemple

Résoudre (2x−5)(3x+12)=0(2x - 5)(3x + 12) = 0(2x−5)(3x+12)=0.

  1. Étape 1 (Énoncé de la propriété) : Si un produit de facteurs est nul, alors au moins l'un des facteurs est nul.

  2. Étape 2 (Séparation) : 2x−5=02x - 5 = 02x−5=0 ou 3x+12=03x + 12 = 03x+12=0.

  3. Étape 3 (Résolution) :

    • 2x=5  ⟹  x=52=2,52x = 5 \implies x = \frac{5}{2} = 2{,}52x=5⟹x=25​=2,5.
    • 3x=−12  ⟹  x=−123=−43x = -12 \implies x = \frac{-12}{3} = -43x=−12⟹x=3−12​=−4.

  4. Étape 4 (Conclusion) : Les solutions de l'équation sont −4-4−4 et 2,52{,}52,5 (noté S={−4;2,5}S = \{-4 ; 2{,}5\}S={−4;2,5}).

Méthode : Mettre un problème en équation

Exemple

Un cinéma propose deux tarifs. Tarif A : abonnement de 20 € puis 5 € par séance. Tarif B : 9 € par séance, sans abonnement. Pour combien de séances les deux tarifs coûtent-ils le même prix ?

  1. Étape 1 (Choisir l'inconnue) : on note xxx le nombre de séances.

  2. Étape 2 (Traduire l'énoncé) : tarif A : 20+5x20 + 5x20+5x ; tarif B : 9x9x9x. On cherche xxx tel que 20+5x=9x20 + 5x = 9x20+5x=9x.

  3. Étape 3 (Résoudre) : 20=9x−5x20 = 9x - 5x20=9x−5x, soit 20=4x20 = 4x20=4x, donc x=204=5x = \frac{20}{4} = 5x=420​=5.

  4. Étape 4 (Vérifier) : tarif A : 20+5×5=4520 + 5 \times 5 = 4520+5×5=45 ; tarif B : 9×5=459 \times 5 = 459×5=45. Les deux coûts sont égaux.

  5. Étape 5 (Conclure par une phrase) : les deux tarifs coûtent 45 € pour 5 séances. Au-delà, le tarif A est plus avantageux (pour 6 séances : 50 € contre 54 €).

Méthode : Résoudre une équation du type x2=ax^2 = ax2=a

Exemple

Résoudre 2x2−18=02x^2 - 18 = 02x2−18=0, puis calculer le côté d'un carré d'aire 50 cm250 \text{ cm}^250 cm2.

  1. Étape 1 (Isoler x2x^2x2) : 2x2=182x^2 = 182x2=18, donc x2=182=9x^2 = \frac{18}{2} = 9x2=218​=9.

  2. Étape 2 (Signe de aaa) : 9>09 > 09>0, l'équation a deux solutions : x=9=3x = \sqrt{9} = 3x=9​=3 ou x=−9=−3x = -\sqrt{9} = -3x=−9​=−3.
    Vérification : 2×32−18=02 \times 3^2 - 18 = 02×32−18=0 et 2×(−3)2−18=02 \times (-3)^2 - 18 = 02×(−3)2−18=0.

  3. Étape 3 (Problème du carré) : si ccc est le côté en cm, c2=50c^2 = 50c2=50, donc c=50c = \sqrt{50}c=50​ ou c=−50c = -\sqrt{50}c=−50​.

  4. Étape 4 (Interpréter) : une longueur est positive, on garde c=50≈7,1c = \sqrt{50} \approx 7{,}1c=50​≈7,1 cm (valeur exacte 50\sqrt{50}50​ cm).

Pièges fréquents

  • Pour x2=25x^2 = 25x2=25, oublier la solution négative : les solutions sont 555 ET −5-5−5 !
  • Diviser par xxx pour « simplifier » une équation comme x(2x−3)=0x(2x-3) = 0x(2x−3)=0 : cela élimine illégalement la solution x=0x = 0x=0 !
  • Oublier d'inverser le sens de l'inégalité dans une inéquation lorsqu'on divise par un nombre négatif.
  • Dans un problème, garder une solution négative alors que l'inconnue est une longueur ou un nombre d'objets, ou oublier la phrase de conclusion avec l'unité.

Questions de révision

Essaie de répondre de tête avant d'afficher la réponse.

Quelle est la propriété de l'équation produit-nul ?

Un produit de facteurs est nul si et seulement si au moins l'un de ses facteurs est nul :
A×B=0  ⟺  A=0 ou B=0A \times B = 0 \iff A = 0 \text{ ou } B = 0A×B=0⟺A=0 ou B=0

Quelles sont les solutions de l'équation x2=49x^2 = 49x2=49 ?

Deux solutions : 777 et −7-7−7 (car 72=497^2 = 4972=49 et (−7)2=49(-7)^2 = 49(−7)2=49).

Combien de solutions admet l'équation x2=−9x^2 = -9x2=−9 ?

Aucune solution réelle, car le carré d'un nombre réel est toujours positif ou nul.

Que devient l'inégalité −2x<6-2x < 6−2x<6 quand on isole xxx ?

x>−3x > -3x>−3
(On change le sens <<< en >>> car on divise par le nombre négatif −2-2−2).

Quelles sont les solutions de (x−3)(2x+8)=0(x - 3)(2x + 8) = 0(x−3)(2x+8)=0 ?

x=3x = 3x=3 ou x=−4x = -4x=−4.

Le nombre 222 est-il solution de 3x−1=x+33x - 1 = x + 33x−1=x+3 ?

Oui : à gauche 3×2−1=53 \times 2 - 1 = 53×2−1=5, à droite 2+3=52 + 3 = 52+3=5.

Résoudre 5x+2=3x−65x + 2 = 3x - 65x+2=3x−6.

5x−3x=−6−25x - 3x = -6 - 25x−3x=−6−2, soit 2x=−82x = -82x=−8, donc x=−4x = -4x=−4.

Exercices corrigés

Exercice 1 Équation élémentaire ax = b

Palier 1 · découverte

Résoudre dans R\mathbb{R}R l'équation : 4x=284x = 284x=28. Que vaut xxx ?

Un indice

Pour isoler xxx, divise les deux membres par 4.

Voir la correction

Réponse attendue : 7

4x=28  ⟹  x=284=74x = 28 \implies x = \frac{28}{4} = 74x=28⟹x=428​=7

Exercice 2 Équation avec x dans chaque membre

Palier 2 · application

Résoudre dans R\mathbb{R}R : 7x−5=3x+157x - 5 = 3x + 157x−5=3x+15. Quelle est la solution ?

Un indice

Regroupe les xxx à gauche (en soustrayant 3x3x3x) et les nombres à droite (en ajoutant 555).

Voir la correction

Réponse attendue : 5

7x−5=3x+15  ⟹  7x−3x=15+5  ⟹  4x=20  ⟹  x=57x - 5 = 3x + 15 \implies 7x - 3x = 15 + 5 \implies 4x = 20 \implies x = 57x−5=3x+15⟹7x−3x=15+5⟹4x=20⟹x=5

Exercice 3 Équations du type x2=ax^2 = ax2=a (Brevet)

Palier 3 · approfondissement

Combien de solutions réelles possède l'équation x2=49x^2 = 49x2=49, et quelles sont-elles ?

  1. Deux solutions : 777 et −7-7−7
  2. Une seule solution : 777
  3. Aucune solution
  4. Deux solutions : 49\sqrt{49}49​ et −49\sqrt{-49}−49​
Un indice

Pense aux nombres dont le carré vaut 49. N'oublie pas le signe moins !

Voir la correction

Bonne réponse : A. Deux solutions : 777 et −7-7−7

Parfait ! Comme 49>049 > 049>0, l'équation x2=49x^2 = 49x2=49 admet deux solutions réelles opposées : 49=7\sqrt{49} = 749​=7 et −49=−7-\sqrt{49} = -7−49​=−7.

Comme 49>049 > 049>0, l'équation x2=49x^2 = 49x2=49 admet deux solutions réelles distinctes :
x=49=7oux=−49=−7x = \sqrt{49} = 7 \quad \text{ou} \quad x = -\sqrt{49} = -7x=49​=7oux=−49​=−7

Exercice 4 Défi Seconde : Équation produit après factorisation

Palier 4 · défi

Résoudre dans R\mathbb{R}R l'équation : (2x+5)(x−4)+(2x+5)(3x+1)=0(2x + 5)(x - 4) + (2x + 5)(3x + 1) = 0(2x+5)(x−4)+(2x+5)(3x+1)=0.
Quelle est la plus grande des deux solutions ?

Un indice

Ne développe surtout pas ! Factorise d'abord par le facteur commun (2x+5)(2x + 5)(2x+5).

Voir la correction

Réponse attendue : 0.75

1. Factorisons par (2x+5)(2x + 5)(2x+5) :
(2x+5)[(x−4)+(3x+1)]=0  ⟹  (2x+5)(4x−3)=0(2x + 5)[(x - 4) + (3x + 1)] = 0 \implies (2x + 5)(4x - 3) = 0(2x+5)[(x−4)+(3x+1)]=0⟹(2x+5)(4x−3)=0
2. Équation produit nul :
2x+5=0  ⟹  x=−52=−2,52x + 5 = 0 \implies x = -\frac{5}{2} = -2,52x+5=0⟹x=−25​=−2,5
4x−3=0  ⟹  4x=3  ⟹  x=34=0,754x - 3 = 0 \implies 4x = 3 \implies x = \frac{3}{4} = 0,754x−3=0⟹4x=3⟹x=43​=0,75
La plus grande solution est 0,750,750,75 (ou 34\frac{3}{4}43​).
