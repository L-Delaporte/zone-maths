Objectifs du chapitre

  • Développer une expression littérale à l'aide de la distributivité simple : k(a+b)=ka+kbk(a+b) = ka+kbk(a+b)=ka+kb.
  • Reconnaître si une expression est une somme ou un produit.
  • Factoriser une expression simple en mettant en évidence un facteur commun.
  • Supprimer des parenthèses précédées d'un signe +++ ou d'un signe −-−.
  • Réduire une expression littérale en regroupant les termes par familles de même puissance.
  • Tester si une égalité est vraie pour une valeur donnée, et savoir qu'une égalité vraie pour une valeur n'est pas forcément une identité.
  • Résoudre une équation du premier degré de type ax+b=cax+b = cax+b=c ou ax+b=cx+dax+b = cx+dax+b=cx+d et vérifier la solution trouvée.

Le cours

1. Vocabulaire du calcul littéral et des équations

  • Expression littérale : expression contenant des nombres et des lettres désignant des variables ou inconnues.
  • Variable : lettre qui peut prendre différentes valeurs, par exemple le nombre de départ d'un programme de calcul.
  • Inconnue : lettre qui cache un nombre dont on cherche la valeur.
  • Équation : égalité comportant une ou plusieurs inconnues (ex: 5x−3=2x+95x - 3 = 2x + 95x−3=2x+9).
  • Résoudre une équation : trouver toutes les valeurs de l'inconnue qui rendent l'égalité vraie.
  • Solution : valeur numérique de l'inconnue qui vérifie l'égalité.
  • Vérification : calcul séparé de chaque membre en remplaçant l'inconnue par la solution trouvée.
  • Identité : égalité vraie pour toutes les valeurs de la lettre (ex : 2(x+3)=2x+62(x + 3) = 2x + 62(x+3)=2x+6).

2. Structure d'une expression : somme ou produit

Pour savoir si une expression est une somme ou un produit, on cherche la dernière opération à effectuer en respectant les priorités.

  • 5x+35x + 35x+3 : on calcule d'abord 5×x5 \times x5×x, puis on ajoute 333. La dernière opération est une addition : c'est une somme.
  • 3(x+2)3(x + 2)3(x+2) : on calcule d'abord la parenthèse, puis on multiplie par 333. La dernière opération est une multiplication : c'est un produit.
  • 4(x+1)+34(x + 1) + 34(x+1)+3 : la dernière opération est l'addition de 333. C'est une somme, même si elle contient un produit.
  • 5x−35x - 35x−3 : la dernière opération est une soustraction, c'est une différence. Une différence est une somme de nombres relatifs, car 5x−3=5x+(−3)5x - 3 = 5x + (-3)5x−3=5x+(−3).

Développer, c'est transformer un produit en somme. Factoriser, c'est transformer une somme en produit.

3. Distributivité simple et suppression de parenthèses

  • Distributivité simple : transformer un produit en somme ou différence :

k(a+b)=k×a+k×b=ka+kbk(a + b) = k \times a + k \times b = ka + kbk(a+b)=k×a+k×b=ka+kb
k(a−b)=k×a−k×b=ka−kbk(a - b) = k \times a - k \times b = ka - kbk(a−b)=k×a−k×b=ka−kb

  • Suppression de parenthèses :

- Précédées d'un signe +++ : on supprime les parenthèses sans rien changer : a+(b−c)=a+b−ca + (b - c) = a + b - ca+(b−c)=a+b−c.
- Précédées d'un signe −-− : on change TOUS les signes à l'intérieur : a−(b−c)=a−b+ca - (b - c) = a - b + ca−(b−c)=a−b+c.

  • Factoriser (sens inverse) : 6x+9=3×2x+3×3=3(2x+3)6x + 9 = 3 \times 2x + 3 \times 3 = 3(2x + 3)6x+9=3×2x+3×3=3(2x+3).

4. Réduction d'une expression littérale

Réduire, c'est regrouper les termes possédant la même lettre affectée du même exposant (par familles) :
E=3x2+5x−7+2x2−8x+12E = 3x^2 + 5x - 7 + 2x^2 - 8x + 12E=3x2+5x−7+2x2−8x+12
E=(3x2+2x2)+(5x−8x)+(−7+12)=5x2−3x+5E = (3x^2 + 2x^2) + (5x - 8x) + (-7 + 12) = 5x^2 - 3x + 5E=(3x2+2x2)+(5x−8x)+(−7+12)=5x2−3x+5

5. Tester une égalité : valeur, identité, contre-exemple

Tester une égalité pour une valeur, c'est remplacer la lettre par cette valeur dans chaque membre séparément, puis comparer les deux résultats. Pour 4x−3=2x+54x - 3 = 2x + 54x−3=2x+5 :

  • pour x=4x = 4x=4 : à gauche 4×4−3=134 \times 4 - 3 = 134×4−3=13, à droite 2×4+5=132 \times 4 + 5 = 132×4+5=13. Les résultats sont égaux : l'égalité est vraie pour x=4x = 4x=4.
  • pour x=3x = 3x=3 : à gauche 4×3−3=94 \times 3 - 3 = 94×3−3=9, à droite 2×3+5=112 \times 3 + 5 = 112×3+5=11. Les résultats sont différents : l'égalité est fausse pour x=3x = 3x=3.

Une égalité vraie pour une valeur n'est pas forcément une identité. Une identité est vraie pour toutes les valeurs de la lettre.

  • x+x=x2x + x = x^2x+x=x2 est vraie pour x=2x = 2x=2 (car 2+2=42 + 2 = 42+2=4 et 22=42^2 = 422=4), mais fausse pour x=3x = 3x=3 (car 3+3=63 + 3 = 63+3=6 et 32=93^2 = 932=9). Ce n'est donc pas une identité : x=3x = 3x=3 est un contre-exemple. Un seul contre-exemple suffit pour le prouver.
  • 2(x+3)=2x+62(x + 3) = 2x + 62(x+3)=2x+6 est une identité. Pour le prouver, quelques essais ne suffisent pas : on transforme un membre par le calcul (ici en développant) jusqu'à obtenir l'autre membre.

Programmes de calcul équivalents : deux programmes sont équivalents s'ils donnent le même résultat pour n'importe quel nombre de départ. On traduit chacun par une expression, puis on montre que l'égalité de ces expressions est une identité.

  • Programme A : choisir un nombre xxx, lui ajouter 333, multiplier le résultat par 444, soustraire le double du nombre de départ. On obtient 4(x+3)−2x=4x+12−2x=2x+124(x + 3) - 2x = 4x + 12 - 2x = 2x + 124(x+3)−2x=4x+12−2x=2x+12.
  • Programme B : choisir un nombre xxx, le multiplier par 222, ajouter 121212. On obtient 2x+122x + 122x+12.

Les deux expressions sont égales pour toute valeur de xxx : les programmes sont équivalents.

6. Résolution pas-à-pas d'une équation : ajouter ou soustraire aux deux membres

Pour résoudre ax+b=cx+dax + b = cx + dax+b=cx+d :
1. Séparer les familles : ajouter ou soustraire un même terme aux deux membres pour rassembler les termes en xxx d'un côté (souvent à gauche) et les nombres constants de l'autre côté (à droite).
2. Réduire les deux membres pour obtenir une forme Ax=BAx = BAx=B.
3. Isoler l'inconnue en divisant les deux membres par le coefficient AAA devant xxx, s'il n'est pas nul : x=BAx = \frac{B}{A}x=AB​.

Pourquoi ça marche ? On peut ajouter ou soustraire un même nombre aux deux membres, et multiplier ou diviser les deux membres par un même nombre non nul : l'égalité reste vraie.

Attention aux coefficients : dans 3x+5=113x + 5 = 113x+5=11, on soustrait 555 aux deux membres pour obtenir 3x=63x = 63x=6. Pour finir, on divise les deux membres par 333, ce qui donne x=2x = 2x=2 : le 333 ne devient pas −3-3−3.

Pour aller plus loin : double distributivité

Cette partie va au-delà de ce qui est attendu en 4e : la double distributivité s'étudie en 3e.

Pour développer un produit de deux sommes, chaque terme de la première parenthèse multiplie chaque terme de la seconde :
(a+b)(c+d)=ac+ad+bc+bd(a + b)(c + d) = ac + ad + bc + bd(a+b)(c+d)=ac+ad+bc+bd
Un carré se développe de la même façon, en l'écrivant comme un produit de deux parenthèses identiques :
(x+3)2=(x+3)(x+3)=x2+3x+3x+9=x2+6x+9(x + 3)^2 = (x + 3)(x + 3) = x^2 + 3x + 3x + 9 = x^2 + 6x + 9(x+3)2=(x+3)(x+3)=x2+3x+3x+9=x2+6x+9

À retenir

  • Somme ou produit : c'est la dernière opération à effectuer qui le dit.
  • Développer : k(a+b)=ka+kbk(a + b) = ka + kbk(a+b)=ka+kb.
  • Un signe −-− devant une parenthèse change le signe de tous les termes qu'elle contient.
  • Réduire : on regroupe les termes en x2x^2x2, en xxx, puis les nombres.
  • Une égalité vraie pour une valeur n'est pas forcément une identité : un seul contre-exemple suffit pour le prouver.
  • Résoudre : on isole xxx en effectuant la même opération sur les deux membres, puis on vérifie la solution.
  • Problème : choisir l'inconnue, écrire l'équation, résoudre, vérifier, conclure par une phrase.

Méthodes et exemples rédigés

Méthode : Résoudre une équation du type ax+b=cx+dax + b = cx + dax+b=cx+d

Exemple

Résoudre l'équation 7x−4=2x+117x - 4 = 2x + 117x−4=2x+11 avec vérification.

  1. Étape 1 (Regroupement des termes en x) : On soustrait 2x2x2x des deux côtés : 7x−2x−4=11  ⟹  5x−4=117x - 2x - 4 = 11 \implies 5x - 4 = 117x−2x−4=11⟹5x−4=11.

  2. Étape 2 (Regroupement des constantes) : On ajoute 444 des deux côtés : 5x=11+4=155x = 11 + 4 = 155x=11+4=15.

  3. Étape 3 (Division par le coefficient) : On divise par 555 : x=155=3x = \frac{15}{5} = 3x=515​=3.

  4. Étape 4 (Vérification) :

    • Membre de gauche : 7×3−4=21−4=177 \times 3 - 4 = 21 - 4 = 177×3−4=21−4=17.
    • Membre de droite : 2×3+11=6+11=172 \times 3 + 11 = 6 + 11 = 172×3+11=6+11=17.

    L'égalité est vérifiée : la solution est bien x=3x = 3x=3.

Méthode : Montrer qu'une égalité est, ou n'est pas, une identité

Exemple

Les égalités 3(x+2)=3x+23(x + 2) = 3x + 23(x+2)=3x+2 et 5(x−1)+2x=7x−55(x - 1) + 2x = 7x - 55(x−1)+2x=7x−5 sont-elles des identités ?

  1. Étape 1 (Chercher un contre-exemple) : pour 3(x+2)=3x+23(x + 2) = 3x + 23(x+2)=3x+2, on essaie x=0x = 0x=0. À gauche : 3×(0+2)=63 \times (0 + 2) = 63×(0+2)=6. À droite : 3×0+2=23 \times 0 + 2 = 23×0+2=2. Comme 6≠26 \neq 26=2, x=0x = 0x=0 est un contre-exemple : ce n'est pas une identité.

  2. Étape 2 (Transformer un membre) : pour la seconde égalité, on développe puis on réduit le membre de gauche : 5(x−1)+2x=5x−5+2x=7x−55(x - 1) + 2x = 5x - 5 + 2x = 7x - 55(x−1)+2x=5x−5+2x=7x−5.

  3. Étape 3 (Conclure) : on obtient exactement le membre de droite, quelle que soit la valeur de xxx : c'est une identité.

Méthode : Mettre un problème en équation

Exemple

La somme de trois nombres entiers consécutifs est égale à 84. Quels sont ces nombres ?

  1. Étape 1 (Choix de l'inconnue) : on note nnn le plus petit des trois nombres ; les suivants sont n+1n + 1n+1 et n+2n + 2n+2.

  2. Étape 2 (Mise en équation) : n+(n+1)+(n+2)=84n + (n + 1) + (n + 2) = 84n+(n+1)+(n+2)=84, soit 3n+3=843n + 3 = 843n+3=84.

  3. Étape 3 (Résolution) : 3n=84−3=813n = 84 - 3 = 813n=84−3=81, donc n=813=27n = \dfrac{81}{3} = 27n=381​=27.

  4. Étape 4 (Vérification et conclusion) : 27+28+29=8427 + 28 + 29 = 8427+28+29=84. Les trois nombres sont 27, 28 et 29.

Pour aller plus loin — Méthode : Développer et réduire avec la double distributivité

Exemple

Développer et réduire E=(2x+3)(x−4)E = (2x + 3)(x - 4)E=(2x+3)(x−4), puis vérifier avec x=1x = 1x=1.

  1. Étape 1 (Distribuer) : E=2x×x+2x×(−4)+3×x+3×(−4)E = 2x \times x + 2x \times (-4) + 3 \times x + 3 \times (-4)E=2x×x+2x×(−4)+3×x+3×(−4).

  2. Étape 2 (Calculer chaque produit) : E=2x2−8x+3x−12E = 2x^2 - 8x + 3x - 12E=2x2−8x+3x−12.

  3. Étape 3 (Réduire) : E=2x2−5x−12E = 2x^2 - 5x - 12E=2x2−5x−12.

  4. Vérification pour x=1x = 1x=1 : forme de départ (2+3)(1−4)=5×(−3)=−15(2 + 3)(1 - 4) = 5 \times (-3) = -15(2+3)(1−4)=5×(−3)=−15 ; forme développée 2−5−12=−152 - 5 - 12 = -152−5−12=−15. Les résultats concordent.

Pièges fréquents

  • Se tromper d'opération : dans 3x+5=113x + 5 = 113x+5=11, on soustrait 555 aux deux membres, ce qui donne 3x=11−5=63x = 11 - 5 = 63x=11−5=6, pas 11+511 + 511+5. Puis on divise les deux membres par 333 : x=6÷3x = 6 \div 3x=6÷3, et non 6−36 - 36−3 !
  • Dans un signe −-− devant une parenthèse, oublier de changer le 2e terme : 5−(2x−3)=5−2x+35 - (2x - 3) = 5 - 2x + 35−(2x−3)=5−2x+3 et NON 5−2x−35 - 2x - 35−2x−3 !
  • Ne pas confondre 3x3x3x (multiplication 3×x3 \times x3×x) et 3+x3+x3+x (addition).
  • Croire qu'une expression est un produit parce qu'elle contient une multiplication : 2x+52x + 52x+5 est une somme, car la dernière opération à effectuer est l'addition.
  • Conclure qu'une égalité est une identité parce qu'elle est vraie pour une ou deux valeurs : il faut le prouver par le calcul. À l'inverse, un seul contre-exemple suffit pour montrer que ce n'en est pas une.

Questions de révision

Essaie de répondre de tête avant d'afficher la réponse.

Que donne le développement de −4(2x−5)-4(2x - 5)−4(2x−5) ?

−8x+20-8x + 20−8x+20 (car (−4)×2x=−8x(-4) \times 2x = -8x(−4)×2x=−8x et (−4)×(−5)=+20(-4) \times (-5) = +20(−4)×(−5)=+20).

Comment simplifier l'expression −(3x−7)-(3x - 7)−(3x−7) ?

−3x+7-3x + 7−3x+7 (le signe −-− devant la parenthèse inverse le signe de chaque terme).

Résoudre l'équation 4x=−204x = -204x=−20.

x=−204=−5x = \frac{-20}{4} = -5x=4−20​=−5.

Résoudre l'équation x−8=−3x - 8 = -3x−8=−3.

x=−3+8=5x = -3 + 8 = 5x=−3+8=5.

Comment vérifie-t-on qu'un nombre est solution d'une équation ?

On remplace l'inconnue par ce nombre dans chaque membre séparément et on vérifie si les deux résultats sont égaux.

Pour aller plus loin : développer (x+2)(x+5)(x + 2)(x + 5)(x+2)(x+5).

x2+5x+2x+10=x2+7x+10x^2 + 5x + 2x + 10 = x^2 + 7x + 10x2+5x+2x+10=x2+7x+10.

Résoudre 3(x−2)=5x+43(x - 2) = 5x + 43(x−2)=5x+4.

3x−6=5x+4  ⟺  −2x=10  ⟺  x=−53x - 6 = 5x + 4 \iff -2x = 10 \iff x = -53x−6=5x+4⟺−2x=10⟺x=−5 (vérification : 3×(−7)=−213 \times (-7) = -213×(−7)=−21 et 5×(−5)+4=−215 \times (-5) + 4 = -215×(−5)+4=−21).

L'expression 3(x+4)3(x + 4)3(x+4) est-elle une somme ou un produit ?

Un produit : la dernière opération à effectuer est la multiplication par 333.

Qu'est-ce qu'une identité ?

Une égalité vraie pour toutes les valeurs de la lettre, par exemple 2(x+3)=2x+62(x + 3) = 2x + 62(x+3)=2x+6.

Une égalité vraie pour x=2x = 2x=2 est-elle forcément une identité ?

Non. Par exemple, x+x=x2x + x = x^2x+x=x2 est vraie pour x=2x = 2x=2, mais fausse pour x=3x = 3x=3 : x=3x = 3x=3 est un contre-exemple.

Exercices corrigés

Exercice 1 Résoudre une équation simple

Palier 1 · découverte

Résoudre l'équation suivante :
3x+5=263x + 5 = 263x+5=26

Un indice

Isole le terme en xxx : quelle opération, faite des deux côtés de l'égalité, fait disparaître le +5+ 5+5 ?

Voir la correction

Réponse attendue : 7

3x=26−5  ⟹  3x=21  ⟹  x=213=73x = 26 - 5 \implies 3x = 21 \implies x = \frac{21}{3} = 73x=26−5⟹3x=21⟹x=321​=7

Exercice 2 Équation avec des x des deux côtés

Palier 2 · application

Résoudre l'équation suivante :
7x−5=2x+157x - 5 = 2x + 157x−5=2x+15

Un indice

Regroupe les termes en xxx d'un même côté de l'égalité et les nombres de l'autre, en faisant chaque fois la même opération dans les deux membres.

Voir la correction

Réponse attendue : 4

7x−2x=15+5  ⟹  5x=20  ⟹  x=205=47x - 2x = 15 + 5 \implies 5x = 20 \implies x = \frac{20}{5} = 47x−2x=15+5⟹5x=20⟹x=520​=4

Exercice 3 Équation avec parenthèses et distributivité

Palier 3 · approfondissement

Résoudre l'équation :
2(3x−1)−4(x+2)=62(3x - 1) - 4(x + 2) = 62(3x−1)−4(x+2)=6

Un indice

Développe chaque produit avec la distributivité. Attention au signe −-− placé devant 4(x+2)4(x + 2)4(x+2) : il change les signes des deux termes obtenus.

Voir la correction

Réponse attendue : 8

1. Développement : 6x−2−4x−8=66x - 2 - 4x - 8 = 66x−2−4x−8=6.
2. Réduction : 2x−10=62x - 10 = 62x−10=6.
3. Résolution : 2x=16  ⟹  x=82x = 16 \implies x = 82x=16⟹x=8.

Exercice 4 Pour aller plus loin : double distributivité (ax+b)(cx+d)(ax + b)(cx + d)(ax+b)(cx+d)

Palier 4 · défi

Pour aller plus loin (notion étudiée en 3e).
Développer et réduire l'expression :
E=(3x−4)(2x+5)E = (3x - 4)(2x + 5)E=(3x−4)(2x+5)
Quel est le coefficient du terme en xxx (le terme du 1er degré) ?

Un indice

Double distributivité : 3x×2x+3x×5−4×2x−4×53x \times 2x + 3x \times 5 - 4 \times 2x - 4 \times 53x×2x+3x×5−4×2x−4×5.

Voir la correction

Réponse attendue : 7

E=6x2+15x−8x−20=6x2+7x−20E = 6x^2 + 15x - 8x - 20 = 6x^2 + 7x - 20E=6x2+15x−8x−20=6x2+7x−20
Le coefficient de xxx est donc 7.
