Objectifs du chapitre

  • Reconnaître et déterminer les primitives de fonctions usuelles et composées.
  • Résoudre l'équation différentielle y′=ayy' = ayy′=ay et y′=ay+by' = ay + by′=ay+b (a≠0a \ne 0a=0).
  • Déterminer l'unique solution vérifiant une condition initiale fixée y(x0)=y0y(x_0) = y_0y(x0​)=y0​.
  • Résoudre une équation y′=ay+fy' = ay + fy′=ay+f à l'aide d'une solution particulière.
  • Modéliser une situation d'évolution (refroidissement, population) par une équation différentielle.

3. Primitives : définition et propriétés

  • FFF est une primitive de fff sur l'intervalle III si FFF est dérivable sur III et F′=fF' = fF′=f.
  • Théorème : toute fonction continue sur un intervalle admet des primitives sur cet intervalle.
  • Si FFF est une primitive de fff, les primitives de fff sont les fonctions x↦F(x)+Cx \mapsto F(x) + Cx↦F(x)+C, C∈RC \in \mathbb{R}C∈R : deux primitives diffèrent d'une constante.

Méthodes et exemples rédigés

Méthode : Résoudre y′=ay+by' = ay + by′=ay+b avec condition initiale

Exemple

Résoudre y′−3y=6y' - 3y = 6y′−3y=6 avec y(0)=5y(0) = 5y(0)=5.

  1. Étape 1 (Forme standard) : y′=3y+6y' = 3y + 6y′=3y+6, d'où a=3a = 3a=3 et b=6b = 6b=6.

  2. Étape 2 (Solution générale) : y(x)=Ce3x−63=Ce3x−2y(x) = C e^{3x} - \frac{6}{3} = C e^{3x} - 2y(x)=Ce3x−36​=Ce3x−2.

  3. Étape 3 (Condition initiale) : y(0)=5  ⟺  Ce0−2=5  ⟺  C−2=5  ⟺  C=7y(0) = 5 \iff C e^0 - 2 = 5 \iff C - 2 = 5 \iff C = 7y(0)=5⟺Ce0−2=5⟺C−2=5⟺C=7.

  4. Conclusion : L'unique solution est y(x)=7e3x−2y(x) = 7e^{3x} - 2y(x)=7e3x−2 pour tout x∈Rx \in \mathbb{R}x∈R.

Méthode : Trouver une primitive d'une forme composée

Exemple

Déterminer une primitive de f(x)=xx2+1f(x) = \dfrac{x}{x^2 + 1}f(x)=x2+1x​, de g(x)=(2x+1)ex2+xg(x) = (2x + 1)e^{x^2 + x}g(x)=(2x+1)ex2+x et de h(x)=3x(x2+1)4h(x) = 3x(x^2 + 1)^4h(x)=3x(x2+1)4 sur R\mathbb{R}R.

  1. Étape 1 (fff, forme u′u\frac{u'}{u}uu′​) : avec u(x)=x2+1>0u(x) = x^2 + 1 > 0u(x)=x2+1>0, u′(x)=2xu'(x) = 2xu′(x)=2x, donc f=12×u′uf = \dfrac{1}{2} \times \dfrac{u'}{u}f=21​×uu′​. Une primitive est F(x)=12ln⁡(x2+1)F(x) = \dfrac{1}{2}\ln(x^2 + 1)F(x)=21​ln(x2+1).

  2. Étape 2 (ggg, forme u′euu'e^uu′eu) : avec u(x)=x2+xu(x) = x^2 + xu(x)=x2+x, u′(x)=2x+1u'(x) = 2x + 1u′(x)=2x+1, donc g=u′eug = u'e^ug=u′eu et G(x)=ex2+xG(x) = e^{x^2 + x}G(x)=ex2+x.

  3. Étape 3 (hhh, forme u′unu'u^nu′un) : avec u(x)=x2+1u(x) = x^2 + 1u(x)=x2+1, h=32×u′u4h = \dfrac{3}{2} \times u'u^4h=23​×u′u4, donc H(x)=32×(x2+1)55=3(x2+1)510H(x) = \dfrac{3}{2} \times \dfrac{(x^2 + 1)^5}{5} = \dfrac{3(x^2 + 1)^5}{10}H(x)=23​×5(x2+1)5​=103(x2+1)5​.

  4. Conclusion (vérification) : H′(x)=3×5×2x(x2+1)410=3x(x2+1)4=h(x)H'(x) = \dfrac{3 \times 5 \times 2x(x^2 + 1)^4}{10} = 3x(x^2 + 1)^4 = h(x)H′(x)=103×5×2x(x2+1)4​=3x(x2+1)4=h(x). On vérifie toujours une primitive en la dérivant.

Méthode : Résoudre y′=ay+fy' = ay + fy′=ay+f avec une solution particulière affine

Exemple

Soit (E):y′=2y−4x(E) : y' = 2y - 4x(E):y′=2y−4x. Chercher une solution particulière affine, puis la solution de (E)(E)(E) vérifiant y(0)=3y(0) = 3y(0)=3.

  1. Étape 1 (Solution particulière) : on cherche g(x)=mx+pg(x) = mx + pg(x)=mx+p. Alors g′(x)=mg'(x) = mg′(x)=m et (E)(E)(E) donne m=2(mx+p)−4x=(2m−4)x+2pm = 2(mx + p) - 4x = (2m - 4)x + 2pm=2(mx+p)−4x=(2m−4)x+2p pour tout xxx. Par identification : 2m−4=02m - 4 = 02m−4=0 et m=2pm = 2pm=2p, d'où m=2m = 2m=2 et p=1p = 1p=1 : g(x)=2x+1g(x) = 2x + 1g(x)=2x+1.

  2. Étape 2 (Vérification) : g′(x)=2g'(x) = 2g′(x)=2 et 2g(x)−4x=4x+2−4x=22g(x) - 4x = 4x + 2 - 4x = 22g(x)−4x=4x+2−4x=2 : on retrouve bien g′(x)g'(x)g′(x).

  3. Étape 3 (Solution générale) : les solutions de y′=2yy' = 2yy′=2y sont Ce2xCe^{2x}Ce2x, donc celles de (E)(E)(E) sont y(x)=Ce2x+2x+1y(x) = Ce^{2x} + 2x + 1y(x)=Ce2x+2x+1, C∈RC \in \mathbb{R}C∈R.

  4. Conclusion : y(0)=C+1=3y(0) = C + 1 = 3y(0)=C+1=3 donne C=2C = 2C=2. L'unique solution est y(x)=2e2x+2x+1y(x) = 2e^{2x} + 2x + 1y(x)=2e2x+2x+1.

Méthode : Modéliser un refroidissement par une équation différentielle

Exemple

Un café à 808080 °C est posé dans une pièce à 202020 °C. Sa température θ(t)\theta(t)θ(t) (en °C, ttt en minutes) vérifie θ′=−0,1(θ−20)\theta' = -0{,}1(\theta - 20)θ′=−0,1(θ−20). Au bout de combien de temps atteint-il 404040 °C ?

  1. Étape 1 (Forme y′=ay+by' = ay + by′=ay+b) : θ′=−0,1θ+2\theta' = -0{,}1\theta + 2θ′=−0,1θ+2, avec a=−0,1a = -0{,}1a=−0,1 et b=2b = 2b=2 ; −ba=20-\dfrac{b}{a} = 20−ab​=20. Les solutions sont θ(t)=Ce−0,1t+20\theta(t) = Ce^{-0{,}1t} + 20θ(t)=Ce−0,1t+20.

  2. Étape 2 (Condition initiale) : θ(0)=C+20=80\theta(0) = C + 20 = 80θ(0)=C+20=80, donc C=60C = 60C=60 et θ(t)=60e−0,1t+20\theta(t) = 60e^{-0{,}1t} + 20θ(t)=60e−0,1t+20.

  3. Étape 3 (Équation) : θ(t)=40  ⟺  60e−0,1t=20  ⟺  e−0,1t=13  ⟺  −0,1t=−ln⁡(3)  ⟺  t=10ln⁡(3)≈10,99\theta(t) = 40 \iff 60e^{-0{,}1t} = 20 \iff e^{-0{,}1t} = \dfrac{1}{3} \iff -0{,}1t = -\ln(3) \iff t = 10\ln(3) \approx 10{,}99θ(t)=40⟺60e−0,1t=20⟺e−0,1t=31​⟺−0,1t=−ln(3)⟺t=10ln(3)≈10,99.

  4. Conclusion : le café atteint 404040 °C au bout d'environ 111111 minutes. Comme lim⁡t→+∞θ(t)=20\lim\limits_{t \to +\infty} \theta(t) = 20t→+∞lim​θ(t)=20, sa température tend vers celle de la pièce.

Pièges fréquents

  • La solution particulière constante de y′=ay+by' = ay + by′=ay+b est −ba-\frac{b}{a}−ab​ et NON +ba+\frac{b}{a}+ab​ !
  • Une primitive d'un produit n'est pas le produit des primitives : xexx e^xxex n'a pas pour primitive x22ex\frac{x^2}{2}e^x2x2​ex (dériver pour s'en convaincre).
  • La constante CCC se détermine avec la condition initiale sur la solution complète Ceax+g(x)Ce^{ax} + g(x)Ceax+g(x), jamais sur CeaxCe^{ax}Ceax seul.
  • Une primitive de e3xe^{3x}e3x est 13e3x\frac{1}{3}e^{3x}31​e3x et non e3xe^{3x}e3x ni 3e3x3e^{3x}3e3x.

Exercice 1 Équation différentielle linéaire y' = ay

Palier 1 · découverte

Quelles sont les solutions sur R\mathbb{R}R de l'équation différentielle y′−3y=0y' - 3y = 0y′−3y=0 ?

  1. y(x)=Ce3xy(x) = C e^{3x}y(x)=Ce3x (C∈RC \in \mathbb{R}C∈R)
  2. y(x)=Ce−3xy(x) = C e^{-3x}y(x)=Ce−3x
  3. y(x)=3ex+Cy(x) = 3e^x + Cy(x)=3ex+C
  4. y(x)=e3x+Cy(x) = e^{3x} + Cy(x)=e3x+C
Un indice

L'équation s'écrit y′=3yy' = 3yy′=3y.

Voir la correction

Bonne réponse : A. y(x)=Ce3xy(x) = C e^{3x}y(x)=Ce3x (C∈RC \in \mathbb{R}C∈R)

L'équation équivaut à y′=3yy' = 3yy′=3y. Les solutions générales sont y(x)=Ce3xy(x) = C e^{3x}y(x)=Ce3x où CCC est une constante réelle quelconque.
