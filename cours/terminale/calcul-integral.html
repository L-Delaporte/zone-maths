Calcul intégral : intégrale, aire, valeur moyenne et intégration par parties — cours de terminale

Intégrale comme aire sous la courbe, théorème fondamental de l'analyse ∫_a^b f(t)dt = F(b) - F(a), linéarité, positivité, intégration par parties (IPP).

Objectifs du chapitre

  • Définir l'intégrale d'une fonction continue ∫abf(t)dt=[F(t)]ab=F(b)−F(a)\int_a^b f(t) dt = [F(t)]_a^b = F(b) - F(a)∫ab​f(t)dt=[F(t)]ab​=F(b)−F(a) où FFF est une primitive de fff.
  • Interpréter géométriquement l'intégrale comme une aire algébrique sous la courbe.
  • Maîtriser les propriétés de l'intégrale : linéarité, relation de Chasles, positivité.
  • Appliquer la formule d'intégration par parties (IPP) : ∫abu′(t)v(t)dt=[u(t)v(t)]ab−∫abu(t)v′(t)dt\int_a^b u'(t)v(t) dt = [u(t)v(t)]_a^b - \int_a^b u(t)v'(t) dt∫ab​u′(t)v(t)dt=[u(t)v(t)]ab​−∫ab​u(t)v′(t)dt.
  • Calculer l'aire d'un domaine délimité par deux courbes.
  • Étudier une suite d'intégrales (signe, monotonie, encadrement, limite) et approcher une intégrale par la méthode des rectangles.

Le cours

1. Définition et Théorème fondamental de l'analyse

Soit fff une fonction continue sur [a;b][a ; b][a;b] et FFF une primitive de fff sur cet intervalle :
∫abf(t)dt=[F(t)]ab=F(b)−F(a)\int_a^b f(t) dt = [F(t)]_a^b = F(b) - F(a)∫ab​f(t)dt=[F(t)]ab​=F(b)−F(a)

  • Relation de Chasles : ∫acf(t)dt+∫cbf(t)dt=∫abf(t)dt\int_a^c f(t) dt + \int_c^b f(t) dt = \int_a^b f(t) dt∫ac​f(t)dt+∫cb​f(t)dt=∫ab​f(t)dt.
  • Valeur moyenne de fff sur [a;b][a ; b][a;b] : μ=1b−a∫abf(t)dt\mu = \frac{1}{b - a} \int_a^b f(t) dtμ=b−a1​∫ab​f(t)dt.

2. Intégration par parties (IPP)

Soient uuu et vvv deux fonctions dérivables à dérivées continues sur [a;b][a ; b][a;b] :
∫abu′(t)v(t)dt=[u(t)v(t)]ab−∫abu(t)v′(t)dt\int_a^b u'(t) v(t) dt = [u(t) v(t)]_a^b - \int_a^b u(t) v'(t) dt∫ab​u′(t)v(t)dt=[u(t)v(t)]ab​−∫ab​u(t)v′(t)dt
Règle ALPES pour choisir v(t)v(t)v(t) (qui sera dérivée) : Logarithme, Polynôme, Exponentielle, Sinus/Cosinus (on dérive de préférence la fonction qui apparaît en premier dans cette liste).

3. Intégrale et aire

  • Si fff est continue et positive sur [a;b][a ; b][a;b] (a≤ba \le ba≤b), ∫abf(x) dx\int_a^b f(x)\,dx∫ab​f(x)dx est l'aire, en unités d'aire (u.a.), du domaine compris entre la courbe, l'axe des abscisses et les droites x=ax = ax=a et x=bx = bx=b.
  • Si fff est négative sur [a;b][a ; b][a;b], cette aire vaut −∫abf(x) dx-\int_a^b f(x)\,dx−∫ab​f(x)dx.
  • Si f≥gf \ge gf≥g sur [a;b][a ; b][a;b], l'aire entre les deux courbes vaut ∫ab(f(x)−g(x)) dx\int_a^b \big(f(x) - g(x)\big)\,dx∫ab​(f(x)−g(x))dx.
  • Théorème fondamental : si fff est continue sur III et a∈Ia \in Ia∈I, la fonction F:x↦∫axf(t) dtF : x \mapsto \int_a^x f(t)\,dtF:x↦∫ax​f(t)dt est l'unique primitive de fff sur III qui s'annule en aaa ; en particulier F′=fF' = fF′=f.

4. Linéarité, positivité, croissance

Pour fff, ggg continues sur [a;b][a ; b][a;b] et λ∈R\lambda \in \mathbb{R}λ∈R :

  • Linéarité : ∫ab(f+λg)=∫abf+λ∫abg\int_a^b (f + \lambda g) = \int_a^b f + \lambda \int_a^b g∫ab​(f+λg)=∫ab​f+λ∫ab​g.
  • Positivité : si a≤ba \le ba≤b et f≥0f \ge 0f≥0 sur [a;b][a ; b][a;b], alors ∫abf≥0\int_a^b f \ge 0∫ab​f≥0.
  • Croissance : si a≤ba \le ba≤b et f≤gf \le gf≤g sur [a;b][a ; b][a;b], alors ∫abf≤∫abg\int_a^b f \le \int_a^b g∫ab​f≤∫ab​g.
  • Conséquence : si m≤f≤Mm \le f \le Mm≤f≤M sur [a;b][a ; b][a;b], alors m(b−a)≤∫abf≤M(b−a)m(b - a) \le \int_a^b f \le M(b - a)m(b−a)≤∫ab​f≤M(b−a).

5. Méthode des rectangles avec Python

Quand on ne connaît pas de primitive (par exemple de x↦e−x2x \mapsto e^{-x^2}x↦e−x2), on approche l'intégrale par une somme d'aires de rectangles de largeur b−an\frac{b - a}{n}nb−a​ :

from math import exp
def rectangles(f, a, b, n):
    h = (b - a) / n
    s = 0
    for k in range(n):
        s = s + f(a + kh)  h
    return s
print(rectangles(lambda x: exp(-x**2), 0, 1, 10))

Avec n=10n = 10n=10 on obtient environ 0,7780{,}7780,778 ; la valeur exacte est proche de 0,7470{,}7470,747. Plus nnn est grand, meilleure est l'approximation.

Pièges fréquents

  • Dans l'intégration par parties, attention au signe moins devant la seconde intégrale !
  • Si a>ba > ba>b, ∫abf(t)dt=−∫baf(t)dt\int_a^b f(t) dt = -\int_b^a f(t) dt∫ab​f(t)dt=−∫ba​f(t)dt.
  • Une intégrale n'est pas toujours une aire : ∫−11x dx=0\int_{-1}^{1} x\,dx = 0∫−11​xdx=0, alors que l'aire entre la droite y=xy = xy=x et l'axe des abscisses sur [−1;1][-1 ; 1][−1;1] vaut 111 u.a. Si fff change de signe, découper avec la relation de Chasles.
  • La positivité et la croissance de l'intégrale exigent des bornes dans l'ordre a≤ba \le ba≤b.
  • Dans ∫abf(t) dt\int_a^b f(t)\,dt∫ab​f(t)dt, la variable ttt est muette : le résultat ne dépend pas de ttt. En revanche, ∫0xf(t) dt\int_0^x f(t)\,dt∫0x​f(t)dt est une fonction de xxx.
