Le cours

1. Loi binomiale B(n,p)\mathcal{B}(n, p)B(n,p)

Soit XXX la variable aléatoire égale au nombre de succès dans un schéma de Bernoulli à nnn épreuves indépendantes de probabilité de succès ppp :

  • XXX suit la loi binomiale de paramètres nnn et ppp, notée X∼B(n,p)X \sim \mathcal{B}(n, p)X∼B(n,p).
  • Pour tout entier k∈{0,1,…,n}k \in \{0, 1, \dots, n\}k∈{0,1,…,n} :

P(X=k)=(nk)pk(1−p)n−kP(X = k) = \binom{n}{k} p^k (1-p)^{n-k}P(X=k)=(kn​)pk(1−p)n−k

  • Espérance mathématique : E(X)=npE(X) = npE(X)=np.
  • Variance : V(X)=np(1−p)V(X) = np(1-p)V(X)=np(1−p) et écart-type : σ(X)=np(1−p)\sigma(X) = \sqrt{np(1-p)}σ(X)=np(1−p)​.

2. Coefficients binomiaux

  • (nk)\binom{n}{k}(kn​) (« kkk parmi nnn ») est le nombre de chemins de l'arbre d'un schéma de Bernoulli à nnn épreuves qui réalisent exactement kkk succès ; c'est aussi le nombre de parties à kkk éléments d'un ensemble à nnn éléments.
  • Formule : (nk)=n!k! (n−k)!\binom{n}{k} = \dfrac{n!}{k!\,(n-k)!}(kn​)=k!(n−k)!n!​ où n!=1×2×⋯×nn! = 1 \times 2 \times \dots \times nn!=1×2×⋯×n et 0!=10! = 10!=1.
  • (n0)=(nn)=1\binom{n}{0} = \binom{n}{n} = 1(0n​)=(nn​)=1, (n1)=n\binom{n}{1} = n(1n​)=n, et symétrie : (nk)=(nn−k)\binom{n}{k} = \binom{n}{n-k}(kn​)=(n−kn​).
  • Relation de Pascal : (nk)+(nk+1)=(n+1k+1)\binom{n}{k} + \binom{n}{k+1} = \binom{n+1}{k+1}(kn​)+(k+1n​)=(k+1n+1​), qui permet de construire le triangle de Pascal.

3. Loi binomiale et variables de Bernoulli

  • Une variable de Bernoulli de paramètre ppp prend la valeur 111 (succès) avec probabilité ppp et 000 sinon : E=pE = pE=p et V=p(1−p)V = p(1 - p)V=p(1−p).
  • Si X1,…,XnX_1, \dots, X_nX1​,…,Xn​ sont des variables de Bernoulli de paramètre ppp indépendantes, alors X=X1+⋯+XnX = X_1 + \dots + X_nX=X1​+⋯+Xn​ compte les succès : X∼B(n,p)X \sim \mathcal{B}(n, p)X∼B(n,p).
  • On en déduit (voir TS2) : E(X)=npE(X) = npE(X)=np (linéarité) et V(X)=np(1−p)V(X) = np(1 - p)V(X)=np(1−p) (indépendance).
  • Exemple : pour X∼B(50;0,2)X \sim \mathcal{B}(50 ; 0{,}2)X∼B(50;0,2), E(X)=10E(X) = 10E(X)=10 et V(X)=50×0,2×0,8=8V(X) = 50 \times 0{,}2 \times 0{,}8 = 8V(X)=50×0,2×0,8=8.

4. Probabilités cumulées et calculs pratiques

  • P(X≤k)=∑i=0kP(X=i)P(X \le k) = \sum_{i=0}^{k} P(X = i)P(X≤k)=∑i=0k​P(X=i) s'obtient à la calculatrice (fonction « binomiale cumulée » / « binomFRép »).
  • P(X≥k)=1−P(X≤k−1)P(X \ge k) = 1 - P(X \le k - 1)P(X≥k)=1−P(X≤k−1) et P(a≤X≤b)=P(X≤b)−P(X≤a−1)P(a \le X \le b) = P(X \le b) - P(X \le a - 1)P(a≤X≤b)=P(X≤b)−P(X≤a−1).
  • En Python :
from math import comb
def binom(n, p, k):
    return comb(n, k)  pk  (1 - p)(n - k)
def cumul(n, p, k):
    return sum(binom(n, p, i) for i in range(k + 1))

5. Succession d'épreuves indépendantes

  • Une succession de nnn épreuves indépendantes se représente par un arbre ou par un produit cartésien : une issue est une liste (x1;x2;… ;xn)(x_1 ; x_2 ; \dots ; x_n)(x1​;x2​;…;xn​).
  • Modèle : la probabilité d'une issue (x1;… ;xn)(x_1 ; \dots ; x_n)(x1​;…;xn​) est le produit des probabilités des issues x1x_1x1​, …, xnx_nxn​ de chaque épreuve.
  • Exemple : on lance une pièce équilibrée puis un dé équilibré : P((Pile;6))=12×16=112P\big((\text{Pile} ; 6)\big) = \frac{1}{2} \times \frac{1}{6} = \frac{1}{12}P((Pile;6))=21​×61​=121​.
  • Pour un schéma de Bernoulli, l'univers est l'ensemble {0;1}n\{0 ; 1\}^n{0;1}n des listes de nnn chiffres (111 pour un succès, 000 pour un échec).

6. Démonstration : expression de la probabilité de kkk succès

Soit un schéma de Bernoulli de paramètres nnn et ppp, XXX le nombre de succès et k∈{0,…,n}k \in \{0, \dots, n\}k∈{0,…,n}.

  • Une issue réalisant {X=k}\{X = k\}{X=k} est une liste de nnn résultats comportant exactement kkk succès et n−kn - kn−k échecs. Par indépendance, sa probabilité est le produit pk(1−p)n−kp^k(1 - p)^{n-k}pk(1−p)n−k, la même pour toutes ces issues.
  • Une telle issue est entièrement déterminée par l'ensemble des kkk rangs (parmi nnn) où ont lieu les succès : il y en a donc (nk)\binom{n}{k}(kn​) (nombre de parties à kkk éléments d'un ensemble à nnn éléments, chapitre TS3).
  • Ces issues étant deux à deux incompatibles, on additionne leurs probabilités :

P(X=k)=(nk)pk(1−p)n−kP(X = k) = \binom{n}{k}p^k(1 - p)^{n-k}P(X=k)=(kn​)pk(1−p)n−k

7. Algorithmes : planche de Galton et surréservation

  • Planche de Galton : une bille rencontre nnn rangées de clous et part à droite avec la probabilité 12\frac{1}{2}21​ à chaque clou ; le numéro de sa case d'arrivée (nombre de déplacements à droite) suit B(n;12)\mathcal{B}\left(n ; \frac{1}{2}\right)B(n;21​).
from random import random

def galton(n, nb_billes):
    cases = [0] * (n + 1)
    for b in range(nb_billes):
        droite = 0
        for i in range(n):
            if random() < 0.5:
                droite = droite + 1
        cases[droite] = cases[droite] + 1
    return cases

  • Surréservation : pour X∼B(n,p)X \sim \mathcal{B}(n, p)X∼B(n,p) et α>0\alpha > 0α>0, on cherche le plus petit entier kkk tel que P(X>k)≤αP(X > k) \le \alphaP(X>k)≤α.
from math import comb

def seuil(n, p, alpha):
    k = 0
    cumul = (1 - p)**n          # P(X <= 0)
    while 1 - cumul > alpha:    # P(X > k) = 1 - P(X <= k)
        k = k + 1
        cumul = cumul + comb(n, k)  pk  (1 - p)(n - k)
    return k

Exemple : une compagnie vend 318318318 billets pour un avion de 300300300 places ; chaque passager se présente indépendamment avec la probabilité 0,920{,}920,92. seuil(318, 0.92, 0.05) renvoie 300300300 : la probabilité que plus de 300300300 passagers se présentent est inférieure ou égale à 5 %5\,\%5%. Avec 320320320 billets, le seuil passe à 302302302.

Exemple

Une machine produit des pièces défectueuses avec une probabilité 0,30{,}30,3, de façon indépendante. On prélève 202020 pièces et XXX est le nombre de pièces défectueuses. Calculer P(X≥1)P(X \ge 1)P(X≥1) et P(4≤X≤7)P(4 \le X \le 7)P(4≤X≤7).

Exemple

Méthode : Déterminer un seuil de probabilité cumulée

Exemple

Avec X∼B(20;0,3)X \sim \mathcal{B}(20 ; 0{,}3)X∼B(20;0,3), déterminer le plus petit entier bbb tel que P(X≤b)≥0,95P(X \le b) \ge 0{,}95P(X≤b)≥0,95.

  1. Étape 1 (Tableau des probabilités cumulées) : à la calculatrice, P(X≤8)≈0,8867P(X \le 8) \approx 0{,}8867P(X≤8)≈0,8867 et P(X≤9)≈0,9520P(X \le 9) \approx 0{,}9520P(X≤9)≈0,9520.

Pièges fréquents

  • Pour utiliser la loi binomiale, les répétitions doivent impérativement être indépendantes (tirage avec remise ou tirage sans remise sur une population très grande par rapport à l'échantillon).
  • Pour P(X≥1)P(X \ge 1)P(X≥1), utiliser la formule du complémentaire : P(X≥1)=1−P(X=0)=1−(1−p)nP(X \ge 1) = 1 - P(X = 0) = 1 - (1-p)^nP(X≥1)=1−P(X=0)=1−(1−p)n.
  • P(X≥4)=1−P(X≤3)P(X \ge 4) = 1 - P(X \le 3)P(X≥4)=1−P(X≤3) et non 1−P(X≤4)1 - P(X \le 4)1−P(X≤4) : la valeur 444 appartient à l'événement {X≥4}\{X \ge 4\}{X≥4}.
  • « Au moins un succès » (X≥1X \ge 1X≥1) n'est pas « exactement un succès » (X=1X = 1X=1) : lire l'énoncé attentivement.
  • (nk)\binom{n}{k}(kn​) n'est pas nk\dfrac{n}{k}kn​ : par exemple (42)=6\binom{4}{2} = 6(24​)=6 alors que 42=2\dfrac{4}{2} = 224​=2.
