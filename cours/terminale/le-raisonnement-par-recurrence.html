Cours et exercices corrigés de terminale : Le raisonnement par récurrence

Principe de récurrence (initialisation, hérédité, conclusion), applications aux sommes, inégalités et suites définies par récurrence.

Objectifs du chapitre

  • Maîtriser les trois étapes incontournables d'une démonstration par récurrence : Initialisation, Hérédité, Conclusion.
  • Démontrer des formules explicites de sommes et de termes généraux de suites.
  • Démontrer des inégalités valables pour tout entier naturel n≥n0n \ge n_0n≥n0​.
  • Éviter les erreurs de logique classiques (oubli de l'initialisation, circularité).
  • Démontrer l'inégalité de Bernoulli et des propriétés de divisibilité par récurrence.
  • Utiliser la récurrence pour étudier une suite définie par un+1=f(un)u_{n+1} = f(u_n)un+1​=f(un​) (encadrement, sens de variation).

Le cours

1. Principe du raisonnement par récurrence

Soit P(n)P(n)P(n) une propriété dépendant d'un entier naturel nnn, et n0∈Nn_0 \in \mathbb{N}n0​∈N :
1. Initialisation : On vérifie que la propriété P(n0)P(n_0)P(n0​) est vraie pour le premier rang n0n_0n0​.
2. Hérédité : On suppose que pour un entier k≥n0k \ge n_0k≥n0​ fixé quelconque, la propriété P(k)P(k)P(k) est vraie (c'est l'hypothèse de récurrence). On démontre alors que P(k+1)P(k+1)P(k+1) est vraie sous cette hypothèse.
3. Conclusion : Par le principe de récurrence, la propriété P(n)P(n)P(n) est vraie pour tout entier n≥n0n \ge n_0n≥n0​.

2. L'image des dominos et le rôle de chaque étape

On peut se représenter une récurrence comme une file infinie de dominos :

  • l'initialisation fait tomber le premier domino ;
  • l'hérédité garantit que si un domino tombe, le suivant tombe aussi.

Les deux étapes sont indispensables :

  • Sans hérédité, on ne sait rien au-delà des premiers rangs.
  • Sans initialisation, rien ne démarre. Exemple : la propriété P(n)P(n)P(n) : « 999 divise 10n+110^n + 110n+1 » est héréditaire, car si 10k+1=9m10^k + 1 = 9m10k+1=9m, alors 10k+1+1=10(10k+1)−9=9(10m−1)10^{k+1} + 1 = 10(10^k + 1) - 9 = 9(10m - 1)10k+1+1=10(10k+1)−9=9(10m−1). Pourtant elle n'est vraie pour aucun nnn : 10n+110^n + 110n+1 a pour somme des chiffres 222, il n'est jamais multiple de 999.

3. Inégalité de Bernoulli (démonstration exigible)

Pour tout réel a>0a > 0a>0 et tout entier naturel nnn :
(1+a)n≥1+na(1 + a)^n \ge 1 + na(1+a)n≥1+na
Conséquence importante : si q>1q > 1q>1, on écrit q=1+aq = 1 + aq=1+a avec a>0a > 0a>0, donc qn≥1+naq^n \ge 1 + naqn≥1+na. Comme lim⁡n→+∞(1+na)=+∞\lim\limits_{n \to +\infty} (1 + na) = +\inftyn→+∞lim​(1+na)=+∞, on obtient par comparaison lim⁡n→+∞qn=+∞\lim\limits_{n \to +\infty} q^n = +\inftyn→+∞lim​qn=+∞ (voir chapitre TA2).

4. Récurrence et suites un+1=f(un)u_{n+1} = f(u_n)un+1​=f(un​)

Si fff est croissante sur un intervalle III et si tous les termes de la suite sont dans III, alors une récurrence permet de « transporter » une inégalité d'un rang au suivant :
a≤uk≤uk+1≤b  ⟹  f(a)≤f(uk)≤f(uk+1)≤f(b)a \le u_k \le u_{k+1} \le b \implies f(a) \le f(u_k) \le f(u_{k+1}) \le f(b)a≤uk​≤uk+1​≤b⟹f(a)≤f(uk​)≤f(uk+1​)≤f(b)
c'est-à-dire f(a)≤uk+1≤uk+2≤f(b)f(a) \le u_{k+1} \le u_{k+2} \le f(b)f(a)≤uk+1​≤uk+2​≤f(b).
On démontre ainsi, en une seule récurrence, que la suite est croissante et bornée.

  • Attention : si fff est décroissante, l'ordre des inégalités s'inverse et la suite n'est en général pas monotone.

5. Conjecturer avec Python, démontrer par récurrence

Un programme peut calculer les premiers termes et suggérer une propriété, mais il ne la démontre pas :

from math import sqrt
u = 0
for n in range(10):
    print(n, u)
    u = sqrt(3*u + 4)

Les valeurs affichées (000 ; 222 ; 3,163{,}163,16 ; 3,733{,}733,73 ; …) laissent penser que la suite est croissante et majorée par 444 : c'est la récurrence qui le prouvera (voir méthode ci-dessous).

Méthodes et exemples rédigés

Méthode : Rédiger une récurrence pour une somme

Exemple

Démontrer que pour tout n≥1n \ge 1n≥1, Sn=1+2+⋯+n=n(n+1)2S_n = 1 + 2 + \dots + n = \frac{n(n+1)}{2}Sn​=1+2+⋯+n=2n(n+1)​.

  1. Initialisation (n=1n = 1n=1) : À gauche, S1=1S_1 = 1S1​=1. À droite, 1(1+1)2=22=1\frac{1(1+1)}{2} = \frac{2}{2} = 121(1+1)​=22​=1. L'égalité est vraie pour n=1n = 1n=1.

  2. Hérédité : Soit k≥1k \ge 1k≥1 un entier fixé. Supposons que Sk=k(k+1)2S_k = \frac{k(k+1)}{2}Sk​=2k(k+1)​ (HR). Montrons que Sk+1=(k+1)(k+2)2S_{k+1} = \frac{(k+1)(k+2)}{2}Sk+1​=2(k+1)(k+2)​.
    On a Sk+1=Sk+(k+1)=k(k+1)2+(k+1)=(k+1)(k2+1)=(k+1)(k+2)2S_{k+1} = S_k + (k+1) = \frac{k(k+1)}{2} + (k+1) = (k+1)\left(\frac{k}{2} + 1\right) = \frac{(k+1)(k+2)}{2}Sk+1​=Sk​+(k+1)=2k(k+1)​+(k+1)=(k+1)(2k​+1)=2(k+1)(k+2)​. La propriété est donc héréditaire.

  3. Conclusion : Par récurrence, pour tout n≥1n \ge 1n≥1, 1+2+⋯+n=n(n+1)21 + 2 + \dots + n = \frac{n(n+1)}{2}1+2+⋯+n=2n(n+1)​.

Méthode : Démontrer une inégalité par récurrence (Bernoulli)

Exemple

Soit a>0a > 0a>0. Démontrer que pour tout n∈Nn \in \mathbb{N}n∈N, (1+a)n≥1+na(1 + a)^n \ge 1 + na(1+a)n≥1+na.

  1. Étape 1 (Énoncé) : Pour n∈Nn \in \mathbb{N}n∈N, on note P(n)P(n)P(n) : « (1+a)n≥1+na(1 + a)^n \ge 1 + na(1+a)n≥1+na ».

  2. Étape 2 (Initialisation, n=0n = 0n=0) : (1+a)0=1(1 + a)^0 = 1(1+a)0=1 et 1+0×a=11 + 0 \times a = 11+0×a=1. On a bien 1≥11 \ge 11≥1, donc P(0)P(0)P(0) est vraie.

  3. Étape 3 (Hérédité) : Soit k∈Nk \in \mathbb{N}k∈N fixé tel que (1+a)k≥1+ka(1 + a)^k \ge 1 + ka(1+a)k≥1+ka (HR). Comme 1+a>01 + a > 01+a>0, on peut multiplier les deux membres par 1+a1 + a1+a sans changer le sens :
    (1+a)k+1≥(1+ka)(1+a)=1+a+ka+ka2=1+(k+1)a+ka2(1 + a)^{k+1} \ge (1 + ka)(1 + a) = 1 + a + ka + ka^2 = 1 + (k+1)a + ka^2(1+a)k+1≥(1+ka)(1+a)=1+a+ka+ka2=1+(k+1)a+ka2
    Or ka2≥0ka^2 \ge 0ka2≥0, donc (1+a)k+1≥1+(k+1)a(1 + a)^{k+1} \ge 1 + (k+1)a(1+a)k+1≥1+(k+1)a : P(k+1)P(k+1)P(k+1) est vraie.

  4. Conclusion : Par récurrence, pour tout n∈Nn \in \mathbb{N}n∈N, (1+a)n≥1+na(1 + a)^n \ge 1 + na(1+a)n≥1+na.

Méthode : Encadrer et étudier les variations d'une suite récurrente

Exemple

Soit (un)(u_n)(un​) définie par u0=0u_0 = 0u0​=0 et un+1=3un+4u_{n+1} = \sqrt{3u_n + 4}un+1​=3un​+4​. Démontrer que pour tout n∈Nn \in \mathbb{N}n∈N, 0≤un≤un+1≤40 \le u_n \le u_{n+1} \le 40≤un​≤un+1​≤4.

  1. Étape 1 (Fonction associée) : un+1=f(un)u_{n+1} = f(u_n)un+1​=f(un​) avec f(x)=3x+4f(x) = \sqrt{3x + 4}f(x)=3x+4​. Sur [0;+∞[[0 ; +\infty[[0;+∞[, x↦3x+4x \mapsto 3x + 4x↦3x+4 est croissante et positive, et la racine carrée est croissante, donc fff est croissante sur [0;+∞[[0 ; +\infty[[0;+∞[.

  2. Étape 2 (Initialisation) : u0=0u_0 = 0u0​=0 et u1=4=2u_1 = \sqrt{4} = 2u1​=4​=2. On a bien 0≤0≤2≤40 \le 0 \le 2 \le 40≤0≤2≤4.

  3. Étape 3 (Hérédité) : Soit k∈Nk \in \mathbb{N}k∈N tel que 0≤uk≤uk+1≤40 \le u_k \le u_{k+1} \le 40≤uk​≤uk+1​≤4. Comme fff est croissante sur [0;+∞[[0 ; +\infty[[0;+∞[ :
    f(0)≤f(uk)≤f(uk+1)≤f(4)f(0) \le f(u_k) \le f(u_{k+1}) \le f(4)f(0)≤f(uk​)≤f(uk+1​)≤f(4)
    soit 2≤uk+1≤uk+2≤16=42 \le u_{k+1} \le u_{k+2} \le \sqrt{16} = 42≤uk+1​≤uk+2​≤16​=4. Et puisque 0≤20 \le 20≤2, on obtient 0≤uk+1≤uk+2≤40 \le u_{k+1} \le u_{k+2} \le 40≤uk+1​≤uk+2​≤4.

  4. Conclusion : Pour tout nnn, 0≤un≤un+1≤40 \le u_n \le u_{n+1} \le 40≤un​≤un+1​≤4 : la suite (un)(u_n)(un​) est croissante et majorée par 444. Elle converge donc (théorème de convergence monotone, chapitre TA2).

Pièges fréquents

  • Ne jamais écrire « supposons que pour tout kkk, P(k)P(k)P(k) est vraie » : cela reviendrait à supposer ce que l'on veut démontrer ! Il faut écrire « soit kkk un entier fixé ».
  • Une propriété peut être héréditaire mais fausse pour tout nnn si l'initialisation échoue !
  • Vérifier une propriété sur de nombreux exemples (à la main ou avec Python) n'est pas une démonstration : n2+n+41n^2 + n + 41n2+n+41 est premier pour n=0,1,…,39n = 0, 1, \dots, 39n=0,1,…,39, mais pour n=40n = 40n=40 on obtient 1681=4121681 = 41^21681=412.
  • P(n)P(n)P(n) est une phrase (vraie ou fausse), pas un nombre : écrire « P(n)P(n)P(n) : un≤4u_n \le 4un​≤4 » et non « P(n)=unP(n) = u_nP(n)=un​ ».
  • Dans l'hérédité, avant de multiplier une inégalité par une quantité, vérifier que celle-ci est positive (dans Bernoulli, 1+a>01 + a > 01+a>0).

Questions de révision

Essaie de répondre de tête avant d'afficher la réponse.

Quelles sont les 3 étapes d'une démonstration par récurrence ?

1. Initialisation, 2. Hérédité, 3. Conclusion.

Dans l'étape d'hérédité, que suppose-t-on et que démontre-t-on ?

On suppose P(k)P(k)P(k) vraie pour un entier fixé k≥n0k \ge n_0k≥n0​, et on démontre que P(k+1)P(k+1)P(k+1) est vraie.

Énoncer l'inégalité de Bernoulli.

Pour tout réel a>0a > 0a>0 et tout n∈Nn \in \mathbb{N}n∈N : (1+a)n≥1+na(1 + a)^n \ge 1 + na(1+a)n≥1+na.

Une propriété héréditaire est-elle forcément vraie ?

Non : il faut aussi l'initialisation. Exemple : « 999 divise 10n+110^n + 110n+1 » est héréditaire mais toujours fausse.

Pour montrer par récurrence que un≤un+1u_n \le u_{n+1}un​≤un+1​ avec un+1=f(un)u_{n+1} = f(u_n)un+1​=f(un​), quelle propriété de fff est utile ?

La croissance de fff sur un intervalle contenant tous les termes de la suite.

Exercices corrigés

Exercice 1 Étape d'initialisation

Palier 1 · découverte

On souhaite démontrer par récurrence pour tout n≥2n \ge 2n≥2 la propriété P(n):2n>n+1P(n) : 2^n > n+1P(n):2n>n+1. Quelle est l'initialisation correcte ?

  1. Pour n=2:22=4n = 2 : 2^2 = 4n=2:22=4 et 2+1=32+1 = 32+1=3. Comme 4>34 > 34>3, P(2)P(2)P(2) est vraie.
  2. Pour n=0:20=1n = 0 : 2^0 = 1n=0:20=1 et 0+1=10+1 = 10+1=1, vrai.
  3. Pour n=1:21=2n = 1 : 2^1 = 2n=1:21=2 et 1+1=21+1 = 21+1=2, vrai.
  4. Pour n=3:23=8n = 3 : 2^3 = 8n=3:23=8 et 3+1=43+1 = 43+1=4, vrai.
Un indice

Le premier rang demandé est n0=2n_0 = 2n0​=2.

Voir la correction

Bonne réponse : A. Pour n=2:22=4n = 2 : 2^2 = 4n=2:22=4 et 2+1=32+1 = 32+1=3. Comme 4>34 > 34>3, P(2)P(2)P(2) est vraie.

Comme l'inégalité doit être démontrée pour n≥2n \ge 2n≥2, l'initialisation se fait au premier rang n=2n = 2n=2 : 22=4>32^2 = 4 > 322=4>3.

Exercice 2 Étape d'hérédité : ce qu'il faut démontrer

Palier 2 · application

On considère la suite définie par u0=0u_0 = 0u0​=0 et un+1=2un+1u_{n+1} = 2u_n + 1un+1​=2un​+1. On veut démontrer par récurrence que, pour tout n∈Nn \in \mathbb{N}n∈N, P(n):un=2n−1P(n) : u_n = 2^n - 1P(n):un​=2n−1.
Dans l'étape d'hérédité, on suppose P(n)P(n)P(n) vraie pour un entier nnn fixé. Que doit-on alors démontrer ?

  1. un+1=2n+1−1u_{n+1} = 2^{n+1} - 1un+1​=2n+1−1
  2. un=2n−1u_n = 2^n - 1un​=2n−1 pour tout entier nnn
  3. un+1=2un+1u_{n+1} = 2u_n + 1un+1​=2un​+1
  4. u0=20−1u_0 = 2^0 - 1u0​=20−1
Un indice

L'hérédité consiste à montrer : si P(n)P(n)P(n) est vraie, alors P(n+1)P(n+1)P(n+1) est vraie.

Voir la correction

Bonne réponse : A. un+1=2n+1−1u_{n+1} = 2^{n+1} - 1un+1​=2n+1−1

Hérédité : on suppose un=2n−1u_n = 2^n - 1un​=2n−1 (hypothèse de récurrence) et on doit montrer P(n+1):un+1=2n+1−1P(n+1) : u_{n+1} = 2^{n+1} - 1P(n+1):un+1​=2n+1−1.
Preuve : un+1=2un+1=2(2n−1)+1=2n+1−2+1=2n+1−1u_{n+1} = 2u_n + 1 = 2(2^n - 1) + 1 = 2^{n+1} - 2 + 1 = 2^{n+1} - 1un+1​=2un​+1=2(2n−1)+1=2n+1−2+1=2n+1−1.
Attention : « un=2n−1u_n = 2^n - 1un​=2n−1 pour tout nnn » est la conclusion de toute la récurrence, pas ce qu'on démontre dans l'hérédité ; un+1=2un+1u_{n+1} = 2u_n + 1un+1​=2un​+1 est la définition de la suite et u0=20−1u_0 = 2^0 - 1u0​=20−1 est l'initialisation.

Exercice 3 Récurrence sur une somme : 1 + 3 + … + (2n − 1) = n²

Palier 3 · approfondissement

Pour n≥1n \ge 1n≥1, on pose Sn=1+3+5+⋯+(2n−1)S_n = 1 + 3 + 5 + \dots + (2n - 1)Sn​=1+3+5+⋯+(2n−1) (somme des nnn premiers entiers impairs) et on veut prouver par récurrence que Sn=n2S_n = n^2Sn​=n2.
En supposant Sn=n2S_n = n^2Sn​=n2, que vaut Sn+1S_{n+1}Sn+1​ ?

  1. Sn+1=n2+2n+1=(n+1)2S_{n+1} = n^2 + 2n + 1 = (n+1)^2Sn+1​=n2+2n+1=(n+1)2
  2. Sn+1=n2+2n−1S_{n+1} = n^2 + 2n - 1Sn+1​=n2+2n−1
  3. Sn+1=n2+2n+3S_{n+1} = n^2 + 2n + 3Sn+1​=n2+2n+3
  4. Sn+1=n2+1S_{n+1} = n^2 + 1Sn+1​=n2+1
Un indice

Sn+1S_{n+1}Sn+1​ s'obtient en ajoutant à SnS_nSn​ le (n+1)(n+1)(n+1)-ième nombre impair, c'est-à-dire 2(n+1)−12(n+1) - 12(n+1)−1.

Voir la correction

Bonne réponse : A. Sn+1=n2+2n+1=(n+1)2S_{n+1} = n^2 + 2n + 1 = (n+1)^2Sn+1​=n2+2n+1=(n+1)2

Initialisation : S1=1=12S_1 = 1 = 1^2S1​=1=12.
Hérédité : supposons Sn=n2S_n = n^2Sn​=n2. Le terme suivant de la somme est 2(n+1)−1=2n+12(n+1) - 1 = 2n + 12(n+1)−1=2n+1, donc
Sn+1=Sn+(2n+1)=n2+2n+1=(n+1)2.S_{n+1} = S_n + (2n + 1) = n^2 + 2n + 1 = (n+1)^2.Sn+1​=Sn​+(2n+1)=n2+2n+1=(n+1)2.
Conclusion : par récurrence, Sn=n2S_n = n^2Sn​=n2 pour tout n≥1n \ge 1n≥1.
Erreur fréquente : ajouter 2n−12n - 12n−1 (le dernier terme de SnS_nSn​, déjà compté) au lieu de 2n+12n + 12n+1.

Exercice 4 Récurrence et divisibilité

Palier 4 · défi

On veut démontrer par récurrence que, pour tout n∈Nn \in \mathbb{N}n∈N, le nombre 4n+24^n + 24n+2 est divisible par 333.
Quelle égalité permet de conclure l'étape d'hérédité à partir de l'hypothèse « 4n+24^n + 24n+2 est divisible par 3 » ?

  1. 4n+1+2=4(4n+2)−64^{n+1} + 2 = 4(4^n + 2) - 64n+1+2=4(4n+2)−6
  2. 4n+1+2=4(4n+2)4^{n+1} + 2 = 4(4^n + 2)4n+1+2=4(4n+2)
  3. 4n+1+2=(4n+2)+34^{n+1} + 2 = (4^n + 2) + 34n+1+2=(4n+2)+3
  4. 4n+1+2=4n+64^{n+1} + 2 = 4^n + 64n+1+2=4n+6
Un indice

Fais apparaître 4n+24^n + 24n+2 dans 4n+1+2=4×4n+24^{n+1} + 2 = 4 \times 4^n + 24n+1+2=4×4n+2.

Voir la correction

Bonne réponse : A. 4n+1+2=4(4n+2)−64^{n+1} + 2 = 4(4^n + 2) - 64n+1+2=4(4n+2)−6

Initialisation : 40+2=34^0 + 2 = 340+2=3, divisible par 3.
Hérédité : supposons 4n+2=3k4^n + 2 = 3k4n+2=3k avec k∈Zk \in \mathbb{Z}k∈Z. Alors
4n+1+2=4×4n+8−6=4(4n+2)−6=12k−6=3(4k−2),4^{n+1} + 2 = 4 \times 4^n + 8 - 6 = 4(4^n + 2) - 6 = 12k - 6 = 3(4k - 2),4n+1+2=4×4n+8−6=4(4n+2)−6=12k−6=3(4k−2),
qui est divisible par 3.
Conclusion : pour tout n∈Nn \in \mathbb{N}n∈N, 333 divise 4n+24^n + 24n+2.
Les autres égalités sont fausses (par exemple 4(4n+2)=4n+1+8≠4n+1+24(4^n + 2) = 4^{n+1} + 8 \neq 4^{n+1} + 24(4n+2)=4n+1+8=4n+1+2).
