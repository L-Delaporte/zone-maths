Cours et exercices corrigés de terminale : Produit scalaire dans l'espace et équations cartésiennes de plans

Objectifs du chapitre

  • Calculer le produit scalaire dans l'espace orthonormé : u⃗⋅v⃗=xx′+yy′+zz′\vec{u}\cdot\vec{v} = xx' + yy' + zz'u⋅v=xx′+yy′+zz′.
  • Déterminer et utiliser l'équation cartésienne d'un plan ax+by+cz+d=0ax + by + cz + d = 0ax+by+cz+d=0 de vecteur normal n⃗(a;b;c)\vec{n}(a ; b ; c)n(a;b;c).
  • Calculer le projeté orthogonal d'un point sur un plan et la distance d'un point à un plan.
  • Calculer une longueur, un angle et démontrer une orthogonalité avec le produit scalaire.
  • Démontrer qu'une droite est orthogonale à un plan.

Le cours

1. Vecteur normal et équation de plan dans l'espace

  • Un vecteur non nul n⃗(abc)\vec{n}\begin{pmatrix} a \\ b \\ c \end{pmatrix}n​abc​​ est normal à un plan P\mathcal{P}P s'il est orthogonal à deux vecteurs directeurs non colinéaires de P\mathcal{P}P.
  • Tout plan de vecteur normal n⃗(a;b;c)\vec{n}(a ; b ; c)n(a;b;c) admet une équation cartésienne de la forme :

ax+by+cz+d=0ax + by + cz + d = 0ax+by+cz+d=0

  • Deux plans sont parallèles ssi leurs vecteurs normaux sont colinéaires. Ils sont perpendiculaires ssi leurs vecteurs normaux sont orthogonaux (n⃗1⋅n⃗2=0\vec{n}_1 \cdot \vec{n}_2 = 0n1​⋅n2​=0).

2. Produit scalaire dans l'espace : définitions et propriétés

  • Deux vecteurs de l'espace sont toujours coplanaires : on définit u⃗⋅v⃗=∥u⃗∥×∥v⃗∥×cos⁡(u⃗,v⃗^)\vec{u} \cdot \vec{v} = \|\vec{u}\| \times \|\vec{v}\| \times \cos(\widehat{\vec{u}, \vec{v}})u⋅v=∥u∥×∥v∥×cos(u,v​) comme dans le plan qui les contient.
  • Formule de polarisation : u⃗⋅v⃗=12(∥u⃗+v⃗∥2−∥u⃗∥2−∥v⃗∥2)\vec{u} \cdot \vec{v} = \frac{1}{2}\left(\|\vec{u} + \vec{v}\|^2 - \|\vec{u}\|^2 - \|\vec{v}\|^2\right)u⋅v=21​(∥u+v∥2−∥u∥2−∥v∥2).
  • En repère orthonormé, pour u⃗(x;y;z)\vec{u}(x ; y ; z)u(x;y;z) et v⃗(x′;y′;z′)\vec{v}(x' ; y' ; z')v(x′;y′;z′) : u⃗⋅v⃗=xx′+yy′+zz′\vec{u} \cdot \vec{v} = xx' + yy' + zz'u⋅v=xx′+yy′+zz′ et ∥u⃗∥=x2+y2+z2\|\vec{u}\| = \sqrt{x^2 + y^2 + z^2}∥u∥=x2+y2+z2​.
  • Le produit scalaire est symétrique et bilinéaire : u⃗⋅(v⃗+kw⃗)=u⃗⋅v⃗+k u⃗⋅w⃗\vec{u} \cdot (\vec{v} + k\vec{w}) = \vec{u} \cdot \vec{v} + k\,\vec{u} \cdot \vec{w}u⋅(v+kw)=u⋅v+ku⋅w.
  • u⃗⊥v⃗  ⟺  u⃗⋅v⃗=0\vec{u} \perp \vec{v} \iff \vec{u} \cdot \vec{v} = 0u⊥v⟺u⋅v=0.

3. Orthogonalité d'une droite et d'un plan

  • Une droite ddd est orthogonale à un plan P\mathcal{P}P si elle est orthogonale à deux droites sécantes de P\mathcal{P}P. Elle est alors orthogonale à toutes les droites de P\mathcal{P}P.
  • De façon équivalente : un vecteur directeur de ddd est normal à P\mathcal{P}P.
  • Le plan passant par AAA et de vecteur normal n⃗\vec{n}n est l'ensemble des points MMM tels que AM→⋅n⃗=0\overrightarrow{AM} \cdot \vec{n} = 0AM⋅n=0.
  • Une droite de vecteur directeur w⃗\vec{w}w est parallèle au plan de vecteur normal n⃗\vec{n}n si et seulement si w⃗⋅n⃗=0\vec{w} \cdot \vec{n} = 0w⋅n=0.

4. Projeté orthogonal et distance

  • Le projeté orthogonal d'un point MMM sur un plan P\mathcal{P}P est le point HHH de P\mathcal{P}P tel que MH→\overrightarrow{MH}MH est colinéaire à un vecteur normal de P\mathcal{P}P (c'est l'intersection de P\mathcal{P}P avec la droite passant par MMM orthogonale à P\mathcal{P}P).
  • HHH est le point de P\mathcal{P}P le plus proche de MMM : pour tout N∈PN \in \mathcal{P}N∈P, MN≥MHMN \ge MHMN≥MH (Pythagore). La distance de MMM au plan est MHMHMH.
  • De même, le projeté orthogonal de MMM sur une droite ddd est le point HHH de ddd tel que MH→\overrightarrow{MH}MH est orthogonal à un vecteur directeur de ddd.

Méthodes et exemples rédigés

Méthode : Trouver l'équation cartésienne d'un plan défini par trois points

Exemple

Déterminer l'équation cartésienne du plan (ABC)(ABC)(ABC) avec A(1;0;0)A(1;0;0)A(1;0;0), B(0;2;0)B(0;2;0)B(0;2;0) et C(0;0;3)C(0;0;3)C(0;0;3).

  1. Étape 1 (Vecteurs directeurs) : AB⃗(−1;2;0)\vec{AB}(-1; 2; 0)AB(−1;2;0) et AC⃗(−1;0;3)\vec{AC}(-1; 0; 3)AC(−1;0;3). Ils ne sont pas colinéaires.

  2. Étape 2 (Vecteur normal n⃗(a;b;c)\vec{n}(a;b;c)n(a;b;c)) : n⃗⋅AB⃗=−a+2b=0  ⟹  a=2b\vec{n} \cdot \vec{AB} = -a + 2b = 0 \implies a = 2bn⋅AB=−a+2b=0⟹a=2b. n⃗⋅AC⃗=−a+3c=0  ⟹  a=3c\vec{n} \cdot \vec{AC} = -a + 3c = 0 \implies a = 3cn⋅AC=−a+3c=0⟹a=3c. En choisissant a=6a = 6a=6, on obtient b=3b = 3b=3 et c=2c = 2c=2. Donc n⃗(6;3;2)\vec{n}(6 ; 3 ; 2)n(6;3;2) est normal.

  3. Étape 3 (Constante d) : 6x+3y+2z+d=06x + 3y + 2z + d = 06x+3y+2z+d=0. Avec A(1;0;0)A(1;0;0)A(1;0;0) : 6(1)+0+0+d=0  ⟹  d=−66(1) + 0 + 0 + d = 0 \implies d = -66(1)+0+0+d=0⟹d=−6.

  4. Conclusion : L'équation est 6x+3y+2z−6=06x + 3y + 2z - 6 = 06x+3y+2z−6=0.

Méthode : Déterminer le projeté orthogonal d'un point sur un plan

Exemple

Soit P:6x+3y+2z−6=0\mathcal{P} : 6x + 3y + 2z - 6 = 0P:6x+3y+2z−6=0 et M(7;3;2)M(7 ; 3 ; 2)M(7;3;2). Déterminer le projeté orthogonal HHH de MMM sur P\mathcal{P}P et la distance MHMHMH.

  1. Étape 1 (Droite orthogonale) : n⃗(6;3;2)\vec{n}(6 ; 3 ; 2)n(6;3;2) est normal à P\mathcal{P}P. La droite Δ\DeltaΔ passant par MMM et dirigée par n⃗\vec{n}n a pour représentation {x=7+6ty=3+3tz=2+2t\begin{cases} x = 7 + 6t \\ y = 3 + 3t \\ z = 2 + 2t \end{cases}⎩⎨⎧​x=7+6ty=3+3tz=2+2t​ (t∈Rt \in \mathbb{R}t∈R).

  2. Étape 2 (Intersection) : on remplace dans l'équation de P\mathcal{P}P : 6(7+6t)+3(3+3t)+2(2+2t)−6=06(7 + 6t) + 3(3 + 3t) + 2(2 + 2t) - 6 = 06(7+6t)+3(3+3t)+2(2+2t)−6=0, soit 42+36t+9+9t+4+4t−6=042 + 36t + 9 + 9t + 4 + 4t - 6 = 042+36t+9+9t+4+4t−6=0, c'est-à-dire 49+49t=049 + 49t = 049+49t=0, donc t=−1t = -1t=−1.

  3. Étape 3 (Coordonnées) : H(7−6;3−3;2−2)=H(1;0;0)H(7 - 6 ; 3 - 3 ; 2 - 2) = H(1 ; 0 ; 0)H(7−6;3−3;2−2)=H(1;0;0). Vérification : 6×1+0+0−6=06 \times 1 + 0 + 0 - 6 = 06×1+0+0−6=0.

  4. Conclusion : MH→(−6;−3;−2)\overrightarrow{MH}(-6 ; -3 ; -2)MH(−6;−3;−2), donc MH=36+9+4=49=7MH = \sqrt{36 + 9 + 4} = \sqrt{49} = 7MH=36+9+4​=49​=7. La distance de MMM au plan P\mathcal{P}P est 777.

Méthode : Calculer un angle géométrique

Exemple

Soient A(1;1;1)A(1 ; 1 ; 1)A(1;1;1), B(2;2;1)B(2 ; 2 ; 1)B(2;2;1) et C(2;1;2)C(2 ; 1 ; 2)C(2;1;2) dans un repère orthonormé. Calculer l'angle BAC^\widehat{BAC}BAC.

  1. Étape 1 (Vecteurs) : AB→(1;1;0)\overrightarrow{AB}(1 ; 1 ; 0)AB(1;1;0) et AC→(1;0;1)\overrightarrow{AC}(1 ; 0 ; 1)AC(1;0;1).

  2. Étape 2 (Produit scalaire et normes) : AB→⋅AC→=1×1+1×0+0×1=1\overrightarrow{AB} \cdot \overrightarrow{AC} = 1 \times 1 + 1 \times 0 + 0 \times 1 = 1AB⋅AC=1×1+1×0+0×1=1 ; AB=2AB = \sqrt{2}AB=2​ et AC=2AC = \sqrt{2}AC=2​.

  3. Étape 3 (Cosinus) : cos⁡(BAC^)=AB→⋅AC→AB×AC=12×2=12\cos(\widehat{BAC}) = \dfrac{\overrightarrow{AB} \cdot \overrightarrow{AC}}{AB \times AC} = \dfrac{1}{\sqrt{2} \times \sqrt{2}} = \dfrac{1}{2}cos(BAC)=AB×ACAB⋅AC​=2​×2​1​=21​.

  4. Conclusion : BAC^=60∘\widehat{BAC} = 60^\circBAC=60∘. Comme BC→(0;−1;1)\overrightarrow{BC}(0 ; -1 ; 1)BC(0;−1;1) donne aussi BC=2BC = \sqrt{2}BC=2​, le triangle ABCABCABC est équilatéral.

Pièges fréquents

  • Dans l'espace, une équation ax+by+c=0ax + by + c = 0ax+by+c=0 ne représente pas une droite mais un plan parallèle à l'axe (Oz)(Oz)(Oz) !
  • Une droite dans l'espace n'a pas une seule équation cartésienne, mais un système paramétrique de 3 équations à 1 paramètre.
  • La formule xx′+yy′+zz′xx' + yy' + zz'xx′+yy′+zz′ n'est valable que dans un repère orthonormé.
  • Un plan a une infinité de vecteurs normaux et d'équations cartésiennes : 6x+3y+2z−6=06x + 3y + 2z - 6 = 06x+3y+2z−6=0 et 12x+6y+4z−12=012x + 6y + 4z - 12 = 012x+6y+4z−12=0 désignent le même plan.
  • Un vecteur orthogonal à un seul vecteur directeur du plan n'est pas forcément normal : il doit être orthogonal à deux vecteurs non colinéaires du plan.

Exercice 1 Équation cartésienne de plan

Palier 1 · découverte

Quelle est l'équation cartésienne du plan passant par A(1;2;3)A(1 ; 2 ; 3)A(1;2;3) et de vecteur normal n⃗(2;−1;4)\vec{n}(2 ; -1 ; 4)n(2;−1;4) ?

  1. 2x−y+4z−12=02x - y + 4z - 12 = 02x−y+4z−12=0
  2. 2x−y+4z+12=02x - y + 4z + 12 = 02x−y+4z+12=0
  3. x+2y+3z−14=0x + 2y + 3z - 14 = 0x+2y+3z−14=0
  4. 2x+y+4z−16=02x + y + 4z - 16 = 02x+y+4z−16=0
Un indice

L'équation est 2x−y+4z+d=02x - y + 4z + d = 02x−y+4z+d=0.

Voir la correction

Bonne réponse : A. 2x−y+4z−12=02x - y + 4z - 12 = 02x−y+4z−12=0

2x−y+4z+d=02x - y + 4z + d = 02x−y+4z+d=0. Le point A(1;2;3)A(1;2;3)A(1;2;3) vérifie : 2(1)−2+4(3)+d=0  ⟺  12+d=0  ⟺  d=−122(1) - 2 + 4(3) + d = 0 \iff 12 + d = 0 \iff d = -122(1)−2+4(3)+d=0⟺12+d=0⟺d=−12. Donc 2x−y+4z−12=02x - y + 4z - 12 = 02x−y+4z−12=0.

Exercice 2 Orthogonalité de deux plans

Palier 2 · application

Les plans P1:3x−2y+z−4=0\mathcal{P}_1 : 3x - 2y + z - 4 = 0P1​:3x−2y+z−4=0 et P2:2x+4y+2z+7=0\mathcal{P}_2 : 2x + 4y + 2z + 7 = 0P2​:2x+4y+2z+7=0 sont-ils orthogonaux ?

  1. Oui, car n⃗1⋅n⃗2=0\vec{n}_1 \cdot \vec{n}_2 = 0n1​⋅n2​=0
  2. Non, car n⃗1⋅n⃗2=16≠0\vec{n}_1 \cdot \vec{n}_2 = 16 \ne 0n1​⋅n2​=16=0
  3. Non, ils sont parallèles
  4. On ne peut pas conclure
Un indice

n⃗1(3;−2;1)\vec{n}_1(3 ; -2 ; 1)n1​(3;−2;1) et n⃗2(2;4;2)\vec{n}_2(2 ; 4 ; 2)n2​(2;4;2).

Voir la correction

Bonne réponse : A. Oui, car n⃗1⋅n⃗2=0\vec{n}_1 \cdot \vec{n}_2 = 0n1​⋅n2​=0

n⃗1⋅n⃗2=3(2)+(−2)(4)+1(2)=6−8+2=0\vec{n}_1 \cdot \vec{n}_2 = 3(2) + (-2)(4) + 1(2) = 6 - 8 + 2 = 0n1​⋅n2​=3(2)+(−2)(4)+1(2)=6−8+2=0. Les vecteurs normaux sont orthogonaux, donc les plans sont perpendiculaires.
