Objectifs du chapitre

  • Utiliser des variables et des affectations successives ; écrire et appeler une fonction.
  • Créer une liste en extension, par ajouts successifs ou en compréhension ; accéder à un élément par son indice.
  • Parcourir une liste avec une boucle for ; utiliser une boucle while pour déterminer un seuil.
  • Programmer un compteur et un accumulateur (somme, produit, moyenne).
  • Simuler une expérience de Bernoulli et sélectionner des données selon un critère.

Le cours

1. Variables, affectations, fonctions

  • L'instruction a = a + 3 calcule d'abord a + 3 avec l'ancienne valeur, puis range le résultat dans a : le signe = est une affectation, le test d'égalité s'écrit ==.
  • Une fonction reçoit des paramètres et renvoie un résultat avec return :
def prix_ttc(ht):
    return ht * 1.2

L'appel prix_ttc(50) renvoie 60.0.

2. Listes

  • En extension : L = [4, 7, 1] ; len(L) vaut 333.
  • Les indices commencent à 000 : L[0] vaut 444, L[2] vaut 111 ; L[-1] est le dernier élément.
  • Par ajouts successifs : on part de L = [] et on écrit L.append(x) dans une boucle.
  • En compréhension : [k**2 for k in range(5)] donne [0, 1, 4, 9, 16] et [x for x in L if x > 3] ne garde que les éléments supérieurs à 333.

3. Boucles

  • for k in range(n) fait prendre à k les valeurs 000, 111, …, n−1n - 1n−1 ; range(1, n + 1) va de 111 à nnn.
  • for x in L parcourt directement les éléments de la liste ; for i in range(len(L)) parcourt ses indices.
  • while condition: répète tant que la condition est vraie : on l'utilise lorsque le nombre de tours n'est pas connu à l'avance (recherche d'un seuil).

4. Compteurs et accumulateurs

  • Un compteur est initialisé à 000 et augmenté de 111 chaque fois qu'une condition est réalisée.
  • Un accumulateur de somme est initialisé à 000 ; un accumulateur de produit est initialisé à 111.
s = 0
c = 0
for x in L:
    s = s + x
    if x >= 10:
        c = c + 1
moyenne = s / len(L)

5. Hasard et simulation

  • from random import random, randint : random() renvoie un nombre décimal au hasard dans [0;1[[0 ; 1[[0;1[ et randint(a, b) un entier au hasard entre aaa et bbb inclus.
  • Le test random() < p est vrai avec la probabilité ppp : il simule une épreuve de Bernoulli de paramètre ppp.
  • En répétant l'épreuve un grand nombre de fois avec un compteur, la fréquence des succès est en général proche de ppp.

Méthodes et exemples rédigés

Méthode : Suivre l'exécution d'une boucle

Exemple

Que vaut p après l'exécution du programme ?

p = 1
for k in range(1, 5):
    p = p * k

  1. Étape 1 (initialisation) : p vaut 111 (accumulateur de produit).

  2. Étape 2 (tableau de suivi) : k=1k = 1k=1 : p=1p = 1p=1 ; k=2k = 2k=2 : p=2p = 2p=2 ; k=3k = 3k=3 : p=6p = 6p=6 ; k=4k = 4k=4 : p=24p = 24p=24.

  3. Conclusion : la boucle s'arrête avant 555, donc p vaut 24=1×2×3×424 = 1 \times 2 \times 3 \times 424=1×2×3×4.

Méthode : Compter les éléments qui vérifient une condition

Exemple

Écrire une fonction qui compte les notes supérieures ou égales à 101010 dans une liste.

  1. Étape 1 : initialiser un compteur c = 0.

  2. Étape 2 : parcourir la liste avec for x in notes: et ajouter 111 lorsque x >= 10.

  3. Conclusion :

    def nb_admis(notes):
    c = 0
    for x in notes:
        if x >= 10:
            c = c + 1
    return c

    Pour [8, 12, 15, 9, 10], la fonction renvoie 333.

Méthode : Estimer une probabilité par simulation

Exemple

Un tireur atteint la cible avec la probabilité 0,70{,}70,7. Estimer cette probabilité sur 100010001000 tirs simulés.

  1. Étape 1 : une épreuve se simule par le test random() < 0.7.

  2. Étape 2 : un compteur ajoute 111 à chaque succès, dans une boucle de 100010001000 tours.

  3. Conclusion :

    from random import random
c = 0
for i in range(1000):
    if random() < 0.7:
        c = c + 1
print(c / 1000)

    La fréquence affichée change à chaque exécution, mais reste en général proche de 0,70{,}70,7.

Pièges fréquents

  • Le premier élément d'une liste a l'indice 000 : dans L = [5, 8, 2], L[1] vaut 888 et L[3] provoque une erreur.
  • range(1, 5) s'arrête à 444 : la borne de droite est exclue.
  • Un accumulateur de produit s'initialise à 111, pas à 000 (sinon le produit reste nul).
  • print affiche une valeur, return la renvoie pour qu'elle soit réutilisée : une fonction de calcul doit se terminer par return.

Questions de révision

Essaie de répondre de tête avant d'afficher la réponse.

Indice du premier élément d'une liste ?

000.

Valeurs prises par k dans for k in range(4) ?

000, 111, 222 et 333.

Que fait L.append(x) ?

Elle ajoute x à la fin de la liste L.

Que donne [2 * k for k in range(4)] ?

[0, 2, 4, 6].

Valeur initiale d'un accumulateur de somme ? de produit ?

000 pour une somme, 111 pour un produit.

À quoi sert un compteur ?

À compter le nombre de fois qu'une condition est réalisée : on l'initialise à 000 et on ajoute 111 à chaque fois.

Quand utiliser while plutôt que for ?

Lorsque le nombre de tours n'est pas connu à l'avance, par exemple pour chercher un seuil.

Comment simuler une épreuve de Bernoulli de paramètre 0,30{,}30,3 ?

Avec le test random() < 0.3, vrai avec la probabilité 0,30{,}30,3.

Différence entre = et == ?

= affecte une valeur à une variable ; == teste l'égalité et renvoie True ou False.

Comment calculer la moyenne des éléments d'une liste L ?

On calcule la somme avec un accumulateur, puis on la divise par len(L).

Exercices corrigés

Exercice 1 Indice dans une liste

Palier 1 · découverte

Qu'affiche le programme suivant ?

L = [4, 7, 1, 9, 3]
print(L[2])
  1. 999
  2. 777
  3. 333
  4. 111
Un indice

En Python, les indices d'une liste commencent à 000 : le premier élément a l'indice 000, le suivant a l'indice suivant, et ainsi de suite.

Voir la correction

Bonne réponse : D. 111

Les indices sont 000, 111, 222, … : L[0] = 4, L[1] = 7, L[2] = 1. Le programme affiche 111. Répondre 777 revient à oublier que l'on commence à 000.

Exercice 2 Accumulateur de somme

Palier 2 · application

Que vaut s à la fin du programme ?

s = 0
for k in range(1, 5):
    s = s + k * k
  1. 555555
  2. 303030
  3. 141414
  4. 101010
Un indice

range(a, b) va de aaa à b−1b - 1b−1 ; à chaque tour, on ajoute la quantité calculée à l'accumulateur.

Voir la correction

Bonne réponse : B. 303030

k prend les valeurs 111, 222, 333 et 444, donc s = 1 + 4 + 9 + 16 = 30. (555555 correspondrait à aller jusqu'à 555 et 101010 à la somme des k sans les élever au carré.)

Exercice 3 Compteur conditionnel

Palier 3 · approfondissement

Que vaut c à la fin du programme ?

L = [12, 5, 18, 7, 20, 9]
c = 0
for x in L:
    if x >= 10:
        c = c + 1
  1. 505050
  2. 222
  3. 666
  4. 333
Un indice

Un compteur augmente de 111 seulement lorsque la condition est vraie ; il ne cumule pas les valeurs.

Voir la correction

Bonne réponse : D. 333

Les éléments supérieurs ou égaux à 101010 sont 121212, 181818 et 202020 : c vaut 333. (505050 serait leur somme, et 666 le nombre total d'éléments.)

Exercice 4 Boucle de seuil

Palier 4 · défi

Une somme de 100100100 euros augmente de 10 %10\,\%10% par an. Que vaut n à la fin du programme ?

u = 100
n = 0
while u < 200:
    u = u * 1.1
    n = n + 1
  1. 999
  2. 777
  3. 888
  4. 101010
Un indice

La boucle s'arrête au premier tour où la condition devient fausse ; n compte les tours effectués.

Voir la correction

Bonne réponse : C. 888

On trouve successivement 110110110 ; 121121121 ; 133,1133{,}1133,1 ; 146,41146{,}41146,41 ; 161,05161{,}05161,05 ; 177,16177{,}16177,16 ; 194,87194{,}87194,87 (pour n=7n = 7n=7), puis 214,36214{,}36214,36 pour n=8n = 8n=8. La somme double donc au bout de 888 ans, et n vaut 888. Avec 101010 ans, on aurait ajouté 10 %10\,\%10% de 100100100 chaque année, ce qui est un raisonnement arithmétique.
