Objectifs du chapitre

  • Calculer un taux de variation et l'interpréter comme la pente d'une sécante.
  • Connaître l'allure de la courbe d'une fonction polynôme du second degré selon le signe de aaa, pour les formes ax2ax^2ax2, ax2+cax^2 + cax2+c et a(x−x1)(x−x2)a(x - x_1)(x - x_2)a(x−x1​)(x−x2​).
  • Déterminer l'axe de symétrie et le sommet d'une parabole ; dresser le tableau de variations.
  • Vérifier qu'un nombre est une racine et factoriser complètement un polynôme du second degré connaissant une racine.
  • Étudier le signe d'une fonction du second degré à partir de sa forme factorisée et résoudre une inéquation.

Le cours

1. Taux de variation

  • Le taux de variation de fff entre aaa et bbb (avec a≠ba \neq ba=b) est f(b)−f(a)b−a\frac{f(b) - f(a)}{b - a}b−af(b)−f(a)​.
  • C'est la pente (coefficient directeur) de la sécante passant par les points de la courbe d'abscisses aaa et bbb.
  • S'il est positif, f(b)>f(a)f(b) > f(a)f(b)>f(a) pour a<ba < ba<b : la fonction a augmenté « en moyenne » entre aaa et bbb.
  • Pour une fonction affine x↦mx+px \mapsto mx + px↦mx+p, le taux de variation vaut toujours mmm.

2. Fonctions polynômes du second degré

  • Une fonction du second degré s'écrit f(x)=ax2+bx+cf(x) = ax^2 + bx + cf(x)=ax2+bx+c avec a≠0a \neq 0a=0 ; sa courbe est une parabole.
  • Si a>0a > 0a>0, la parabole est tournée vers le haut et fff admet un minimum ; si a<0a < 0a<0, elle est tournée vers le bas et fff admet un maximum.
  • Le sommet S(α;β)S(\alpha ; \beta)S(α;β) correspond à cet extremum ; la droite d'équation x=αx = \alphax=α est l'axe de symétrie de la parabole.

3. Formes particulières

  • f(x)=ax2f(x) = ax^2f(x)=ax2 : sommet O(0;0)O(0 ; 0)O(0;0), axe x=0x = 0x=0.
  • f(x)=ax2+cf(x) = ax^2 + cf(x)=ax2+c : sommet (0;c)(0 ; c)(0;c), axe x=0x = 0x=0.
  • f(x)=a(x−x1)(x−x2)f(x) = a(x - x_1)(x - x_2)f(x)=a(x−x1​)(x−x2​) : les racines sont x1x_1x1​ et x2x_2x2​ (la courbe coupe l'axe des abscisses en ces points), l'axe de symétrie est x=x1+x22x = \frac{x_1 + x_2}{2}x=2x1​+x2​​ et le sommet a pour ordonnée f(x1+x22)f\left(\frac{x_1 + x_2}{2}\right)f(2x1​+x2​​).

4. Symétrie et tableau de variations

  • Si f(x1)=f(x2)f(x_1) = f(x_2)f(x1​)=f(x2​) avec x1≠x2x_1 \neq x_2x1​=x2​, l'axe de symétrie passe par le milieu : α=x1+x22\alpha = \frac{x_1 + x_2}{2}α=2x1​+x2​​.
  • Pour a>0a > 0a>0 : fff est décroissante sur ]−∞;α]]-\infty ; \alpha]]−∞;α] puis croissante sur [α;+∞[[\alpha ; +\infty[[α;+∞[.
  • Pour a<0a < 0a<0 : fff est croissante sur ]−∞;α]]-\infty ; \alpha]]−∞;α] puis décroissante sur [α;+∞[[\alpha ; +\infty[[α;+∞[.

5. Racines et factorisation

  • x1x_1x1​ est une racine de fff lorsque f(x1)=0f(x_1) = 0f(x1​)=0 : on le vérifie par un calcul.
  • Si x1x_1x1​ est une racine de f(x)=ax2+bx+cf(x) = ax^2 + bx + cf(x)=ax2+bx+c, alors f(x)=a(x−x1)(x−x2)f(x) = a(x - x_1)(x - x_2)f(x)=a(x−x1​)(x−x2​) ; en développant, le terme constant vaut a×x1×x2=ca \times x_1 \times x_2 = ca×x1​×x2​=c, ce qui donne l'autre racine x2x_2x2​.

Exemple : f(x)=2x2−2x−12f(x) = 2x^2 - 2x - 12f(x)=2x2−2x−12 et f(3)=0f(3) = 0f(3)=0 ; 2×3×x2=−122 \times 3 \times x_2 = -122×3×x2​=−12 donne x2=−2x_2 = -2x2​=−2, donc f(x)=2(x−3)(x+2)f(x) = 2(x - 3)(x + 2)f(x)=2(x−3)(x+2).

6. Signe d'une forme factorisée

  • Pour x1<x2x_1 < x_2x1​<x2​, a(x−x1)(x−x2)a(x - x_1)(x - x_2)a(x−x1​)(x−x2​) est du signe de aaa à l'extérieur des racines et du signe contraire entre les racines (tableau de signes).
  • Exemple : −2(x+1)(x−4)⩾0-2(x + 1)(x - 4) \geqslant 0−2(x+1)(x−4)⩾0 équivaut à x∈[−1;4]x \in [-1 ; 4]x∈[−1;4], car a=−2<0a = -2 < 0a=−2<0.

Méthodes et exemples rédigés

Méthode : Calculer un taux de variation

Exemple

Soit f(x)=x2−3xf(x) = x^2 - 3xf(x)=x2−3x. Calculer le taux de variation de fff entre 111 et 444.

  1. Étape 1 (images) : f(1)=1−3=−2f(1) = 1 - 3 = -2f(1)=1−3=−2 et f(4)=16−12=4f(4) = 16 - 12 = 4f(4)=16−12=4.

  2. Étape 2 (quotient) : f(4)−f(1)4−1=4−(−2)3=63=2\frac{f(4) - f(1)}{4 - 1} = \frac{4 - (-2)}{3} = \frac{6}{3} = 24−1f(4)−f(1)​=34−(−2)​=36​=2.

  3. Conclusion : le taux de variation vaut 222 : la sécante passant par les points d'abscisses 111 et 444 a pour pente 222.

Méthode : Sommet et tableau de variations d'une forme factorisée

Exemple

Soit f(x)=−(x−1)(x−5)f(x) = -(x - 1)(x - 5)f(x)=−(x−1)(x−5). Déterminer le sommet de la parabole et le tableau de variations de fff.

  1. Étape 1 (axe) : les racines sont 111 et 555, donc α=1+52=3\alpha = \frac{1 + 5}{2} = 3α=21+5​=3.

  2. Étape 2 (sommet) : β=f(3)=−(3−1)(3−5)=−2×(−2)=4\beta = f(3) = -(3 - 1)(3 - 5) = -2 \times (-2) = 4β=f(3)=−(3−1)(3−5)=−2×(−2)=4 ; le sommet est S(3;4)S(3 ; 4)S(3;4).

  3. Conclusion : a=−1<0a = -1 < 0a=−1<0, donc fff est croissante sur ]−∞;3]]-\infty ; 3]]−∞;3] et décroissante sur [3;+∞[[3 ; +\infty[[3;+∞[ ; son maximum est 444, atteint en x=3x = 3x=3.

Méthode : Factoriser connaissant une racine, puis étudier le signe

Exemple

Soit f(x)=x2+2x−8f(x) = x^2 + 2x - 8f(x)=x2+2x−8. Vérifier que 222 est une racine, factoriser f(x)f(x)f(x) et résoudre f(x)<0f(x) < 0f(x)<0.

  1. Étape 1 (vérification) : f(2)=4+4−8=0f(2) = 4 + 4 - 8 = 0f(2)=4+4−8=0.

  2. Étape 2 (autre racine) : f(x)=1×(x−2)(x−x2)f(x) = 1 \times (x - 2)(x - x_2)f(x)=1×(x−2)(x−x2​) et 1×2×x2=−81 \times 2 \times x_2 = -81×2×x2​=−8, d'où x2=−4x_2 = -4x2​=−4 : f(x)=(x−2)(x+4)f(x) = (x - 2)(x + 4)f(x)=(x−2)(x+4).

  3. Étape 3 (signe) : a=1>0a = 1 > 0a=1>0, donc f(x)f(x)f(x) est négatif entre les racines −4-4−4 et 222.

  4. Conclusion : l'ensemble des solutions de f(x)<0f(x) < 0f(x)<0 est ]−4;2[]-4 ; 2[]−4;2[.

Pièges fréquents

  • Dans un taux de variation, garder le même ordre en haut et en bas : f(b)−f(a)b−a\frac{f(b) - f(a)}{b - a}b−af(b)−f(a)​, et non f(b)−f(a)a−b\frac{f(b) - f(a)}{a - b}a−bf(b)−f(a)​.
  • −32=−9-3^2 = -9−32=−9 alors que (−3)2=9(-3)^2 = 9(−3)2=9 : mettre les nombres négatifs entre parenthèses lorsqu'on calcule une image.
  • Le signe de a(x−x1)(x−x2)a(x - x_1)(x - x_2)a(x−x1​)(x−x2​) entre les racines dépend du signe de aaa : un tableau de signes évite les erreurs.
  • En factorisant, ne pas oublier le coefficient aaa : 2x2−2x−12=2(x−3)(x+2)2x^2 - 2x - 12 = 2(x - 3)(x + 2)2x2−2x−12=2(x−3)(x+2), et non (x−3)(x+2)(x - 3)(x + 2)(x−3)(x+2).

Exercice 1 Taux de variation

Palier 1 · découverte

Soit fff la fonction carré : f(x)=x2f(x) = x^2f(x)=x2. Calculer le taux de variation de fff entre 111 et 444.

  1. 666
  2. 555
  3. 151515
  4. 333
Un indice

Le taux de variation entre aaa et bbb est f(b)−f(a)b−a\frac{f(b) - f(a)}{b - a}b−af(b)−f(a)​ : la variation des images divisée par la variation des abscisses.

Voir la correction

Bonne réponse : B. 555

f(4)−f(1)4−1=16−13=153=5\frac{f(4) - f(1)}{4 - 1} = \frac{16 - 1}{3} = \frac{15}{3} = 54−1f(4)−f(1)​=316−1​=315​=5. La sécante passant par les points (1;1)(1 ; 1)(1;1) et (4;16)(4 ; 16)(4;16) a pour pente 555. (151515 est la variation des images, sans division.)

Exercice 2 Racines d'une forme factorisée

Palier 2 · application

Soit f(x)=3(x−2)(x+5)f(x) = 3(x - 2)(x + 5)f(x)=3(x−2)(x+5). Quel est l'ensemble des solutions de l'équation f(x)=0f(x) = 0f(x)=0 ?

  1. {−5;2}\{-5 ; 2\}{−5;2}
  2. {2;5}\{2 ; 5\}{2;5}
  3. {−5;2;3}\{-5 ; 2 ; 3\}{−5;2;3}
  4. {−2;5}\{-2 ; 5\}{−2;5}
Un indice

Un produit est nul si et seulement si l'un au moins de ses facteurs est nul ; un coefficient non nul ne s'annule jamais.

Voir la correction

Bonne réponse : A. {−5;2}\{-5 ; 2\}{−5;2}

f(x)=0  ⟺  x−2=0f(x) = 0 \iff x - 2 = 0f(x)=0⟺x−2=0 ou x+5=0  ⟺  x=2x + 5 = 0 \iff x = 2x+5=0⟺x=2 ou x=−5x = -5x=−5. L'ensemble des solutions est {−5;2}\{-5 ; 2\}{−5;2} ; le coefficient 333 n'est pas une solution.
