Objectifs du chapitre

  • Calculer des dérivées usuelles, composées et des dérivées partielles.
  • Écrire la différentielle totale et la différentielle logarithmique d'une fonction de plusieurs variables.
  • Propager des incertitudes de mesure.
  • Utiliser les développements limités usuels et le logarithme décimal (pH).

Le cours

1. Dérivées

Dérivées usuelles : (xn)′=nxn−1(x^n)' = nx^{n-1}(xn)′=nxn−1, (ex)′=ex(e^x)' = e^x(ex)′=ex, (ln⁡x)′=1x(\ln x)' = \dfrac{1}{x}(lnx)′=x1​, (x)′=12x(\sqrt{x})' = \dfrac{1}{2\sqrt{x}}(x​)′=2x​1​.
Composées : (eu)′=u′eu(e^u)' = u'e^u(eu)′=u′eu, (ln⁡u)′=u′u(\ln u)' = \dfrac{u'}{u}(lnu)′=uu′​, (un)′=nu′un−1(u^n)' = nu'u^{n-1}(un)′=nu′un−1.
Exemple : C(t)=C0e−ktC(t) = C_0 e^{-kt}C(t)=C0​e−kt a pour dérivée C′(t)=−kC0e−kt=−kC(t)C'(t) = -kC_0e^{-kt} = -kC(t)C′(t)=−kC0​e−kt=−kC(t).

2. Dérivées partielles et différentielle totale

Pour f(x,y)f(x, y)f(x,y), la dérivée partielle ∂f∂x\dfrac{\partial f}{\partial x}∂x∂f​ se calcule en dérivant par rapport à xxx, yyy étant traité comme une constante.
Différentielle totale : df=∂f∂xdx+∂f∂ydy.df = \dfrac{\partial f}{\partial x}dx + \dfrac{\partial f}{\partial y}dy.df=∂x∂f​dx+∂y∂f​dy.
Incertitude absolue (majorant) : Δf=∣∂f∂x∣Δx+∣∂f∂y∣Δy\Delta f = \left|\dfrac{\partial f}{\partial x}\right|\Delta x + \left|\dfrac{\partial f}{\partial y}\right|\Delta yΔf=​∂x∂f​​Δx+​∂y∂f​​Δy.

3. Différentielle logarithmique

Pour un produit de puissances f=k xaybzcf = k\,x^a y^b z^cf=kxaybzc : ln⁡f=ln⁡k+aln⁡x+bln⁡y+cln⁡z\ln f = \ln k + a\ln x + b\ln y + c\ln zlnf=lnk+alnx+blny+clnz, donc dff=adxx+bdyy+cdzz.\dfrac{df}{f} = a\dfrac{dx}{x} + b\dfrac{dy}{y} + c\dfrac{dz}{z}.fdf​=axdx​+bydy​+czdz​.
Incertitude relative : Δff=∣a∣Δxx+∣b∣Δyy+∣c∣Δzz\dfrac{\Delta f}{f} = |a|\dfrac{\Delta x}{x} + |b|\dfrac{\Delta y}{y} + |c|\dfrac{\Delta z}{z}fΔf​=∣a∣xΔx​+∣b∣yΔy​+∣c∣zΔz​ : les incertitudes relatives s'ajoutent, pondérées par la valeur absolue des exposants (même pour un quotient).
Exemple : IMC=mh2IMC = \dfrac{m}{h^2}IMC=h2m​ donne ΔIMCIMC=Δmm+2Δhh\dfrac{\Delta IMC}{IMC} = \dfrac{\Delta m}{m} + 2\dfrac{\Delta h}{h}IMCΔIMC​=mΔm​+2hΔh​.

4. Approximations et logarithme décimal

Au voisinage de 000 : ex≈1+x+x22e^x \approx 1 + x + \dfrac{x^2}{2}ex≈1+x+2x2​, ln⁡(1+x)≈x−x22\ln(1 + x) \approx x - \dfrac{x^2}{2}ln(1+x)≈x−2x2​, (1+x)α≈1+αx(1 + x)^\alpha \approx 1 + \alpha x(1+x)α≈1+αx, donc 1+x≈1+x2\sqrt{1 + x} \approx 1 + \dfrac{x}{2}1+x​≈1+2x​.
Approximation affine : f(a+h)≈f(a)+f′(a)hf(a + h) \approx f(a) + f'(a)hf(a+h)≈f(a)+f′(a)h.
Logarithme décimal : log⁡x=ln⁡xln⁡10\log x = \dfrac{\ln x}{\ln 10}logx=ln10lnx​, log⁡(10n)=n\log(10^n) = nlog(10n)=n. pH=−log⁡[H3O+]pH = -\log[H_3O^+]pH=−log[H3​O+] ; pH=pKa+log⁡[A−][AH]pH = pK_a + \log\dfrac{[A^-]}{[AH]}pH=pKa​+log[AH][A−]​. Comme d(log⁡c)=dccln⁡10d(\log c) = \dfrac{dc}{c \ln 10}d(logc)=cln10dc​, une erreur relative Δcc\dfrac{\Delta c}{c}cΔc​ donne ΔpH=1ln⁡10Δcc\Delta pH = \dfrac{1}{\ln 10}\dfrac{\Delta c}{c}ΔpH=ln101​cΔc​.

5. Aux partiels : pièges fréquents

  • Soustraire les incertitudes relatives pour un quotient : elles s'ajoutent toujours.
  • Oublier l'exposant : le rayon intervient à la puissance 444 dans la loi de Poiseuille, donc avec un coefficient 444.
  • Appliquer la différentielle logarithmique à une somme : elle ne s'applique qu'aux produits et quotients ; pour une somme, les incertitudes absolues s'ajoutent.
  • Confondre ln⁡\lnln et log⁡\loglog dans le calcul d'un pH.

Méthodes et exemples rédigés

Méthode : Incertitude relative par la différentielle logarithmique

Exemple

Le volume d'une sphère est V=43πr3V = \dfrac{4}{3}\pi r^3V=34​πr3, avec r=2,0±0,1r = 2{,}0 \pm 0{,}1r=2,0±0,1 cm. Incertitude relative sur VVV ?

  1. Étape 1 (Logarithme) : ln⁡V=ln⁡4π3+3ln⁡r\ln V = \ln\dfrac{4\pi}{3} + 3\ln rlnV=ln34π​+3lnr.

  2. Étape 2 (Différentier) : dVV=3drr\dfrac{dV}{V} = 3\dfrac{dr}{r}VdV​=3rdr​.

  3. Étape 3 (Conclure) : ΔVV=3×0,12,0=0,15\dfrac{\Delta V}{V} = 3 \times \dfrac{0{,}1}{2{,}0} = 0{,}15VΔV​=3×2,00,1​=0,15, soit 15 %15\,\%15%.

Méthode : Calculer un pH

Exemple

Une solution a [H3O+]=2×10−4[H_3O^+] = 2 \times 10^{-4}[H3​O+]=2×10−4 mol/L. Calculer son pH (on donne log⁡2≈0,301\log 2 \approx 0{,}301log2≈0,301).

  1. Étape 1 (Propriétés du log) : log⁡(2×10−4)=log⁡2−4\log(2 \times 10^{-4}) = \log 2 - 4log(2×10−4)=log2−4.

  2. Étape 2 (Calculer) : pH=−(0,301−4)=3,699pH = -(0{,}301 - 4) = 3{,}699pH=−(0,301−4)=3,699.

  3. Étape 3 (Arrondir) : pH≈3,70pH \approx 3{,}70pH≈3,70.

Pièges fréquents

  • La différentielle logarithmique donne une incertitude relative ; multipliez par la valeur de fff pour obtenir l'incertitude absolue.
  • Dans une dérivée partielle par rapport à xxx, les autres variables sont des constantes : ∂∂x(x2y)=2xy\dfrac{\partial}{\partial x}(x^2 y) = 2xy∂x∂​(x2y)=2xy.
  • Une variation de 111 unité de pH correspond à un facteur 101010 sur la concentration.

Exercice 1 Dérivée d'un logarithme

Palier 1 · découverte

Soit f(x)=ln⁡(3x+1)f(x) = \ln(3x + 1)f(x)=ln(3x+1) pour x>−13x > -\dfrac{1}{3}x>−31​.
Calculez f′(1)f'(1)f′(1) (fraction a/ba/ba/b).

Un indice

Appliquez la dérivée de ln⁡u\ln ulnu avec u(x)=3x+1u(x) = 3x + 1u(x)=3x+1.

Voir la correction

Réponse attendue : 3/4

(ln⁡u)′=u′u(\ln u)' = \dfrac{u'}{u}(lnu)′=uu′​ avec u′=3u' = 3u′=3 : f′(x)=33x+1f'(x) = \dfrac{3}{3x + 1}f′(x)=3x+13​.
f′(1)=34f'(1) = \dfrac{3}{4}f′(1)=43​, soit 3/43/43/4.

Exercice 3 Incertitude sur l'IMC

Un patient pèse m=80±1m = 80 \pm 1m=80±1 kg et mesure h=1,80±0,01h = 1{,}80 \pm 0{,}01h=1,80±0,01 m. L'indice de masse corporelle est IMC=mh2IMC = \dfrac{m}{h^2}IMC=h2m​.

Un indice

Réponse attendue : 2.4

Δmm=180=0,012 5\dfrac{\Delta m}{m} = \dfrac{1}{80} = 0{,}012\,5mΔm​=801​=0,0125 et 2Δhh=0,021,80≈0,011 12\dfrac{\Delta h}{h} = \dfrac{0{,}02}{1{,}80} \approx 0{,}011\,12hΔh​=1,800,02​≈0,0111.
ΔIMCIMC≈0,023 6\dfrac{\Delta IMC}{IMC} \approx 0{,}023\,6IMCΔIMC​≈0,0236, soit 2,4 %2{,}4\,\%2,4% (les incertitudes relatives s'ajoutent, même pour un quotient).
