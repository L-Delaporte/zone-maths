Le cours

1. Espérance, variance et écart-type

Pour une variable aléatoire XXX prenant les valeurs x1,x2,…,xkx_1, x_2, \dots, x_kx1​,x2​,…,xk​ avec les probabilités pi=P(X=xi)p_i = P(X = x_i)pi​=P(X=xi​) :

  • Espérance mathématique (moyenne pondérée sur le long terme) :

E(X)=∑i=1kxipi=x1p1+x2p2+⋯+xkpkE(X) = \sum_{i=1}^k x_i p_i = x_1 p_1 + x_2 p_2 + \dots + x_k p_kE(X)=i=1∑k​xi​pi​=x1​p1​+x2​p2​+⋯+xk​pk​

  • Variance (mesure de la dispersion par rapport à la moyenne) :

V(X)=∑i=1k(xi−E(X))2pi=E(X2)−(E(X))2(formule de Ko¨nig-Huygens)V(X) = \sum_{i=1}^k (x_i - E(X))^2 p_i = E(X^2) - (E(X))^2 \quad \text{(formule de König-Huygens)}V(X)=i=1∑k​(xi​−E(X))2pi​=E(X2)−(E(X))2(formule de Ko¨nig-Huygens)

  • Écart-type : σ(X)=V(X)\sigma(X) = \sqrt{V(X)}σ(X)=V(X)​ (même unité que XXX).

2. Transformation affine aX+baX + baX+b

Pour tous réels aaa et bbb, par linéarité de l'espérance :
E(aX+b)=aE(X)+bE(aX + b) = a E(X) + bE(aX+b)=aE(X)+b
Pour aller plus loin (non exigible en première) : V(aX+b)=a2V(X)V(aX + b) = a^2 V(X)V(aX+b)=a2V(X) et σ(aX+b)=∣a∣ σ(X)\sigma(aX + b) = |a|\,\sigma(X)σ(aX+b)=∣a∣σ(X).

3. Variable aléatoire et loi de probabilité

Une variable aléatoire XXX sur un univers fini Ω\OmegaΩ est une fonction qui associe un nombre réel à chaque issue.

  • L'événement {X=xi}\{X = x_i\}{X=xi​} regroupe les issues pour lesquelles XXX prend la valeur xix_ixi​.
  • La loi de probabilité de XXX est la donnée des valeurs xix_ixi​ et des probabilités pi=P(X=xi)p_i = P(X = x_i)pi​=P(X=xi​), souvent présentée dans un tableau. On a toujours p1+p2+⋯+pk=1p_1 + p_2 + \dots + p_k = 1p1​+p2​+⋯+pk​=1.

Exemple : on lance deux pièces équilibrées et XXX est le nombre de « Pile ». P(X=0)=14P(X = 0) = \frac{1}{4}P(X=0)=41​, P(X=1)=12P(X = 1) = \frac{1}{2}P(X=1)=21​, P(X=2)=14P(X = 2) = \frac{1}{4}P(X=2)=41​.

  • Notations : {X≤a}\{X \le a\}{X≤a} est l'événement « XXX prend une valeur inférieure ou égale à aaa ». Avec les deux pièces : P(X≤1)=P(X=0)+P(X=1)=34P(X \le 1) = P(X = 0) + P(X = 1) = \frac{3}{4}P(X≤1)=P(X=0)+P(X=1)=43​.

Démonstration : formule de König-Huygens

Notons μ=E(X)\mu = E(X)μ=E(X). En développant (xi−μ)2=xi2−2μxi+μ2(x_i - \mu)^2 = x_i^2 - 2\mu x_i + \mu^2(xi​−μ)2=xi2​−2μxi​+μ2 :

5. Linéarité de l'espérance

Si XXX et YYY sont deux variables aléatoires définies sur le même univers et aaa, bbb deux réels (propriétés admises) :
E(X+Y)=E(X)+E(Y)etE(aX+b)=aE(X)+bE(X + Y) = E(X) + E(Y) \quad \text{et} \quad E(aX + b) = aE(X) + bE(X+Y)=E(X)+E(Y)etE(aX+b)=aE(X)+b
Exemple : on lance deux dés équilibrés ; XXX et YYY sont les deux résultats. E(X)=E(Y)=1+2+3+4+5+66=3,5E(X) = E(Y) = \frac{1 + 2 + 3 + 4 + 5 + 6}{6} = 3{,}5E(X)=E(Y)=61+2+3+4+5+6​=3,5, donc la somme S=X+YS = X + YS=X+Y a pour espérance E(S)=7E(S) = 7E(S)=7, sans qu'il soit nécessaire de déterminer la loi de SSS.
⚠️ Il n'y a pas de formule analogue pour la variance d'une somme en Première.

6. Algorithmes : espérance, variance, écart-type et échantillons

  • Calcul à partir de la loi (listes des valeurs et des probabilités) :
from math import sqrt

def esperance(valeurs, probas):
    return sum(valeurs[i] * probas[i] for i in range(len(valeurs)))


def variance(valeurs, probas):
    m = esperance(valeurs, probas)
    return sum((valeurs[i] - m) * 2  probas[i] for i in range(len(valeurs)))


def ecart_type(valeurs, probas):
    return sqrt(variance(valeurs, probas))

Avec valeurs = [5, 2, -2] et probas = [0.2, 0.3, 0.5] (jeu de l'urne), on obtient, aux arrondis près, 0,60{,}60,6, 7,847{,}847,84 et 2,82{,}82,8.

  • Moyenne d'échantillons : pour une variable XXX d'espérance μ\muμ et d'écart-type σ\sigmaσ, on simule NNN échantillons de taille nnn et on calcule la proportion de ceux dont la moyenne mmm vérifie ∣m−μ∣≤2σn|m - \mu| \le \frac{2\sigma}{\sqrt{n}}∣m−μ∣≤n​2σ​.
from random import randint
from math import sqrt

def moyenne_echantillon(n):     # gain du jeu : 10 si 6, -2 sinon
    s = 0
    for k in range(n):
        s = s + (10 if randint(1, 6) == 6 else -2)
    return s / n


def proportion(N, n, mu, sigma):
    c = 0
    for j in range(N):
        if abs(moyenne_echantillon(n) - mu) <= 2 * sigma / sqrt(n):
            c = c + 1
    return c / N

Pour ce jeu, μ=0\mu = 0μ=0 et V(X)=100×16+4×56=20V(X) = 100 \times \frac{1}{6} + 4 \times \frac{5}{6} = 20V(X)=100×61​+4×65​=20, donc σ=20\sigma = \sqrt{20}σ=20​. proportion(1000, 100, 0, sqrt(20)) renvoie en général une valeur proche de 0,950{,}950,95 : la moyenne d'un échantillon est le plus souvent à moins de 2σn\frac{2\sigma}{\sqrt{n}}n​2σ​ de l'espérance, et cet écart diminue quand nnn augmente.

7. Pour aller plus loin : minimum de x↦E((X−x)2)x \mapsto E((X - x)^2)x↦E((X−x)2)

Notons μ=E(X)\mu = E(X)μ=E(X). Pour tout réel xxx, en développant et par linéarité de l'espérance :
E((X−x)2)=E(X2)−2x μ+x2=(x−μ)2+E(X2)−μ2=(x−μ)2+V(X)E\left((X - x)^2\right) = E(X^2) - 2x\,\mu + x^2 = (x - \mu)^2 + E(X^2) - \mu^2 = (x - \mu)^2 + V(X)E((X−x)2)=E(X2)−2xμ+x2=(x−μ)2+E(X2)−μ2=(x−μ)2+V(X)
C'est une fonction polynôme du second degré de xxx, minimale pour x=μx = \mux=μ, de minimum V(X)V(X)V(X) : l'espérance est le nombre « le plus proche » des valeurs de XXX au sens des carrés des écarts, et la variance mesure cet écart minimal.

Pièges fréquents

  • Dans la formule de König-Huygens, E(X2)E(X^2)E(X2) se calcule en élevant les valeurs xix_ixi​ au carré sans modifier les probabilités : E(X2)=∑xi2piE(X^2) = \sum x_i^2 p_iE(X2)=∑xi2​pi​.
  • Une variance est toujours positive ou nulle (V(X)≥0V(X) \ge 0V(X)≥0). Si vous obtenez un résultat négatif, vous avez inversé les termes de König-Huygens.
  • Toujours vérifier que la somme des probabilités de la loi vaut 111 : c'est un contrôle simple qui détecte beaucoup d'erreurs.
  • (Pour aller plus loin) V(aX+b)=a2V(X)V(aX + b) = a^2 V(X)V(aX+b)=a2V(X) : la constante bbb disparaît et aaa est élevé au carré. Par exemple V(−2X+3)=4V(X)V(-2X + 3) = 4V(X)V(−2X+3)=4V(X).
  • L'espérance n'est pas forcément une valeur prise par XXX : dans l'exemple de l'urne, E(X)=0,6E(X) = 0{,}6E(X)=0,6 alors que XXX ne prend que les valeurs 555, 222 et −2-2−2.
