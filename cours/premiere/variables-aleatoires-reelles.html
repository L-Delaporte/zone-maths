Le cours

1. Espérance, variance et écart-type

Pour une variable aléatoire XXX prenant les valeurs x1,x2,…,xkx_1, x_2, \dots, x_kx1​,x2​,…,xk​ avec les probabilités pi=P(X=xi)p_i = P(X = x_i)pi​=P(X=xi​) :

  • Espérance mathématique (moyenne pondérée sur le long terme) :

E(X)=∑i=1kxipi=x1p1+x2p2+⋯+xkpkE(X) = \sum_{i=1}^k x_i p_i = x_1 p_1 + x_2 p_2 + \dots + x_k p_kE(X)=i=1∑k​xi​pi​=x1​p1​+x2​p2​+⋯+xk​pk​

  • Variance (mesure de la dispersion par rapport à la moyenne) :

V(X)=∑i=1k(xi−E(X))2pi=E(X2)−(E(X))2(formule de Ko¨nig-Huygens)V(X) = \sum_{i=1}^k (x_i - E(X))^2 p_i = E(X^2) - (E(X))^2 \quad \text{(formule de König-Huygens)}V(X)=i=1∑k​(xi​−E(X))2pi​=E(X2)−(E(X))2(formule de Ko¨nig-Huygens)

  • Écart-type : σ(X)=V(X)\sigma(X) = \sqrt{V(X)}σ(X)=V(X)​ (même unité que XXX).

3. Variable aléatoire et loi de probabilité

Une variable aléatoire XXX sur un univers fini Ω\OmegaΩ est une fonction qui associe un nombre réel à chaque issue.

  • L'événement {X=xi}\{X = x_i\}{X=xi​} regroupe les issues pour lesquelles XXX prend la valeur xix_ixi​.
  • La loi de probabilité de XXX est la donnée des valeurs xix_ixi​ et des probabilités pi=P(X=xi)p_i = P(X = x_i)pi​=P(X=xi​), souvent présentée dans un tableau. On a toujours p1+p2+⋯+pk=1p_1 + p_2 + \dots + p_k = 1p1​+p2​+⋯+pk​=1.

Exemple : on lance deux pièces équilibrées et XXX est le nombre de « Pile ». P(X=0)=14P(X = 0) = \frac{1}{4}P(X=0)=41​, P(X=1)=12P(X = 1) = \frac{1}{2}P(X=1)=21​, P(X=2)=14P(X = 2) = \frac{1}{4}P(X=2)=41​.

4. Interpréter l'espérance par la simulation

Si l'on répète un grand nombre de fois l'expérience, la moyenne des valeurs obtenues pour XXX est en général proche de E(X)E(X)E(X). On peut l'observer en Python (dé : gain de 101010 si on obtient 666, perte de 222 sinon) :
from random import randint
def moyenne(N):
s = 0
for k in range(N):
s = s + (10 if randint(1, 6) == 6 else -2)
return s / N
Ici E(X)=10×16−2×56=0E(X) = 10 \times \frac{1}{6} - 2 \times \frac{5}{6} = 0E(X)=10×61​−2×65​=0, et moyenne(100000) renvoie une valeur proche de 000.

Méthodes et exemples rédigés

Méthode : Calculer E(X)E(X)E(X) et V(X)V(X)V(X) à l'aide d'un tableau

Exemple

On lance une pièce équilibrée. Si Pile, on gagne 10 € ; si Face, on perd 6 €. La mise est de 1 €.

  1. Étape 1 (Gain net X) : En cas de Pile, gain net x1=10−1=+9x_1 = 10 - 1 = +9x1​=10−1=+9 €. En cas de Face, gain net x2=−6−1=−7x_2 = -6 - 1 = -7x2​=−6−1=−7 €.

  2. Étape 2 (Probabilités) : p1=P(X=9)=0,5p_1 = P(X = 9) = 0{,}5p1​=P(X=9)=0,5 et p2=P(X=−7)=0,5p_2 = P(X = -7) = 0{,}5p2​=P(X=−7)=0,5.

  3. Étape 3 (Espérance) : E(X)=9(0,5)+(−7)(0,5)=4,5−3,5=+1E(X) = 9(0{,}5) + (-7)(0{,}5) = 4{,}5 - 3{,}5 = +1E(X)=9(0,5)+(−7)(0,5)=4,5−3,5=+1 €. Le jeu est favorable au joueur (espérance positive).

Méthode : Déterminer une loi puis calculer E(X)E(X)E(X), V(X)V(X)V(X) et σ(X)\sigma(X)σ(X)

Exemple

Une urne contient 222 boules rouges, 333 vertes et 555 blanches, indiscernables au toucher. On tire une boule : rouge, on gagne 5 € ; verte, on gagne 2 € ; blanche, on perd 2 €. XXX est le gain algébrique.

  1. Étape 1 (Loi) : P(X=5)=210=0,2P(X = 5) = \frac{2}{10} = 0{,}2P(X=5)=102​=0,2 ; P(X=2)=310=0,3P(X = 2) = \frac{3}{10} = 0{,}3P(X=2)=103​=0,3 ; P(X=−2)=510=0,5P(X = -2) = \frac{5}{10} = 0{,}5P(X=−2)=105​=0,5. Contrôle : 0,2+0,3+0,5=10{,}2 + 0{,}3 + 0{,}5 = 10,2+0,3+0,5=1.

  2. Étape 2 (Espérance) : E(X)=5×0,2+2×0,3+(−2)×0,5=1+0,6−1=0,6E(X) = 5 \times 0{,}2 + 2 \times 0{,}3 + (-2) \times 0{,}5 = 1 + 0{,}6 - 1 = 0{,}6E(X)=5×0,2+2×0,3+(−2)×0,5=1+0,6−1=0,6.

  3. Étape 3 (E(X2)E(X^2)E(X2)) : E(X2)=25×0,2+4×0,3+4×0,5=5+1,2+2=8,2E(X^2) = 25 \times 0{,}2 + 4 \times 0{,}3 + 4 \times 0{,}5 = 5 + 1{,}2 + 2 = 8{,}2E(X2)=25×0,2+4×0,3+4×0,5=5+1,2+2=8,2.

  4. Étape 4 (Variance et écart-type) : V(X)=8,2−0,62=8,2−0,36=7,84V(X) = 8{,}2 - 0{,}6^2 = 8{,}2 - 0{,}36 = 7{,}84V(X)=8,2−0,62=8,2−0,36=7,84 et σ(X)=7,84=2,8\sigma(X) = \sqrt{7{,}84} = 2{,}8σ(X)=7,84​=2,8.

  5. Conclusion : en moyenne, on gagne 0,60 € par partie, avec un écart-type de 2,80 €.

Méthode : Rendre un jeu équitable

Exemple

On lance un dé équilibré. Si l'on obtient 666, on gagne aaa euros ; sinon, on perd 2 €. Déterminer aaa pour que le jeu soit équitable.

  1. Étape 1 (Loi du gain XXX) : P(X=a)=16P(X = a) = \frac{1}{6}P(X=a)=61​ et P(X=−2)=56P(X = -2) = \frac{5}{6}P(X=−2)=65​.

  3. Étape 3 (Équation) : le jeu est équitable si E(X)=0  ⟺  a−10=0  ⟺  a=10E(X) = 0 \iff a - 10 = 0 \iff a = 10E(X)=0⟺a−10=0⟺a=10.

  4. Conclusion : il faut un gain de 10 € en cas de 666 ; si a>10a > 10a>10, le jeu est favorable au joueur.

Méthode : Utiliser les propriétés de E(aX+b)E(aX + b)E(aX+b) et V(aX+b)V(aX + b)V(aX+b)

Exemple

Pour le jeu de l'urne ci-dessus (E(X)=0,6E(X) = 0{,}6E(X)=0,6, V(X)=7,84V(X) = 7{,}84V(X)=7,84), l'organisateur double tous les gains et pertes puis retire 1 € de frais : le nouveau gain est Y=2X−1Y = 2X - 1Y=2X−1. Calculer E(Y)E(Y)E(Y), V(Y)V(Y)V(Y) et σ(Y)\sigma(Y)σ(Y).

  1. Étape 1 (Espérance) : E(Y)=2E(X)−1=2×0,6−1=0,2E(Y) = 2E(X) - 1 = 2 \times 0{,}6 - 1 = 0{,}2E(Y)=2E(X)−1=2×0,6−1=0,2.

  2. Étape 2 (Variance) : V(Y)=22×V(X)=4×7,84=31,36V(Y) = 2^2 \times V(X) = 4 \times 7{,}84 = 31{,}36V(Y)=22×V(X)=4×7,84=31,36.

  3. Étape 3 (Écart-type) : σ(Y)=∣2∣×σ(X)=2×2,8=5,6\sigma(Y) = |2| \times \sigma(X) = 2 \times 2{,}8 = 5{,}6σ(Y)=∣2∣×σ(X)=2×2,8=5,6 (et 31,36=5,6\sqrt{31{,}36} = 5{,}631,36​=5,6).

Pièges fréquents

  • Dans la formule de König-Huygens, E(X2)E(X^2)E(X2) se calcule en élevant les valeurs xix_ixi​ au carré sans modifier les probabilités : E(X2)=∑xi2piE(X^2) = \sum x_i^2 p_iE(X2)=∑xi2​pi​.
  • Une variance est toujours positive ou nulle (V(X)≥0V(X) \ge 0V(X)≥0). Si vous obtenez un résultat négatif, vous avez inversé les termes de König-Huygens.
  • Toujours vérifier que la somme des probabilités de la loi vaut 111 : c'est un contrôle simple qui détecte beaucoup d'erreurs.
  • V(aX+b)=a2V(X)V(aX + b) = a^2 V(X)V(aX+b)=a2V(X) : la constante bbb disparaît et aaa est élevé au carré. Par exemple V(−2X+3)=4V(X)V(-2X + 3) = 4V(X)V(−2X+3)=4V(X).
  • L'espérance n'est pas forcément une valeur prise par XXX : dans l'exemple de l'urne, E(X)=0,6E(X) = 0{,}6E(X)=0,6 alors que XXX ne prend que les valeurs 555, 222 et −2-2−2.

Si E(X)=4E(X) = 4E(X)=4, que vaut E(3X−5)E(3X - 5)E(3X−5) ?
