Applications du produit scalaire, formule d'Al-Kashi et droites — cours de première

Théorème d'Al-Kashi (loi des cosinus), théorème de la médiane, vecteur normal à une droite et équation cartésienne ax + by + c = 0.

Objectifs du chapitre

  • Appliquer le théorème d'Al-Kashi (loi des cosinus) dans un triangle quelconque : a2=b2+c2−2bccos⁡(A^)a^2 = b^2 + c^2 - 2bc \cos(\widehat{A})a2=b2+c2−2bccos(A).
  • Appliquer le théorème de la médiane : si III est le milieu de [BC][BC][BC], alors AB2+AC2=2AI2+BC22AB^2 + AC^2 = 2AI^2 + \frac{BC^2}{2}AB2+AC2=2AI2+2BC2​.
  • Définir un vecteur normal à une droite et déterminer l'équation cartésienne ax+by+c=0ax + by + c = 0ax+by+c=0 associée à n⃗(a;b)\vec{n}(a ; b)n(a;b).

Le cours

1. Théorème d'Al-Kashi (Loi des cosinus)

Dans un triangle ABCABCABC quelconque avec les notations usuelles (a=BC,b=AC,c=ABa = BC, b = AC, c = ABa=BC,b=AC,c=AB) :
a2=b2+c2−2bccos⁡(A^)a^2 = b^2 + c^2 - 2bc \cos(\widehat{A})a2=b2+c2−2bccos(A)
b2=a2+c2−2accos⁡(B^)b^2 = a^2 + c^2 - 2ac \cos(\widehat{B})b2=a2+c2−2accos(B)
c2=a2+b2−2abcos⁡(C^)c^2 = a^2 + b^2 - 2ab \cos(\widehat{C})c2=a2+b2−2abcos(C)
Généralisation du théorème de Pythagore : si A^=90∘\widehat{A} = 90^\circA=90∘, alors cos⁡(A^)=0\cos(\widehat{A}) = 0cos(A)=0 et on retrouve a2=b2+c2a^2 = b^2 + c^2a2=b2+c2.

2. Vecteur normal à une droite

  • Un vecteur normal à une droite D\mathcal{D}D est un vecteur non nul n⃗\vec{n}n orthogonal à tout vecteur directeur de D\mathcal{D}D.
  • La droite passant par A(xA;yA)A(x_A ; y_A)A(xA​;yA​) de vecteur normal n⃗(ab)\vec{n}\begin{pmatrix} a \\ b \end{pmatrix}n(ab​) admet pour équation cartésienne :

a(x−xA)+b(y−yA)=0  ⟺  ax+by+c=0a(x - x_A) + b(y - y_A) = 0 \iff ax + by + c = 0a(x−xA​)+b(y−yA​)=0⟺ax+by+c=0

3. Calculer un angle avec Al-Kashi

En isolant le cosinus dans la formule d'Al-Kashi, on obtient un angle à partir des trois côtés :
cos⁡(A^)=b2+c2−a22bc\cos(\widehat{A}) = \frac{b^2 + c^2 - a^2}{2bc}cos(A)=2bcb2+c2−a2​
Exemple : si a=BC=7a = BC = 7a=BC=7, b=AC=5b = AC = 5b=AC=5 et c=AB=8c = AB = 8c=AB=8, alors cos⁡(A^)=25+64−4980=4080=12\cos(\widehat{A}) = \frac{25 + 64 - 49}{80} = \frac{40}{80} = \frac{1}{2}cos(A)=8025+64−49​=8040​=21​, donc A^=60∘\widehat{A} = 60^\circA=60∘.

4. Théorème de la médiane

Soit III le milieu de [AB][AB][AB]. Pour tout point MMM du plan :
MA⃗⋅MB⃗=MI2−AB24\vec{MA} \cdot \vec{MB} = MI^2 - \frac{AB^2}{4}MA⋅MB=MI2−4AB2​
Preuve : MA⃗⋅MB⃗=(MI⃗+IA⃗)⋅(MI⃗−IA⃗)=MI2−IA2\vec{MA} \cdot \vec{MB} = (\vec{MI} + \vec{IA}) \cdot (\vec{MI} - \vec{IA}) = MI^2 - IA^2MA⋅MB=(MI+IA)⋅(MI−IA)=MI2−IA2, et IA=AB2IA = \frac{AB}{2}IA=2AB​.
Conséquence : l'ensemble des points MMM tels que MA⃗⋅MB⃗=0\vec{MA} \cdot \vec{MB} = 0MA⋅MB=0 est le cercle de diamètre [AB][AB][AB].

5. Équation cartésienne d'un cercle

Dans un repère orthonormé, le cercle de centre Ω(a;b)\Omega(a ; b)Ω(a;b) et de rayon r>0r > 0r>0 a pour équation :
(x−a)2+(y−b)2=r2(x - a)^2 + (y - b)^2 = r^2(x−a)2+(y−b)2=r2
En effet, M(x;y)M(x ; y)M(x;y) appartient au cercle si et seulement si ΩM2=r2\Omega M^2 = r^2ΩM2=r2.
Exemple : le cercle de centre Ω(1;−2)\Omega(1 ; -2)Ω(1;−2) et de rayon 333 a pour équation (x−1)2+(y+2)2=9(x - 1)^2 + (y + 2)^2 = 9(x−1)2+(y+2)2=9.

Méthodes et exemples rédigés

Méthode : Trouver l'équation d'une droite connaissant un point et un vecteur normal

Exemple

Déterminer l'équation de la droite D\mathcal{D}D passant par A(2;−3)A(2 ; -3)A(2;−3) et ayant pour vecteur normal n⃗(4;−1)\vec{n}(4 ; -1)n(4;−1).

  1. Étape 1 (Forme cartésienne) : Comme n⃗(4;−1)\vec{n}(4 ; -1)n(4;−1) est normal, l'équation s'écrit 4x−y+c=04x - y + c = 04x−y+c=0.

  2. Étape 2 (Constante c) : A(2;−3)∈D  ⟹  4(2)−(−3)+c=0  ⟹  8+3+c=0  ⟹  c=−11A(2 ; -3) \in \mathcal{D} \implies 4(2) - (-3) + c = 0 \implies 8 + 3 + c = 0 \implies c = -11A(2;−3)∈D⟹4(2)−(−3)+c=0⟹8+3+c=0⟹c=−11.

  3. Étape 3 (Conclusion) : L'équation cartésienne est 4x−y−11=04x - y - 11 = 04x−y−11=0.

Méthode : Déterminer le centre et le rayon d'un cercle

Exemple

Montrer que l'ensemble des points M(x;y)M(x ; y)M(x;y) tels que x2+y2−4x+6y−3=0x^2 + y^2 - 4x + 6y - 3 = 0x2+y2−4x+6y−3=0 est un cercle, et préciser son centre et son rayon.

  1. Étape 1 (Forme canonique en xxx) : x2−4x=(x−2)2−4x^2 - 4x = (x - 2)^2 - 4x2−4x=(x−2)2−4.

  2. Étape 2 (Forme canonique en yyy) : y2+6y=(y+3)2−9y^2 + 6y = (y + 3)^2 - 9y2+6y=(y+3)2−9.

  3. Étape 3 (Regroupement) : l'équation devient (x−2)2−4+(y+3)2−9−3=0(x - 2)^2 - 4 + (y + 3)^2 - 9 - 3 = 0(x−2)2−4+(y+3)2−9−3=0, soit (x−2)2+(y+3)2=16(x - 2)^2 + (y + 3)^2 = 16(x−2)2+(y+3)2=16.

  4. Conclusion : comme 16=42>016 = 4^2 > 016=42>0, c'est le cercle de centre Ω(2;−3)\Omega(2 ; -3)Ω(2;−3) et de rayon 444.

Méthode : Déterminer le projeté orthogonal d'un point sur une droite

Exemple

Dans un repère orthonormé, soit D:x−2y+3=0\mathcal{D} : x - 2y + 3 = 0D:x−2y+3=0 et A(4;1)A(4 ; 1)A(4;1). Déterminer les coordonnées du projeté orthogonal HHH de AAA sur D\mathcal{D}D, puis la distance AHAHAH.

  1. Étape 1 (Vecteur directeur) : D\mathcal{D}D a pour vecteur directeur u⃗(21)\vec{u}\begin{pmatrix} 2 \\ 1 \end{pmatrix}u(21​) (de la forme (−b;a)(-b ; a)(−b;a)).

  2. Étape 2 (Conditions sur H(x;y)H(x ; y)H(x;y)) : H∈DH \in \mathcal{D}H∈D donne x−2y+3=0x - 2y + 3 = 0x−2y+3=0 ; AH⃗⊥u⃗\vec{AH} \perp \vec{u}AH⊥u donne 2(x−4)+1×(y−1)=02(x - 4) + 1 \times (y - 1) = 02(x−4)+1×(y−1)=0, soit 2x+y=92x + y = 92x+y=9.

  3. Étape 3 (Système) : de la première équation, x=2y−3x = 2y - 3x=2y−3 ; alors 2(2y−3)+y=9  ⟺  5y=15  ⟺  y=32(2y - 3) + y = 9 \iff 5y = 15 \iff y = 32(2y−3)+y=9⟺5y=15⟺y=3, puis x=3x = 3x=3. Donc H(3;3)H(3 ; 3)H(3;3).

  4. Étape 4 (Distance) : AH⃗(−12)\vec{AH}\begin{pmatrix} -1 \\ 2 \end{pmatrix}AH(−12​), donc AH=(−1)2+22=5AH = \sqrt{(-1)^2 + 2^2} = \sqrt{5}AH=(−1)2+22​=5​.

  5. Conclusion : H(3;3)H(3 ; 3)H(3;3) et AH=5AH = \sqrt{5}AH=5​ ; c'est la distance du point AAA à la droite D\mathcal{D}D.

Méthode : Calculer une longueur avec Al-Kashi

Exemple

Dans un triangle ABCABCABC, AC=5AC = 5AC=5, AB=8AB = 8AB=8 et BAC^=120∘\widehat{BAC} = 120^\circBAC=120∘. Calculer BCBCBC.

  1. Étape 1 (Formule) : BC2=AB2+AC2−2×AB×AC×cos⁡(A^)BC^2 = AB^2 + AC^2 - 2 \times AB \times AC \times \cos(\widehat{A})BC2=AB2+AC2−2×AB×AC×cos(A).

  2. Étape 2 (Valeurs) : cos⁡(120∘)=−12\cos(120^\circ) = -\frac{1}{2}cos(120∘)=−21​, donc BC2=64+25−2×8×5×(−12)=89+40=129BC^2 = 64 + 25 - 2 \times 8 \times 5 \times \left(-\frac{1}{2}\right) = 89 + 40 = 129BC2=64+25−2×8×5×(−21​)=89+40=129.

  3. Conclusion : BC=129≈11,36BC = \sqrt{129} \approx 11{,}36BC=129​≈11,36. L'angle étant obtus, on vérifie que BC2>AB2+AC2BC^2 > AB^2 + AC^2BC2>AB2+AC2.

Pièges fréquents

  • Pour ax+by+c=0ax + by + c = 0ax+by+c=0 :
    - Un vecteur directeur est u⃗(−b;a)\vec{u}(-b ; a)u(−b;a).
    - Un vecteur normal est n⃗(a;b)\vec{n}(a ; b)n(a;b).
  • Dans (x−a)2+(y−b)2=r2(x - a)^2 + (y - b)^2 = r^2(x−a)2+(y−b)2=r2, le membre de droite est le carré du rayon : (x−1)2+y2=9(x - 1)^2 + y^2 = 9(x−1)2+y2=9 a pour rayon 333, et non 999.
  • Une équation de la forme x2+y2+⋯=0x^2 + y^2 + \dots = 0x2+y2+⋯=0 ne définit pas toujours un cercle : x2+y2−2x+4y+10=0  ⟺  (x−1)2+(y+2)2=−5x^2 + y^2 - 2x + 4y + 10 = 0 \iff (x - 1)^2 + (y + 2)^2 = -5x2+y2−2x+4y+10=0⟺(x−1)2+(y+2)2=−5, ensemble vide.
  • Dans Al-Kashi, l'angle utilisé est celui opposé au côté isolé : a2a^2a2 va avec A^\widehat{A}A, angle compris entre les côtés bbb et ccc.

Exercices corrigés

Exercice 1 Vecteur normal et droite

Palier 1 · découverte

Un vecteur normal à la droite d'équation cartésienne 4x−7y+1=04x - 7y + 1 = 04x−7y+1=0 est :

  1. n⃗(4;−7)\vec{n}(4 ; -7)n(4;−7)
  2. n⃗(7;4)\vec{n}(7 ; 4)n(7;4)
  3. n⃗(−7;4)\vec{n}(-7 ; 4)n(−7;4)
  4. n⃗(4;7)\vec{n}(4 ; 7)n(4;7)
Un indice

Pour une droite d'équation ax+by+c=0ax + by + c = 0ax+by+c=0, un vecteur normal est n⃗(a;b)\vec{n}(a ; b)n(a;b).

Voir la correction

Bonne réponse : A. n⃗(4;−7)\vec{n}(4 ; -7)n(4;−7)

D'après le cours, les coefficients de xxx et yyy donnent les coordonnées d'un vecteur normal : n⃗(a;b)=n⃗(4;−7)\vec{n}(a ; b) = \vec{n}(4 ; -7)n(a;b)=n(4;−7).

Exercice 2 Équation cartésienne de cercle

Palier 2 · application

Quelle est l'équation du cercle de centre Ω(2;−3)\Omega(2 ; -3)Ω(2;−3) et de rayon R=4R = 4R=4 ?

  1. (x−2)2+(y+3)2=16(x - 2)^2 + (y + 3)^2 = 16(x−2)2+(y+3)2=16
  2. (x+2)2+(y−3)2=16(x + 2)^2 + (y - 3)^2 = 16(x+2)2+(y−3)2=16
  3. (x−2)2+(y+3)2=4(x - 2)^2 + (y + 3)^2 = 4(x−2)2+(y+3)2=4
  4. x2+y2=16x^2 + y^2 = 16x2+y2=16
Un indice

L'équation d'un cercle de centre (x0,y0)(x_0, y_0)(x0​,y0​) et de rayon RRR est (x−x0)2+(y−y0)2=R2(x - x_0)^2 + (y - y_0)^2 = R^2(x−x0​)2+(y−y0​)2=R2.

Voir la correction

Bonne réponse : A. (x−2)2+(y+3)2=16(x - 2)^2 + (y + 3)^2 = 16(x−2)2+(y+3)2=16

(x−2)2+(y−(−3))2=42  ⟺  (x−2)2+(y+3)2=16(x - 2)^2 + (y - (-3))^2 = 4^2 \iff (x - 2)^2 + (y + 3)^2 = 16(x−2)2+(y−(−3))2=42⟺(x−2)2+(y+3)2=16.

Exercice 3 Équation d'une droite perpendiculaire

Palier 3 · approfondissement

Quelle est l'équation cartésienne de la droite passant par A(1;2)A(1 ; 2)A(1;2) et perpendiculaire à la droite d'équation 2x+3y−5=02x + 3y - 5 = 02x+3y−5=0 ?

  1. 3x−2y+1=03x - 2y + 1 = 03x−2y+1=0
  2. 2x+3y−8=02x + 3y - 8 = 02x+3y−8=0
  3. 3x+2y−7=03x + 2y - 7 = 03x+2y−7=0
  4. −2x+3y−4=0-2x + 3y - 4 = 0−2x+3y−4=0
Un indice

Un vecteur normal à la première droite est (2;3)(2 ; 3)(2;3). Il sert de vecteur directeur à la droite perpendiculaire.

Voir la correction

Bonne réponse : A. 3x−2y+1=03x - 2y + 1 = 03x−2y+1=0

La droite cherchée a pour vecteur normal un vecteur orthogonal à (2;3)(2 ; 3)(2;3), par exemple (3;−2)(3 ; -2)(3;−2). Équation : 3x−2y+c=03x - 2y + c = 03x−2y+c=0. En A(1;2)A(1 ; 2)A(1;2) : 3(1)−2(2)+c=0  ⟺  c=13(1) - 2(2) + c = 0 \iff c = 13(1)−2(2)+c=0⟺c=1. Donc 3x−2y+1=03x - 2y + 1 = 03x−2y+1=0.

Exercice 4 Cercle défini par un diamètre
