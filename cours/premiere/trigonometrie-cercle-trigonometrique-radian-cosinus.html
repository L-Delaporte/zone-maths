Le cours

1. Enroulement de la droite réelle, cosinus et sinus

Dans un repère orthonormé (O;I,J)(O ; I, J)(O;I,J), le cercle trigonométrique est le cercle de centre OOO et de rayon 111, orienté dans le sens direct (sens inverse des aiguilles d'une montre).
On « enroule » la droite des réels autour de ce cercle à partir du point I(1;0)I(1 ; 0)I(1;0) : à chaque réel xxx correspond un unique point MMM du cercle, son image, obtenu en parcourant depuis III un arc de longueur ∣x∣|x|∣x∣, dans le sens direct si x>0x > 0x>0 et dans le sens indirect si x<0x < 0x<0.

  • cos⁡(x)\cos(x)cos(x) est l'abscisse de MMM et sin⁡(x)\sin(x)sin(x) son ordonnée : M(cos⁡(x);sin⁡(x))M(\cos(x) ; \sin(x))M(cos(x);sin(x)).
  • Pour tout réel xxx : −1≤cos⁡(x)≤1-1 \le \cos(x) \le 1−1≤cos(x)≤1, −1≤sin⁡(x)≤1-1 \le \sin(x) \le 1−1≤sin(x)≤1 et cos⁡2(x)+sin⁡2(x)=1\cos^2(x) + \sin^2(x) = 1cos2(x)+sin2(x)=1 (car OM2=1OM^2 = 1OM2=1).
  • Lien avec le triangle rectangle : pour 0<x<π20 < x < \frac{\pi}{2}0<x<2π​, si HHH est le projeté orthogonal de MMM sur (OI)(OI)(OI), le triangle OHMOHMOHM est rectangle en HHH et son hypoténuse mesure OM=1OM = 1OM=1 ; on retrouve cos⁡=coˆteˊ adjacenthypoteˊnuse=OH\cos = \frac{\text{côté adjacent}}{\text{hypoténuse}} = OHcos=hypoteˊnusecoˆteˊ adjacent​=OH et sin⁡=coˆteˊ opposeˊhypoteˊnuse=HM\sin = \frac{\text{côté opposé}}{\text{hypoténuse}} = HMsin=hypoteˊnusecoˆteˊ opposeˊ​=HM.

3. Réels associés : lecture sur le cercle

Les symétries du cercle trigonométrique donnent, pour tout réel xxx :

  • cos⁡(−x)=cos⁡(x)\cos(-x) = \cos(x)cos(−x)=cos(x) et sin⁡(−x)=−sin⁡(x)\sin(-x) = -\sin(x)sin(−x)=−sin(x) (symétrie par rapport à l'axe des abscisses) ;
  • cos⁡(π−x)=−cos⁡(x)\cos(\pi - x) = -\cos(x)cos(π−x)=−cos(x) et sin⁡(π−x)=sin⁡(x)\sin(\pi - x) = \sin(x)sin(π−x)=sin(x) (symétrie par rapport à l'axe des ordonnées) ;
  • cos⁡(π+x)=−cos⁡(x)\cos(\pi + x) = -\cos(x)cos(π+x)=−cos(x) et sin⁡(π+x)=−sin⁡(x)\sin(\pi + x) = -\sin(x)sin(π+x)=−sin(x) (symétrie par rapport à l'origine) ;
  • cos⁡(π2−x)=sin⁡(x)\cos(\frac{\pi}{2} - x) = \sin(x)cos(2π​−x)=sin(x) et sin⁡(π2−x)=cos⁡(x)\sin(\frac{\pi}{2} - x) = \cos(x)sin(2π​−x)=cos(x) (symétrie par rapport à la droite d'équation y=xy = xy=x).

Exemple : cos⁡(2π3)=cos⁡(π−π3)=−12\cos\left(\frac{2\pi}{3}\right) = \cos\left(\pi - \frac{\pi}{3}\right) = -\frac{1}{2}cos(32π​)=cos(π−3π​)=−21​ et sin⁡(2π3)=32\sin\left(\frac{2\pi}{3}\right) = \frac{\sqrt{3}}{2}sin(32π​)=23​​.

4. Le radian et la longueur d'arc

Sur un cercle de rayon RRR, un angle de θ\thetaθ radians intercepte un arc de longueur ℓ=R θ\ell = R\,\thetaℓ=Rθ. En particulier, sur le cercle trigonométrique (R=1R = 1R=1), la mesure en radians est égale à la longueur de l'arc.
Conversion : θrad=θdeg×π180\theta_{\text{rad}} = \theta_{\text{deg}} \times \frac{\pi}{180}θrad​=θdeg​×180π​.
Exemple : 135∘=135×π180=3π4135^\circ = 135 \times \frac{\pi}{180} = \frac{3\pi}{4}135∘=135×180π​=43π​ rad.

5. Réels associés à un même point du cercle

Les réels xxx et x+2kπx + 2k\pix+2kπ (k∈Zk \in \mathbb{Z}k∈Z) sont associés au même point du cercle trigonométrique. On a donc cos⁡(x+2kπ)=cos⁡(x)\cos(x + 2k\pi) = \cos(x)cos(x+2kπ)=cos(x) et sin⁡(x+2kπ)=sin⁡(x)\sin(x + 2k\pi) = \sin(x)sin(x+2kπ)=sin(x).
Pour aller plus loin : la mesure principale est l'unique mesure appartenant à ]−π;π]]-\pi ; \pi]]−π;π].
Exemple : 17π3=18π3−π3=6π−π3\frac{17\pi}{3} = \frac{18\pi}{3} - \frac{\pi}{3} = 6\pi - \frac{\pi}{3}317π​=318π​−3π​=6π−3π​ : la mesure principale est −π3-\frac{\pi}{3}−3π​.

6. Pour aller plus loin : les fonctions cosinus et sinus

Ces fonctions seront étudiées en terminale ; ce paragraphe n'est pas un attendu du programme de première.

  • Elles sont définies sur R\mathbb{R}R et à valeurs dans [−1;1][-1 ; 1][−1;1].
  • Elles sont périodiques de période 2π2\pi2π : leur courbe se répète par translation de 2π2\pi2π.
  • cos⁡\coscos est paire (courbe symétrique par rapport à l'axe des ordonnées) ; sin⁡\sinsin est impaire (courbe symétrique par rapport à l'origine).
  • Sur [0;π][0 ; \pi][0;π], cos⁡\coscos est décroissante de 111 à −1-1−1. Sur [−π2;π2]\left[-\frac{\pi}{2} ; \frac{\pi}{2}\right][−2π​;2π​], sin⁡\sinsin est croissante de −1-1−1 à 111.
  • Autres angles associés : cos⁡(π2+x)=−sin⁡(x)\cos\left(\frac{\pi}{2} + x\right) = -\sin(x)cos(2π​+x)=−sin(x) et sin⁡(π2+x)=cos⁡(x)\sin\left(\frac{\pi}{2} + x\right) = \cos(x)sin(2π​+x)=cos(x).

7. Algorithme : approximation de π\piπ par la méthode d'Archimède

Un polygone régulier à nnn côtés inscrit dans un cercle de rayon 111 a un périmètre proche de 2π2\pi2π lorsque nnn est grand : son demi-périmètre approche donc π\piπ. On part de l'hexagone régulier (n=6n = 6n=6, côté c=1c = 1c=1) et on double à chaque étape le nombre de côtés ; on admet (théorème de Pythagore) que le nouveau côté vaut 2−4−c2\sqrt{2 - \sqrt{4 - c^2}}2−4−c2​​.

from math import sqrt


def archimede(k):
    n = 6
    c = 1
    for i in range(k):
        c = sqrt(2 - sqrt(4 - c * c))
        n = 2 * n
    return n * c / 2

archimede(0) renvoie 333 ; archimede(1) environ 3,10583{,}10583,1058 (121212 côtés) ; archimede(4) environ 3,14103{,}14103,1410 (969696 côtés, comme Archimède).

Méthodes et exemples rédigés

Pour aller plus loin — Méthode : Résoudre une équation cos⁡(x)=a\cos(x) = acos(x)=a

Exemple

Résoudre dans [0;2π[[0 ; 2\pi[[0;2π[ l'équation cos⁡(x)=12\cos(x) = \frac{1}{2}cos(x)=21​.

  1. Étape 1 (Angle de référence) : On sait que cos⁡(π3)=12\cos\left(\frac{\pi}{3}\right) = \frac{1}{2}cos(3π​)=21​.

  2. Étape 2 (Solutions modulo 2π2\pi2π) : Les deux points du cercle d'abscisse 12\frac{1}{2}21​ sont x=π3x = \frac{\pi}{3}x=3π​ et x=−π3x = -\frac{\pi}{3}x=−3π​.

  3. Étape 3 (Intervalle [0;2π[[0 ; 2\pi[[0;2π[) : En ajoutant 2π2\pi2π à −π3-\frac{\pi}{3}−3π​, on obtient −π3+2π=5π3-\frac{\pi}{3} + 2\pi = \frac{5\pi}{3}−3π​+2π=35π​.

  4. Conclusion : S={π3;5π3}S = \left\{\frac{\pi}{3} ; \frac{5\pi}{3}\right\}S={3π​;35π​}.

Pour aller plus loin — Méthode : Résoudre une équation sin⁡(x)=a\sin(x) = asin(x)=a

Exemple

Résoudre dans ]−π;π]]-\pi ; \pi]]−π;π] l'équation sin⁡(x)=−32\sin(x) = -\frac{\sqrt{3}}{2}sin(x)=−23​​.

  1. Étape 1 (Angle de référence) : sin⁡(π3)=32\sin\left(\frac{\pi}{3}\right) = \frac{\sqrt{3}}{2}sin(3π​)=23​​, et sin⁡\sinsin est impaire, donc sin⁡(−π3)=−32\sin\left(-\frac{\pi}{3}\right) = -\frac{\sqrt{3}}{2}sin(−3π​)=−23​​.

  2. Étape 2 (Second point) : les deux points du cercle d'ordonnée −32-\frac{\sqrt{3}}{2}−23​​ sont symétriques par rapport à l'axe des ordonnées ; comme sin⁡(π−x)=sin⁡(x)\sin(\pi - x) = \sin(x)sin(π−x)=sin(x), le second correspond à π−(−π3)=4π3\pi - \left(-\frac{\pi}{3}\right) = \frac{4\pi}{3}π−(−3π​)=34π​.

  3. Étape 3 (Intervalle) : 4π3∉]−π;π]\frac{4\pi}{3} \notin ]-\pi ; \pi]34π​∈/]−π;π], on lui retire 2π2\pi2π : 4π3−2π=−2π3\frac{4\pi}{3} - 2\pi = -\frac{2\pi}{3}34π​−2π=−32π​.

Méthode : Calculer un cosinus connaissant le sinus

Exemple

On sait que x∈[π2;π]x \in \left[\frac{\pi}{2} ; \pi\right]x∈[2π​;π] et sin⁡(x)=35\sin(x) = \frac{3}{5}sin(x)=53​. Calculer cos⁡(x)\cos(x)cos(x).

  1. Étape 1 (Relation fondamentale) : cos⁡2(x)=1−sin⁡2(x)=1−925=1625\cos^2(x) = 1 - \sin^2(x) = 1 - \frac{9}{25} = \frac{16}{25}cos2(x)=1−sin2(x)=1−259​=2516​.

  3. Étape 3 (Choix du signe) : pour x∈[π2;π]x \in \left[\frac{\pi}{2} ; \pi\right]x∈[2π​;π], le point est à gauche de l'axe des ordonnées, donc cos⁡(x)≤0\cos(x) \le 0cos(x)≤0.

Exemple

Pièges fréquents

  • Ne pas oublier que cos⁡2(x)+sin⁡2(x)=1\cos^2(x) + \sin^2(x) = 1cos2(x)+sin2(x)=1 permet de trouver l'un quand on a l'autre, mais il faut choisir le signe (+++ ou −-−) selon le quadrant !
  • La calculatrice doit impérativement être réglée en mode Radian pour les calculs utilisant des angles en radians.
  • Le cosinus est l'abscisse du point du cercle et le sinus son ordonnée : ne pas les inverser.
  • (Pour aller plus loin) L'équation cos⁡(x)=a\cos(x) = acos(x)=a (ou sin⁡(x)=a\sin(x) = asin(x)=a) n'a aucune solution si a>1a > 1a>1 ou a<−1a < -1a<−1.
  • cos⁡(2x)≠2cos⁡(x)\cos(2x) \neq 2\cos(x)cos(2x)=2cos(x) : par exemple cos⁡(2×π2)=−1\cos\left(2 \times \frac{\pi}{2}\right) = -1cos(2×2π​)=−1 alors que 2cos⁡(π2)=02\cos\left(\frac{\pi}{2}\right) = 02cos(2π​)=0.
