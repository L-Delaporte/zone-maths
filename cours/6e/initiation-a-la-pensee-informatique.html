6e · Pensée Informatique · 6A1

Cours et exercices corrigés de 6e : Initiation à la pensée informatique : instructions, séquences et boucles

Identifier une instruction, produire et exécuter une séquence d'instructions, répéter une séquence (boucle), programmer un déplacement simple sur un quadrillage et dans Scratch.

Objectifs du chapitre

  • Identifier une instruction et une séquence d'instructions.
  • Produire et exécuter (à la main) une séquence d'instructions.
  • Répéter une séquence d'instructions à l'aide d'une boucle « répéter ».
  • Programmer le déplacement d'un robot ou d'un lutin sur un quadrillage ou dans Scratch.

Le cours

1. Instructions et séquences

  • Une instruction est un ordre élémentaire donné à une machine (un robot, un lutin) : « avancer d'une case », « tourner à droite »…
  • Une séquence est une suite d'instructions exécutées les unes après les autres, dans l'ordre. Changer l'ordre peut changer le résultat.
  • Un programme (ou script) est une séquence d'instructions écrite pour réaliser une tâche.

2. Déplacements sur un quadrillage

On code souvent un déplacement case par case avec des flèches :

  • → : une case vers la droite ; ← : une case vers la gauche ;
  • ↑ : une case vers le haut ; ↓ : une case vers le bas.

Exemple : le programme « → → ↑ → ↓ ↓ » amène le robot 333 cases à droite et 111 case vers le bas par rapport à son départ (car 222 ↓ et 111 ↑).

3. La boucle « répéter »

Quand une séquence se répète, on utilise une boucle : « répéter nnn fois [ … ] ».

répéter 4 fois
    avancer de 50 pas
    tourner de 90 degrés

Ce script trace un carré de côté 505050 pas : il est plus court que d'écrire 888 instructions à la suite.

4. Premiers pas dans Scratch

Dans Scratch, un lutin exécute des blocs emboîtés :

  • un bloc événement lance le script (« quand le drapeau vert est cliqué ») ;
  • des blocs mouvement (« avancer de 10 pas », « tourner de 90 degrés ») ;
  • des blocs contrôle (« répéter 10 fois ») ;
  • une variable (par exemple « score ») permet de mémoriser un nombre qui peut changer.

À retenir

  • Une séquence s'exécute dans l'ordre, instruction par instruction.
  • « répéter nnn fois » exécute nnn fois tout le bloc qu'elle contient.
  • Carré : répéter 444 fois [avancer ; tourner de 909090 degrés].

Méthodes et exemples rédigés

Méthode : Exécuter un programme à la main

Exemple

Le robot part de la case de départ et exécute : → → → ↑ ↑ ←. Où arrive-t-il ?

  1. Étape 1 : On suit les instructions une par une, dans l'ordre, en notant la position.

  2. Étape 2 : Horizontalement : 333 cases à droite puis 111 à gauche, soit 222 cases à droite.

  3. Étape 3 : Verticalement : 222 cases vers le haut. Le robot finit 222 cases à droite et 222 cases au-dessus du départ.

Méthode : Écrire une boucle

Exemple

Écrire un script court qui trace un rectangle de 808080 pas sur 303030 pas.

  1. Étape 1 : On repère le motif qui se répète : « avancer de 808080, tourner de 909090, avancer de 303030, tourner de 909090 ».

  2. Étape 2 : Ce motif doit être exécuté 222 fois pour fermer le rectangle.

  3. Étape 3 : Script : « répéter 222 fois [avancer de 808080 ; tourner de 909090 ; avancer de 303030 ; tourner de 909090] ».

Pièges fréquents

  • L'ordre des instructions compte : « tourner puis avancer » ne donne pas le même trajet que « avancer puis tourner ».
  • Dans une boucle « répéter 4 fois », toutes les instructions à l'intérieur sont exécutées 4 fois, pas seulement la première.
  • Tourner « à droite » dépend de l'orientation du robot : un robot tourné vers le bas qui tourne à droite part vers la gauche de l'écran.

Questions de révision

Essaie de répondre de tête avant d'afficher la réponse.

Qu'est-ce qu'une séquence d'instructions ?

Une suite d'instructions exécutées les unes après les autres, dans l'ordre.

À quoi sert une boucle « répéter » ?

À exécuter plusieurs fois la même séquence d'instructions sans la réécrire.

Quel angle utiliser dans « répéter 4 fois [avancer de 50 ; tourner de … degrés] » pour tracer un carré ?

909090 degrés.

Un script répète 555 fois « avancer de 202020 pas ». Quelle distance parcourt le lutin ?

5×20=1005 \times 20 = 1005×20=100 pas.

Quel bloc démarre souvent un script Scratch ?

« Quand le drapeau vert est cliqué ».

Exercices corrigés

Exercice 1 Déplacement sur un quadrillage

Palier 1 · découverte

Un robot se déplace d'une case à chaque flèche. Il exécute le programme :
→ → → ↑ ↑ ←\rightarrow \ \rightarrow \ \rightarrow \ \uparrow \ \uparrow \ \leftarrow→ → → ↑ ↑ ←
À la fin, de combien de cases se trouve-t-il à droite de sa case de départ ?

Un indice

Ne regarde que les flèches horizontales.

Voir la correction

Réponse attendue : 2

Flèches horizontales : 333 vers la droite, 111 vers la gauche : 3−1=23 - 1 = 23−1=2.
Le robot est 222 cases à droite (et 222 cases au-dessus) de son départ.

Exercice 2 Distance parcourue avec une boucle

Palier 2 · application

Un lutin exécute le script suivant :

quand le drapeau vert est cliqué
répéter 5 fois
    avancer de 30 pas

Combien de pas le lutin a-t-il parcourus au total ?

Un indice

L'instruction « avancer de 303030 pas » est exécutée 555 fois.

Voir la correction

Réponse attendue : 150

5×30=1505 \times 30 = 1505×30=150
Le lutin a parcouru 150150150 pas.

Exercice 3 Tracer un rectangle

Palier 3 · approfondissement

Un lutin (stylo en position d'écriture) exécute le script suivant :

répéter 2 fois
    avancer de 80 pas
    tourner de 90 degrés
    avancer de 30 pas
    tourner de 90 degrés

Quelle est la longueur totale du trait tracé, en pas ?

Un indice

Pendant un passage dans la boucle, le lutin avance de 80+3080 + 3080+30 pas.

Voir la correction

Réponse attendue : 220

Un passage dans la boucle : 80+30=11080 + 30 = 11080+30=110 pas. Deux passages :
2×110=2202 \times 110 = 2202×110=220
Le lutin trace un rectangle de périmètre 220220220 pas.

Exercice 4 Défi 5ème : Une variable qui double

Palier 4 · défi

On exécute le script suivant :

mettre N à 2
répéter 4 fois
    mettre N à N × 2
dire N

Quel nombre le lutin dit-il à la fin ?

Un indice

Au départ N=2N = 2N=2 ; à chaque passage dans la boucle, NNN est multiplié par 222.

Voir la correction

Réponse attendue : 32

Valeurs successives de NNN : 222, puis 444, 888, 161616, 323232 après les 444 passages.
Le lutin dit 323232.
