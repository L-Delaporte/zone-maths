Objectifs du chapitre

  • Reconnaître une situation de croissance linéaire : la variation absolue d'une étape à la suivante est constante.
  • Calculer un terme d'une suite arithmétique avec u(n)=u(0)+nru(n) = u(0) + nru(n)=u(0)+nr ou u(n)=u(1)+(n−1)ru(n) = u(1) + (n - 1)ru(n)=u(1)+(n−1)r.
  • Déterminer le sens de variation d'une suite arithmétique ou d'une fonction affine selon le signe de rrr ou de aaa.
  • Déterminer l'expression d'une fonction affine à partir de deux valeurs et interpréter son coefficient directeur.
  • Déterminer un seuil par le calcul ou à l'aide d'un programme Python.

Le cours

1. Croissance linéaire

Une quantité a une croissance linéaire lorsqu'elle augmente (ou diminue) de la même valeur à chaque étape : la variation absolue est constante.

  • Exemple : un abonnement passe à 404040 €, puis 555555 €, puis 707070 € : on ajoute 151515 € à chaque fois.
  • Contre-exemple : une hausse de 5 %5\,\%5% par an ajoute chaque année une valeur différente ; ce n'est pas une croissance linéaire (voir le chapitre 1TC6).

2. Suites arithmétiques

On note u(n)u(n)u(n) la valeur obtenue à l'étape nnn. La suite uuu est arithmétique de raison rrr lorsque, pour tout entier naturel nnn, u(n+1)=u(n)+ru(n+1) = u(n) + ru(n+1)=u(n)+r.

  • Terme général : u(n)=u(0)+nru(n) = u(0) + nru(n)=u(0)+nr ; si la suite commence à u(1)u(1)u(1) : u(n)=u(1)+(n−1)ru(n) = u(1) + (n - 1)ru(n)=u(1)+(n−1)r.
  • Entre deux termes quelconques : u(q)=u(p)+(q−p)ru(q) = u(p) + (q - p)ru(q)=u(p)+(q−p)r, donc r=u(q)−u(p)q−pr = \frac{u(q) - u(p)}{q - p}r=q−pu(q)−u(p)​.

3. Sens de variation et représentation

  • Si r>0r > 0r>0, la suite est croissante ; si r<0r < 0r<0, elle est décroissante ; si r=0r = 0r=0, elle est constante.
  • Les points de coordonnées (n;u(n))\left(n ; u(n)\right)(n;u(n)) sont alignés : ils sont sur la droite d'équation y=rx+u(0)y = rx + u(0)y=rx+u(0).

4. Fonctions affines

Une fonction affine s'écrit f(x)=ax+bf(x) = ax + bf(x)=ax+b ; sa courbe est une droite de coefficient directeur aaa et d'ordonnée à l'origine b=f(0)b = f(0)b=f(0).

  • Pour deux nombres x1≠x2x_1 \neq x_2x1​=x2​ : a=f(x2)−f(x1)x2−x1a = \frac{f(x_2) - f(x_1)}{x_2 - x_1}a=x2​−x1​f(x2​)−f(x1​)​.
  • Quand xxx augmente de 111, f(x)f(x)f(x) varie de aaa : c'est le modèle continu de la croissance linéaire.
  • fff est croissante si a>0a > 0a>0, décroissante si a<0a < 0a<0, constante si a=0a = 0a=0.

5. Seuil

Pour savoir à partir de quel rang u(n)u(n)u(n) dépasse une valeur SSS, on résout u(0)+nr>Su(0) + nr > Su(0)+nr>S et on prend le plus petit entier qui convient. Exemple : 200+15n>500  ⟺  15n>300  ⟺  n>20200 + 15n > 500 \iff 15n > 300 \iff n > 20200+15n>500⟺15n>300⟺n>20, donc n=21n = 21n=21.
On peut aussi faire calculer ce rang par une boucle :

u = 200
n = 0
while u <= 500:
    u = u + 15
    n = n + 1
print(n)   # affiche 21

Méthodes et exemples rédigés

Méthode : Calculer un terme d'une suite arithmétique

Exemple

Une citerne contient 353535 hL ; on en prélève 444 hL chaque semaine. On note u(n)u(n)u(n) le volume après nnn semaines. Calculer u(8)u(8)u(8).

  1. Étape 1 (Reconnaître la suite) : on retire la même quantité chaque semaine, donc uuu est arithmétique de premier terme u(0)=35u(0) = 35u(0)=35 et de raison r=−4r = -4r=−4.

  2. Étape 2 (Terme général) : u(n)=35−4nu(n) = 35 - 4nu(n)=35−4n.

  3. Étape 3 (Calcul) : u(8)=35−4×8=35−32=3u(8) = 35 - 4 \times 8 = 35 - 32 = 3u(8)=35−4×8=35−32=3.

  4. Conclusion : après 888 semaines, il reste 333 hL dans la citerne.

Méthode : Déterminer une fonction affine à partir de deux valeurs

Exemple

Un abonnement coûte f(x)=ax+bf(x) = ax + bf(x)=ax+b euros pour xxx séances, avec f(4)=38f(4) = 38f(4)=38 et f(10)=68f(10) = 68f(10)=68. Déterminer aaa et bbb.

  1. Étape 1 (Coefficient directeur) : a=68−3810−4=306=5a = \frac{68 - 38}{10 - 4} = \frac{30}{6} = 5a=10−468−38​=630​=5.

  2. Étape 2 (Ordonnée à l'origine) : f(4)=5×4+b=38f(4) = 5 \times 4 + b = 38f(4)=5×4+b=38, donc b=18b = 18b=18.

  3. Étape 3 (Vérification) : f(10)=50+18=68f(10) = 50 + 18 = 68f(10)=50+18=68.

  4. Conclusion : f(x)=5x+18f(x) = 5x + 18f(x)=5x+18 : 181818 € de frais fixes et 555 € par séance.

Méthode : Déterminer un seuil

Exemple

Une médiathèque compte 1 2001\,2001200 inscrits en 2026 et en gagne 454545 par an. En quelle année dépassera-t-elle 2 0002\,0002000 inscrits ?

  1. Étape 1 (Modéliser) : avec u(0)u(0)u(0) pour 2026, u(n)=1 200+45nu(n) = 1\,200 + 45nu(n)=1200+45n.

  2. Étape 2 (Inéquation) : 1 200+45n>2 000  ⟺  45n>8001\,200 + 45n > 2\,000 \iff 45n > 8001200+45n>2000⟺45n>800.

  3. Étape 3 (Plus petit entier) : 45×17=765<80045 \times 17 = 765 < 80045×17=765<800 et 45×18=810>80045 \times 18 = 810 > 80045×18=810>800, donc n=18n = 18n=18.

  4. Conclusion : le seuil est dépassé pour n=18n = 18n=18, c'est-à-dire en 2026+18=20442026 + 18 = 20442026+18=2044.

Pièges fréquents

  • u(n)=u(0)+nru(n) = u(0) + nru(n)=u(0)+nr si la suite commence à u(0)u(0)u(0), mais u(n)=u(1)+(n−1)ru(n) = u(1) + (n - 1)ru(n)=u(1)+(n−1)r si elle commence à u(1)u(1)u(1).
  • Dans a=f(x2)−f(x1)x2−x1a = \frac{f(x_2) - f(x_1)}{x_2 - x_1}a=x2​−x1​f(x2​)−f(x1​)​, garder le même ordre au numérateur et au dénominateur.
  • Pour un seuil, l'inéquation donne par exemple n>17,7n > 17{,}7n>17,7 : le rang cherché est 181818, et il faut encore le traduire en année si la question le demande.
  • Une augmentation d'un même pourcentage chaque année n'est pas une croissance linéaire : la variation absolue change d'une année à l'autre.

Questions de révision

Essaie de répondre de tête avant d'afficher la réponse.

Qu'est-ce qu'une croissance linéaire ?

Une évolution où l'on ajoute (ou retranche) la même valeur à chaque étape.

Relation de récurrence d'une suite arithmétique de raison rrr ?

u(n+1)=u(n)+ru(n+1) = u(n) + ru(n+1)=u(n)+r pour tout entier naturel nnn.

Terme général d'une suite arithmétique de premier terme u(0)u(0)u(0) et de raison rrr ?

u(n)=u(0)+nru(n) = u(0) + nru(n)=u(0)+nr.

Terme général si la suite commence à u(1)u(1)u(1) ?

u(n)=u(1)+(n−1)ru(n) = u(1) + (n - 1)ru(n)=u(1)+(n−1)r.

Comment obtenir la raison à partir de u(p)u(p)u(p) et u(q)u(q)u(q) ?

r=u(q)−u(p)q−pr = \frac{u(q) - u(p)}{q - p}r=q−pu(q)−u(p)​.

Sens de variation d'une suite arithmétique de raison r<0r < 0r<0 ?

Elle est décroissante.

Comment reconnaît-on graphiquement une suite arithmétique ?

Les points (n;u(n))\left(n ; u(n)\right)(n;u(n)) sont alignés.

Coefficient directeur d'une fonction affine connaissant deux valeurs ?

a=f(x2)−f(x1)x2−x1a = \frac{f(x_2) - f(x_1)}{x_2 - x_1}a=x2​−x1​f(x2​)−f(x1​)​.

Que représente bbb dans f(x)=ax+bf(x) = ax + bf(x)=ax+b ?

L'ordonnée à l'origine : f(0)=bf(0) = bf(0)=b.

Si 15n>30015n > 30015n>300, à partir de quel entier nnn le seuil est-il dépassé ?

n>20n > 20n>20, donc à partir de n=21n = 21n=21.

Exercices corrigés

Exercice 1 Terme d'une suite arithmétique

Palier 1 · découverte

La suite uuu est arithmétique de premier terme u(0)=12u(0) = 12u(0)=12 et de raison r=7r = 7r=7. Que vaut u(10)u(10)u(10) ?

  1. 898989
  2. 120120120
  3. 757575
  4. 828282
Un indice

Partir du premier terme et ajouter la raison autant de fois qu'il y a d'étapes : u(n)=u(0)+nru(n) = u(0) + nru(n)=u(0)+nr.

Voir la correction

Bonne réponse : D. 828282

u(10)=12+10×7=12+70=82u(10) = 12 + 10 \times 7 = 12 + 70 = 82u(10)=12+10×7=12+70=82.

Exercice 2 Fonction affine par deux valeurs

Palier 2 · application

La fonction affine fff vérifie f(2)=11f(2) = 11f(2)=11 et f(6)=23f(6) = 23f(6)=23. Quelle est son expression ?

  1. f(x)=12x−13f(x) = 12x - 13f(x)=12x−13
  2. f(x)=4x+3f(x) = 4x + 3f(x)=4x+3
  3. f(x)=3x+5f(x) = 3x + 5f(x)=3x+5
  4. f(x)=3x+11f(x) = 3x + 11f(x)=3x+11
Un indice

Le coefficient directeur est le quotient de la variation des images par la variation des abscisses ; on obtient ensuite bbb en utilisant l'une des deux valeurs connues.

Voir la correction

Bonne réponse : C. f(x)=3x+5f(x) = 3x + 5f(x)=3x+5

a=23−116−2=124=3a = \frac{23 - 11}{6 - 2} = \frac{12}{4} = 3a=6−223−11​=412​=3, puis 2×3+b=112 \times 3 + b = 112×3+b=11 donne b=5b = 5b=5. Vérification : f(6)=18+5=23f(6) = 18 + 5 = 23f(6)=18+5=23. Donc f(x)=3x+5f(x) = 3x + 5f(x)=3x+5.

Exercice 3 Seuil dans un contexte

Palier 3 · approfondissement

Une plateforme compte 3 4003\,4003400 abonnés en 2026 et en gagne 260260260 chaque année. On note u(n)u(n)u(n) le nombre d'abonnés en 2026+n2026 + n2026+n. En quelle année le nombre d'abonnés dépassera-t-il strictement 6 0006\,0006000 ?

  1. 2036
  2. 2046
  3. 2035
  4. 2037
Un indice

Écrire u(n)u(n)u(n) en fonction de nnn, résoudre l'inéquation u(n)>Su(n) > Su(n)>S, garder le plus petit entier qui convient, puis le traduire en année.

Voir la correction

Bonne réponse : D. 2037

u(n)=3 400+260nu(n) = 3\,400 + 260nu(n)=3400+260n. 260n>2 600  ⟺  n>10260n > 2\,600 \iff n > 10260n>2600⟺n>10 : l'inégalité est stricte, donc n=10n = 10n=10 ne convient pas (u(10)=6 000u(10) = 6\,000u(10)=6000) et le plus petit entier est n=11n = 11n=11. L'année cherchée est 2026+11=20372026 + 11 = 20372026+11=2037.

Exercice 4 Comparer deux tarifs

Palier 4 · défi

Tarif A : 999 € par séance. Tarif B : un abonnement de 606060 € puis 555 € par séance. À partir de combien de séances le tarif B est-il strictement moins cher que le tarif A ?

  1. 161616
  2. 151515
  3. 121212
  4. 777
Un indice

Exprimer le coût de chaque tarif en fonction du nombre de séances, puis résoudre l'inéquation « coût B < coût A » dans les entiers naturels.

Voir la correction

Bonne réponse : A. 161616

60+5n<9n  ⟺  60<4n  ⟺  n>1560 + 5n < 9n \iff 60 < 4n \iff n > 1560+5n<9n⟺60<4n⟺n>15. Pour 151515 séances les deux tarifs coûtent 135135135 € ; le tarif B devient strictement moins cher à partir de 161616 séances (140140140 € contre 144144144 €).
