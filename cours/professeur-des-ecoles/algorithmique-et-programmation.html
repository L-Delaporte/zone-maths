Cours et exercices corrigés du CRPE : Algorithmique et programmation (Scratch)

Lecture et exécution d'un programme Scratch, variables, boucles, instructions conditionnelles, programmes de calcul, déplacements et tracés, recherche d'erreurs dans un script.

Objectifs du chapitre

  • Exécuter à la main un script et prévoir le résultat affiché ou le tracé obtenu.
  • Comprendre le rôle d'une variable, d'une boucle (« répéter », « répéter jusqu'à ») et d'une instruction conditionnelle.
  • Traduire un programme de calcul en expression littérale, et inversement.
  • Repérer et corriger une erreur dans un script.

Le cours

1. Variables

Une variable est une case mémoire qui porte un nom et contient une valeur, que le programme peut modifier. « mettre nnn à 555 » remplace l'ancienne valeur ; « ajouter 222 à nnn » la transforme en n+2n + 2n+2.

2. Boucles et conditions

  • répéter kkk fois : le bloc est exécuté exactement kkk fois.
  • répéter jusqu'à une condition : on teste la condition avant chaque passage ; on s'arrête dès qu'elle est vraie.
  • si … alors … sinon : un seul des deux blocs est exécuté selon la condition.

3. Tracés

Pour un polygone régulier à nnn côtés, le lutin tourne de 360°n\frac{360°}{n}n360°​ à chaque sommet (angle extérieur) : 120°120°120° pour un triangle équilatéral, 90°90°90° pour un carré, 60°60°60° pour un hexagone.

4. Programmes de calcul

Un programme « choisir un nombre, le multiplier par 333, ajouter 444 » se traduit par x↦3x+4x \mapsto 3x + 4x↦3x+4. Exécuter le programme pour plusieurs valeurs permet de conjecturer ; le calcul littéral permet de démontrer.

5. Au concours : erreurs d'élèves fréquentes

  • Tourner de 60°60°60° pour tracer un triangle équilatéral (confusion angle intérieur et extérieur).
  • Oublier d'initialiser une variable au début du script.
  • Mal compter le nombre de passages d'une boucle « répéter jusqu'à ».

Méthodes et exemples rédigés

Méthode : Exécuter un script à la main avec un tableau

Exemple

mettre nnn à 111 ; mettre sss à 000 ; répéter jusqu'à n>4n > 4n>4 : ajouter nnn à sss, ajouter 111 à nnn. Que vaut sss ?

  1. Tableau : (n;s)(n ; s)(n;s) vaut (1;0)(1 ; 0)(1;0), puis (2;1)(2 ; 1)(2;1), (3;3)(3 ; 3)(3;3), (4;6)(4 ; 6)(4;6), (5;10)(5 ; 10)(5;10).

  2. Arrêt : n=5>4n = 5 > 4n=5>4 : la boucle s'arrête.

  3. Résultat : s=1+2+3+4=10s = 1 + 2 + 3 + 4 = 10s=1+2+3+4=10.

Méthode : Tracer un polygone régulier

Exemple

Écrire un script qui trace un hexagone régulier de côté 505050 pas.

  1. Étape 1 : l'hexagone a 666 côtés : on répète 666 fois.

  2. Étape 2 : à chaque passage, avancer de 505050 puis tourner de 360°6=60°\frac{360°}{6} = 60°6360°​=60°.

  3. Script : stylo en position d'écriture ; répéter 666 fois (avancer de 505050 ; tourner de 606060 degrés).

Pièges fréquents

  • L'ordre des instructions compte : « ajouter 111 puis multiplier par 222 » n'est pas « multiplier par 222 puis ajouter 111 ».
  • Une boucle « répéter jusqu'à » dont la condition n'est jamais vraie ne s'arrête pas.
  • L'angle de rotation du lutin n'est pas l'angle intérieur du polygone.

Questions de révision

Essaie de répondre de tête avant d'afficher la réponse.

Angle dont tourne le lutin pour un pentagone régulier ?

72°72°72°.

Expression du programme « ajouter 555, multiplier par 222 » ?

2(x+5)=2x+102(x + 5) = 2x + 102(x+5)=2x+10.

Combien de fois le bloc est-il exécuté dans « répéter 888 fois » ?

888 fois.

Que fait « ajouter −3-3−3 à nnn » ?

Remplace nnn par n−3n - 3n−3.

Exercices corrigés

Exercice 1 Programme de calcul

Palier 1 · découverte

Programme : choisir un nombre ; le multiplier par 333 ; ajouter 444. Quel résultat obtient-on en choisissant 555 ?

Un indice

Appliquez les instructions une à une, dans l'ordre donné.

Voir la correction

Réponse attendue : 19

5×3=155 \times 3 = 155×3=15, puis 15+4=1915 + 4 = 1915+4=19.

Exercice 2 Tracer un octogone

Palier 2 · application

Un lutin trace un octogone régulier avec le script : répéter 888 fois (avancer de 404040 ; tourner de ??? degrés).
De combien de degrés doit-il tourner ?

Un indice

Au cours du tracé complet, le lutin effectue exactement un tour sur lui-même.

Voir la correction

Réponse attendue : 45

Le lutin tourne de l'angle extérieur : 360°8=45°\frac{360°}{8} = 45°8360°​=45° (l'angle intérieur de l'octogone mesure 135°135°135°).

Exercice 3 Boucle « répéter jusqu'à »

Palier 3 · approfondissement

Script : mettre nnn à 222 ; mettre sss à 000 ; répéter jusqu'à n>10n > 10n>10 : (ajouter nnn à sss ; ajouter 333 à nnn).
Quelle est la valeur de sss à la fin ?

Un indice

Dressez un tableau des valeurs de nnn et de sss après chaque passage dans la boucle.

Voir la correction

Réponse attendue : 15

(n;s)(n ; s)(n;s) : (2;0)(2 ; 0)(2;0) → (5;2)(5 ; 2)(5;2) → (8;7)(8 ; 7)(8;7) → (11;15)(11 ; 15)(11;15). Comme 11>1011 > 1011>10, la boucle s'arrête : s=2+5+8=15s = 2 + 5 + 8 = 15s=2+5+8=15.

Exercice 4 Instruction conditionnelle

Palier 4 · défi

Script : mettre nnn à 666 ; répéter 333 fois : (si nnn est pair alors mettre nnn à n÷2n \div 2n÷2, sinon mettre nnn à 3×n+13 \times n + 13×n+1).
Quelle est la valeur de nnn à la fin ?

Un indice

À chaque passage, testez d'abord la parité de nnn.

Voir la correction

Réponse attendue : 5

666 est pair : n=3n = 3n=3. 333 est impair : n=10n = 10n=10. 101010 est pair : n=5n = 5n=5. À la fin, n=5n = 5n=5.
